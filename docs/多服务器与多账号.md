# 多服务器与多账号

在“设置 → 服务器”添加服务器，或在已有服务器下选择“添加账号”。登录成功后，该账号会加入在线来源；其他已登录账号继续保留。账号行显示在线状态，“退出登录”只退出这一账号。

启动时恢复此前允许自动连接的账号。主动退出的账号不会因为保存了密码而自动重新登录；再次登录后恢复自动连接。临时无法连接的来源可以在服务器页重新登录，其他可用来源仍能使用。

## 浏览与搜索

- 主页显示所有在线来源的媒体库、继续观看和最近添加内容。无论连接一个还是多个服务器，轮播、媒体库卡片下方、媒体卡片和列表标题都不追加服务器名称或用户名；各来源的同编号条目仍分别保留。
- 搜索默认查询全部在线来源；每个来源独立分页。进入具体媒体库、文件夹、人物或详情页后，操作保持该条目的来源。搜索、最近搜索、收藏与详情货架不显示服务器名称或用户名。
- 收藏聚合全部在线账号。收藏、观看状态、下载、图片和元数据操作只使用选中条目所属账号。
- 某个来源读取失败时保留其他来源的结果，并提示刷新重试。多来源结果交错排列；具体媒体库继续使用该库支持的排序与筛选。
- 标题栏的服务器和账号选择用于确定服务器管理、通知设置等操作的默认身份，不会退出其他在线账号。在添加账号表单上可通过主页按钮返回浏览。

## 版本与播放

详情页和播放器的“版本”选择项先显示文件信息；只有连接多个不同服务器时，才在文件信息后追加服务器名称，不显示用户名。只连接一个服务器时，即使登录了该服务器的多个账号，也不追加服务器名称。同服务器不同账号通过服务器身份和媒体编号识别同一条目；不同服务器通过一致的刮削标识、类型与季集信息匹配，不会仅按同名合并。没有足够标识的跨服务器媒体仍可分别浏览、搜索和播放。

播放中选择另一个来源的版本，会保留当前播放位置，使用新来源的凭据和媒体地址，并向各自来源上报对应播放状态。跨来源换版使用精确播放位置，不额外套用普通续播的回退秒数。新来源不可用时会提示失败；不会把观看记录写到另一个账号。

飞牛影视目前返回适配模型中缺少可信跨服务器刮削标识时，不做跨服务器版本合并；同一飞牛服务器不同账号仍可通过媒体编号识别版本。
