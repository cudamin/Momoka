# 多服务器与多账号

在“设置 → 服务器”添加服务器，或在已有服务器下选择“添加账号”。服务器页顶部先选连接模式：

- **聚合模式（默认）**：可同时登录多台服务器、多个账号；登录成功后该账号加入在线来源，其他已登录账号继续保留。账号行显示在线状态，“退出登录”只退出这一账号。
- **独占模式**：同一时间只保留一台服务器、一个账号在线。登录或切换到另一台服务器/账号时，当前连接退出，**保存的账号与密码不删除**，以后点它仍可直接恢复。启动时先用上次的账号；它连不上时按最近登录次序再试下一个，直到有一个上线。

主动退出的账号不会因为保存了密码而自动重新登录；再次登录后恢复自动连接。临时无法连接的来源可以在服务器页重新登录。独占模式切回聚合后不会自动重连此前被收口的账号，需要时在服务器页登录。

## 界面

界面由**在线的服务器台数**决定，不由保存了多少配置决定：

- **只有一台服务器在线**（无论一个还是几个账号）时，使用那台服务器自己的界面。Emby 与 Jellyfin 各有自己的服务端管理目录与网页控制台；飞牛影视和 Plex 目前使用通用界面。Jellyfin 界面包括它的库分类、能力过滤和五段式设置目录（见 [Jellyfin 支持](Jellyfin支持.md)）。
- **同时有多台服务器在线**时，切换到通用界面：设置里的服务端管理入口（Emby 的「通知」与两家的服务器目录）整组收起，只保留各端共有的功能；服务器页与账号菜单会写明“通用界面”。同一台服务器上的多个账号不改变界面。
- **没有在线来源**时也是通用界面；登录后按上面两条重新计算，不需重启。

两种模式都不会删除服务器配置、账号或保存的凭据。退出登录只影响当前在线来源；模式收口保留令牌与密码，供以后恢复。

## 浏览与搜索

- 主页显示所有在线来源的媒体库、继续观看和最近添加内容。无论连接一个还是多个服务器，轮播、媒体库卡片下方、媒体卡片和列表标题都不追加服务器名称或用户名；各来源的同编号条目仍分别保留。
- 搜索默认查询全部在线来源；每个来源独立分页。进入具体媒体库、文件夹、人物或详情页后，操作保持该条目的来源。搜索、最近搜索、收藏与详情货架不显示服务器名称或用户名。
- 收藏聚合全部在线账号。收藏、观看状态、下载、图片和元数据操作只使用选中条目所属账号。
- 某个来源读取失败时保留其他来源的结果，并提示刷新重试。多来源结果交错排列；具体媒体库继续使用该库支持的排序与筛选。
- 标题栏的服务器和账号选择用于确定服务器管理、通知设置等操作的默认身份，不会退出其他在线账号。在添加账号表单上可通过主页按钮返回浏览。

## 版本与播放

详情页和播放器的“版本”选择项先显示文件信息；只有连接多个不同服务器时，才在文件信息后追加服务器名称，不显示用户名。只连接一个服务器时，即使登录了该服务器的多个账号，也不追加服务器名称。同服务器不同账号通过服务器身份和媒体编号识别同一条目；不同服务器通过一致的刮削标识、类型与季集信息匹配，不会仅按同名合并。没有足够标识的跨服务器媒体仍可分别浏览、搜索和播放。

播放中选择另一个来源的版本，会保留当前播放位置，使用新来源的凭据和媒体地址，并向各自来源上报对应播放状态。跨来源换版使用精确播放位置，不额外套用普通续播的回退秒数。新来源不可用时会提示失败；不会把观看记录写到另一个账号。

飞牛影视目前返回适配模型中缺少可信跨服务器刮削标识时，不做跨服务器版本合并；同一飞牛服务器不同账号仍可通过媒体编号识别版本。
