# 多服务器与多账号

在“设置 → 服务器”添加服务器，或在已有服务器下选择“添加账号”。服务器的登录行为由**聚合模式**决定：

- **关闭（装机默认）**：同一时间只有一台服务器、一个账号在线。登录另一台服务器或另一个账号会替换当前在线来源；被替换的账号下线，但服务器、账号、保存的令牌和密码都保留，切换回来时不必重新输入密码。启动时只恢复上次使用的那个账号，连不上再按最近登录次序尝试下一个。
- **开启**：多台服务器、多个账号可以同时在线。登录新账号不会退出其他账号；账号行显示在线状态，“退出登录”只退出这一账号。关闭聚合模式时会留下当前来源，其余在线账号下线但保留凭据与自动连接。

在服务器页拨动开关就当场生效，不需要重启。主动退出的账号不会因为保存了密码而自动重新登录；再次登录后恢复自动连接。临时无法连接的来源可以在服务器页重新登录；它恢复后，媒体库列表与最近添加会重新包含这个来源的内容。

## 账号菜单

标题栏右上角（侧边栏模式下在左下角）的账号按钮只写身份：用户名与服务器名。打开后的第一行显示“用户名 · 服务器名”，多个账号在线时再补一句账号数，不写界面类型。

- 聚合模式开启时，两张子菜单叫“添加服务器”“添加账号”：在线项可用来切换默认管理身份，离线项登录后加入在线来源，菜单末尾另有“添加服务器…”“添加账号…”直接打开登录页。
- 聚合模式关闭时，两张子菜单叫“切换服务器”“切换用户”：选择另一项会替换当前在线来源，保存的凭据不删除。

## 界面

服务端管理入口由**在线的服务器台数**决定，不由保存了多少配置决定：

- **只有一台服务器在线**（无论一个还是几个账号）时，使用那台服务器自己的界面。Emby 与 Jellyfin 各有自己的服务端管理目录与网页控制台；飞牛影视作为唯一在线服务器时有自己的「帐号／影视服务器」原生目录；Plex 使用通用目录。Jellyfin 界面包括它的库分类、能力过滤和五段式设置目录（见 [Jellyfin 支持](Jellyfin支持.md)），飞牛的目录见 [飞牛影视](飞牛影视.md)。
- **同时有多台服务器在线**时，设置左栏在「Momoka」组之后按在线服务器各列一组（例如「Emby · 客厅」「Jellyfin · 书房」「飞牛影视 · 果服」）；多服务器时这些组默认全部收起，展开哪一组就显示那一台现有的设置目录。组内保留各产品自己的分区标题：Emby「Emby Server／设备／高级」、Jellyfin「服务器／设备／电视直播／插件／高级」、飞牛「帐号／影视服务器」；标题只分段、不能当作页面选中。组内入口绑定那一台自己的服务器与账号，不再是“当前来源”：Emby／Jellyfin 的入口打开那一台的 WebView2 网页控制台，飞牛影视打开它自己的原生页。每个账号只看得到自己可访问的库；没有库管理权限的服务器/账号不列对应管理入口（Emby／Jellyfin 整组不占行，飞牛只保留帐号设置）。同一台服务器上的多个账号不改变结论，组内优先使用有管理权限的在线账号。
- **没有在线来源**时登录后按上面两条重新计算，不需重启。

## 浏览与搜索

- 聚合模式开启、多个来源在线时，主页显示所有在线来源的媒体库、继续观看和最近添加内容；每个在线账号的每个库都有自己的“最近添加”一排。两个及以上在线账号时，主页在继续观看卡的季集信息下面写服务器名，在每个库“最近添加 · …”货架标题和媒体库卡片名称前面写“服务器名 · ”；只有一个在线账号时不写。轮播、搜索、最近搜索、收藏与详情货架不追加服务器名称或用户名；各来源的同编号条目仍分别保留。服务器名取服务器配置里的名称，不显示用户名。
- 搜索查询全部在线来源；每个来源独立分页。进入具体媒体库、文件夹、人物或详情页后，操作保持该条目的来源。搜索、最近搜索、收藏与详情货架不显示服务器名称或用户名。
- 标题栏的收藏页直接聚合全部在线账号的收藏；两个及以上可收藏账号在线时，工具栏出现「全部账号」筛选，切到单个账号后只显示并只请求那个账号。选择随返回栈保留到下次打开。Plex 没有收藏列表，不参与收藏聚合与账号筛选。
- 收藏、观看状态、下载、图片和元数据操作只使用选中条目所属账号。
- 某个来源读取失败时保留其他来源的结果，并提示刷新重试。多来源结果交错排列；具体媒体库继续使用该库支持的排序与筛选。
- 标题栏的服务器和账号选择用于确定服务器管理、通知设置等操作的默认身份；聚合模式下不会退出其他在线账号。

## 版本与播放

详情页和播放器的“版本”选择项先显示本条目的文件信息；聚合模式开启时，还会查找当前账号其他媒体库、其他在线账号与其他服务器里的同一媒体，保留本地版本次序并去掉重复条目。关闭聚合模式后只显示本条目的版本，不查询其他库。只有连接多个不同服务器时，才在文件信息后追加服务器名称，不显示用户名；同一服务器的多个账号或媒体库不追加服务器名称。同服务器不同账号可以通过服务器身份和媒体编号识别同一条目；其他独立条目和跨服务器版本通过一致的刮削标识、类型、年份与季集信息匹配，不会仅按同名合并。没有足够标识的媒体仍可分别浏览、搜索和播放。

播放中选择另一个来源的版本，会保留当前播放位置，使用新来源的凭据和媒体地址，并向各自来源上报对应播放状态。跨来源换版使用精确播放位置，不额外套用普通续播的回退秒数。新来源不可用时会提示失败；不会把观看记录写到另一个账号。

飞牛影视列表、搜索与详情返回的 `imdb_id` 会作为 IMDb 标识参与双向跨库匹配；内部 `trim_id` 不当作 TMDB 标识猜测。单集详情没有所属剧编号时，先沿“单集 → 季 → 剧”读取所属剧，再核对季集号；缺少可信刮削标识时仍不按同名跨服务器合并。同一飞牛服务器不同账号仍可通过媒体编号识别本条目版本。

版本查询保持各账号自己的媒体库权限。另一账号无法访问原条目时，仍可在它有权限的库里查找同片；Emby 标识查询接口不可用时回退标题搜索，候选照样核对刮削标识，Jellyfin／飞牛各走自己的协议。

## 设置位置

- **设置 → 服务器**：聚合模式开关、已保存服务器与账号、局域网发现与连接测试。
- **设置 → 关于**：图片缓存占用与清除、图片缓存上限，以及缓存目录等本机位置。
