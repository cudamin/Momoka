# Plex

在 Momoka 的服务器连接页填写 Plex 服务器地址（例如 `192.168.1.5`、`192.168.1.5:32400` 或从浏览器复制的带 `/web` 的地址），应用自动识别服务类型。登录使用 **Plex 账号**（plex.tv）而不是服务器本地账号：Plex 服务器本身不校验账号密码，账号由 Plex 的账号服务认证，拿到的令牌再交回目标服务器核对这台服务器有没有共享给该账号。保存的密码与令牌走现有的 DPAPI 凭据保险箱，与 Emby、飞牛共用同一套。

连接后复用 Momoka 的主页、媒体库、搜索、电影与剧集详情和播放界面。列表支持名称、入库时间、上映日期与评分排序（另有「随机」用于首页轮播）。播放器使用服务器给出的原始文件地址（`Part.key`），令牌只在请求头 `X-Plex-Token` 里，不进地址、不进日志、不进启动参数；支持续播、内嵌音轨、Plex 可单独下载的外挂字幕以及进度上报（`/:/timeline`）。「标记为已观看 / 未观看」走 `/:/scrobble` 与 `/:/unscrobble`。

## 与其它后端不同的地方

- **地址默认端口是 32400**，但只对 `http` 生效；`https` 且没写端口的地址保留 443，因为那种写法基本是反向代理，硬指到 32400 会把能用的配置改坏。浏览器地址栏里的 `/web` 或 `/web/index.html` 会被剥掉。
- 用户明确写出的 HTTP `:80` 会保留，包括保存后的显示地址再归一化；IPv6 主机只保留一层方括号，无端口 HTTP IPv6 同样使用 32400。端口是否明确填写按原始地址的 authority 判断，不拿 `Uri.IsDefaultPort` 代替这一事实。直接 Plex 与共享显示入口都有离线表驱动往返回归，不需要连接服务器。
- **没有用户列表。** Plex 服务器不提供 Emby 那种公开用户列表，登录页因此只有用户名与密码两格，直接手填。
- **不支持的入口一律收起，不置灰**：收藏（Plex 服务端 API 没有条目级收藏位）、筛选面板与字母跳转、合集、下载到设备、修改元数据、识别、删除、章节缩略图、遗漏集、搜索字幕、通知、网页控制台。这些是服务端没有对应接口，不是没做完；菜单与设置左栏都按产品裁剪。
- **管理入口一个都没有。** Plex 没有可供本客户端读取的管理接口，所以「设置」左栏在 Plex 名下不会多出任何一组，与飞牛影视同样待遇。

## 协议依据与验证边界

协议面见 [Plex 协议技能](../.claude/skills/momoka-plex-api/SKILL.md)，接口清单见其 [接口表](../.claude/skills/momoka-plex-api/references/endpoints.md)。

**这一版没有对任何真实 Plex 服务器做过核对。** 所有路径、字段名与参数都是从 Plex 的公开接口约定写下来的，只用离线假传输验证了「本客户端发出什么、怎么读回答」：

- `PlexProtocolTests`：地址归一化（默认端口、https、`/web`、账户信息、非法 scheme）、条目标识与媒体地址不能逃逸服务器、`/:/` 特殊端点的拼法、令牌只在请求头、`/identity` 不带令牌、401 判为令牌失效且不回显服务端正文、跨来源重定向不发第二次请求、账号密码走正文且客户端标识走头部、分页走 `X-Plex-Container-*` 头、排序与类型走查询串、scrobble 与 timeline 的参数与毫秒单位。
- `PlexMediaTests`：登录、令牌失效后同身份恢复、已保存账号恢复（不重登账号）、音乐库被挡在外面、搜索分类、详情把 `Media`/`Part`/`Stream` 映射成媒体源与音轨、季集与「接下来播放」、播放规划（原始地址、请求头、part key）、进度上报、菜单裁剪，以及不支持的收藏操作不向服务器发任何请求。
- 媒体库 ID 使用 `Directory.key`，电影／剧集条目继续使用 `ratingKey`；库 key 缺失、null 或空白时拒绝本次库响应，不生成可点击的空 ID 入口。新增库映射回归直接使用 `GetViews` 产物验证两库浏览、逐库最近添加、随机轮播及跨来源导航键，不执行登录或真实服务器请求。

**没有验证的是**：真实 Plex 服务器是否按上面这些路径与字段回答；真实播放、进度上报落库、多账号切换、反向代理与 HTTPS 下的实际行为；plex.tv 账号服务的实际响应形状与错误码。第一次连真实服务器时请按只读顺序来（先只填地址点「连接」，确认识别出 Plex 与服务器名，再登录），并把观察结果补进这一节。
