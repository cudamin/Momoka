## 身份与传输

音乐是独立 `/music` 应用，业务基址 `{mount}/api/v1/`，不能借用影视 `/v`、Authorization 或应用密钥。粘贴音乐页面/API URL 时保留音乐 mount 和已有反代路径，移除 query/fragment。

匿名配置确认 `serverGUID` 与版本后，`POST user/password-login`，正文 `{username,password:SHA256(明文)小写hex,deviceId}`。官方 `pA` 生成稳定 32 位 hex；Momoka 从现有稳定设备 ID 取 MD5 32 hex，是客户端身份选择。登录返回 `{userToken,user:{guid,name,role}}`；再 `GET user/me` 核对用户，仅接受 `admin/member`。保存令牌恢复沿用既有会话，先匿名确认服务器再确认用户；身份变更拒绝旧响应和重新发送旧操作。

网页 `Ik` 写 `music-token=encodeURIComponent(token); Path=/; SameSite=Strict`，REST fetch 为 `credentials:include`。Momoka 每请求 Cookie，禁用共享 Cookie 容器。图片/原音频同样需要身份，令牌不进 URL。HTTP401 或 code120001 过期，100003/100004 权限而非过期；`Wb` 接受 code0/200。错误本地生成，不展示可能回显凭据的 msg。

REST `authx` 是六位 nonce、毫秒 timestamp 和 MD5 签名。公开音乐应用常量写在 `FnMusicSigner`，不含用户 token。GET 最终 query 过滤字面 `undefined/null` 后按 key 覆盖、排序、URLSearchParams 编码，再 `+` 转 `%20` 并 decode；POST 对实际 JSON 原文摘要，空 body 与 `{}` 不同。当前参数只用标量，数组/multipart 不在本批。

## 浏览与资源

| 需求 | 官方请求 |
| --- | --- |
| 歌曲 | `GET track/list?page=&size=&sort=`；`track/metadata?guid=` 返回 `{track,audioSpec}` |
| 专辑 | `album/list`、`album/detail?guid=`；`track/album-detail/list?albumGUID=&page=&size=&sort=trackNo,asc` |
| 艺术家 | `artist/list`、`artist/detail?guid=`；`album/artist-detail/list?artistGUID=`、`track/artist-detail/list?artistGUID=` |
| 歌单 | `playlist/list` 无参数；`playlist/detail?guid=`；`playlist/batch-detail?guids=<逗号>`；`track/playlist-detail/list?playlistGUID=&page=&size=&sort=` |
| 搜索 | `search/track|album|artist|playlist?q=`；跨版本分页未知，本批本地切片 |
| 喜欢 | `favorite-track/list`；`POST favorite-track/create|delete {trackGUID}`，确认不绑读回到可重试写入 |
| 封面 | `static/cover?coverId=<完整ID>&size=`；160/600/1024/1600/2000，原图省略 size |
| 音频 | `track/stream?guid=<原始GUID>`，普通原流不创建转码 |
| 歌词 | `GET lyric/list?trackGUID=<原始GUID>` 返回 `{list,preferred}`；条目 `{guid,content,offset,source,updatedAt,createdAt}` |
| 历史 | `POST event/report {events:[{eventType:"track_play",occurredAt:<毫秒>,payload:{trackGUID}}]}`；无伪造影视进度/停止上报 |

列表通常 `{list,total,sort}`。歌单计数可缺，不拿当前页条数冒充歌曲总数。歌曲 duration 毫秒；audioSpec.bitrate 比特/秒、size 字节、channel 声道，createdAt/updatedAt 秒。artists 为 `{guid,name}`，album 带 guid/name/artists/originalReleaseYear/coverId。容器本地 ID `fnmusic:album|artist|playlist:<guid>`，歌曲和 ArtistItems.Id 保留原 GUID。虚拟 root `music` 表示当前账号可访问集合，不伪造 shared-library 筛选接口。

歌词条目的 `content` 是 LRC 或纯文本原文，`offset` 是用户在飞牛音乐里调过的毫秒偏移（官方 `lyric_offset_change` 事件按 `offset: Math.round(秒*1000)` 上报）。`source` 1＝内嵌、2＝外部 .lrc、4＝手工；官方播放页按 1 > 2 > 4 > 未知、再按 `updatedAt`、`createdAt` 倒序挑第一条能解析出时间轴的歌词，`preferred` 指向的那条优先。Momoka 复刻这条顺序并叠加 `offset`；TTML／YRC 原文不猜时间轴，退回文件内嵌标签。

## 边界与验证

实现密码连接/保存恢复、四类分页与容器、搜索、封面、歌曲喜欢、普通原流、歌词表及历史事件。CUE、ISO/SACD、accessStatus 非零、管理员已删除不给原流，避免整文件冒充分轨。转码/HLS、OAuth、首次初始化、漫游、物理目录和音乐管理尚未实现；TTML／YRC 歌词只识别格式并跳过。
