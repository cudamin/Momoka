## 正式行为与有意收窄

管理员电影、单集、视频“更多”增加“移出媒体库…”，版本表增加“移出所选版本”，下一步确认明确文件保留与恢复位置。整个条目发送空 `media_guids`；版本发送唯一所选文件 ID；两者固定 `delete_file=0`。现有物理删除入口仍执行其原有语义，这次新增移出路径不提供物理删除开关。

设置 → 影视服务器 → 媒体库每个非直播库显示“已移除文件…”。普通或未知管理员身份收起管理页与移出入口；服务层在请求前重新读取管理身份，并用当前来源和权限代次守卫后续请求。简表中正常文件不出现；文件夹可打开，移除项可选中后点“恢复所选项”。恢复成功只表示服务器接受并后台处理，不伪造即时入库结果。

取消确认不写。确认期间身份、权限或来源改变不写。在途写提交后暂时阻止关闭；页面释放显式取消读取并关闭弹窗，未提交时保留点击外部关闭。操作确认与页面读取分开；已确认恢复行立即移除，刷新失败显示“已提交恢复，但刷新失败”，显式刷新只读，不重复恢复。已确认路径由服务跨弹窗过滤服务器迟到旧行，观察到该路径明确正常后才解除防重。

同进程恢复按来源键、媒体库 ID 与本次移出已核的文件路径，精确退役该主体的移出原因票，保留同 ID 的物理删除原因。同账号重新登录能恢复旧票，当前账号权限仍在发出前检查；只有内存，不落盘，跨重启清单以服务器响应为准。连续移出版本以已确认清单判断最后一版，滞后列表不能重发已移出的版本。

恢复后需从媒体库重新打开详情，索引更新可能稍有延迟。当前详情访问中的播放目标与被移出版本继续受原删除防护，不清空物理删除记忆，也不宣称原详情页立即可播；父批次已认可这个范围。
