## 功能与边界

飞牛电影/视频/单集菜单新增「管理字幕…」，使用独立原生 ContentDialog，按媒体 GUID/完整路径列出版本。普通在线账号提供搜索、下载和本地上传；当前明确字幕拒权时隐藏菜单和从属操作。官方未提供单独字幕权限字段时，普通账号按官方可达性开放入口，执行服务端拒绝仍生效。管理员另显示服务器字幕完整路径输入和添加，实际 PUT 前重新读取 `user/info` 核管理员。

每个媒体版本持有独立服务、快照和写入回执。版本选择不改变已经捕获的操作目标；离页捕获原所属 Page，退出原账号撤销任务，默认浏览账号切换保留仍在线的固定账号。当前权限代次、媒体 GUID/路径、完整字幕快照、候选对象和搜索代次都参与守卫。删除先明确列出媒体文件、字幕名和不可撤销影响，取消无请求；相同 GUID 重复或同标签多文件无法区分时拒绝，确认后重新读取完整快照，变化则零写入。GET/DELETE 非原子，不能保证阻止服务端并发替换。

HTTP transport 在内容/鉴权/签名准备成功、实际发送前才记录 dispatched；业务明确非零 code、HTTP 4xx 和本地校验不造未知写入义务。`code=0` 的窄回调先记录 `Touched/NeedsRefresh`，避免后续 scope 取消覆盖成功。已确认成功但回读失败只允许刷新；未知回执记录 `NeedsRefresh` 且整次对话不再允许该版本写入。只读恢复显示最新列表供核对，保持未确认提示；列表新增不能反证某候选写入成功。关闭或切回未改版本仍交回整个对话的刷新义务。

本地上传保持原文件名/字节，支持 SRT/SUB/SSA/ASS/VTT/SUP，单个文件；**32 MiB 是 Momoka 的本地内存/资源限制，不是飞牛官方上限。** 管理员输入 NAS 完整路径添加单个字幕，未实现系统 WebSocket 文件浏览。官方 Web 支持最多 20 文件，本次最小原生入口选择单文件，属于有意范围限制。

外挂文本轨通过原生 `/subtitle/dl/{guid}` 进入 `FnNasMediaAdapter`、`MpvTrackMap`、`PlaybackPlanner` 和 `EmbyClient.SubtitleUrl` 两个出口，保留 ProviderId 供飞牛上报，使用本地选择索引并区分容器 ff-index。URL 型外轨不加载、不删除；外置图形轨可管理但当前播放器不加载，界面注明。`CanDelete = IsExternal && 有 Guid && 无 Url`；`ExtraFile` 仅用于展示/映射，不能扩展删除权限。未改播放管线、uosc 或外部后端。
