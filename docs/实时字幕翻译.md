# 实时字幕翻译（0.1.9）

## 设置 → 字幕 → 实时字幕翻译

默认关闭。启用后保留播放器原来的主字幕，逐句发送当前可见的文字字幕到所选服务，译文由独立 OSD 图层显示，不占主/次字幕轨道。支持 Google Cloud Translation v2、Microsoft Translator v3 与兼容 OpenAI Chat Completions 的 AI 服务；不是语音转文字或 OCR，PGS/VOBSUB 图形字幕和没有文字字幕的片源不会外发。

- 三种服务需要用户自己的 API 密钥，可能按量收费；谷歌/微软密钥只发到已核对的官方域，AI 允许用户配置可信 HTTPS 服务（本机模型允许 HTTP 回环地址）。地址不能夹账号、查询串或片段。不会借用浏览器登录。
- API 密钥经 Windows DPAPI 加密保存。输入只接收新值，保存成功清空，不回填明文。偏好备份不含密钥、端点、模型、区域与开启状态；导入/恢复默认不覆盖现有连接，只恢复语言/字号/位置。
- 译文支持目标语言、字号和位置，开关、配置立即作用于当前播放。外部 mpv 只有开启 IPC 才有翻译入口；缺密钥、读数/脚本不可用显示一次通知并保留原字幕。
- 只保留每片最多 256 句的内存缓存，切片清除，不保存原文/译文文件。一个请求预算最多 15 秒；字幕变了仍继续采样并取消旧请求，迟到响应丢弃。同窗换片同时守服务代次、原生文件代次、账号寿命；Lua 最后核对原句、字幕轨与时间。
- 默认 AI 模型在 2026-10-25 核对官方文档后选择 `gpt-6-luna`，该模型使用 `reasoning_effort=none` 减轻延迟。模型名可改为实际服务支持的名称，第三方模型不强加这个特定选项。网络/推理延迟可能超过台词展示时间，不承诺每句都有译文或翻译质量。
- 启用即会外发字幕文本；不要为含私密信息的字幕开启未知服务。模型请求把原句放在 JSON 数据/用户角色里，不拼入系统指令；这不保证模型永远不会误解字幕中的指令。

## 验证入口

- 独立离线：`tests/Momoka.SubtitleTranslationTests`（HTTP 请求、安全/密钥/缓存）、`tests/Momoka.SubtitleTranslationRuntimeTests`（逐句运行寿命/取消/备份）。先 Release 编译当前源再运行。
- Lua/libass 无媒体测试：`py -3 tools/test-subtitle-translation.py --output <本树新的唯一目录>`，不连网络/读用户配置。
- 真实控件离线：`--probe-shell --probe-section settings` 里的「字幕实时翻译的服务显隐、密钥及宽窄布局」一条，覆盖三家服务切换、占位密钥保存与清空、从属行显隐恢复、五主题宽窄窗截图，以及外部 mpv 无 IPC 时翻译卡收起、恢复 IPC 后回来；传输全部假处理，拒绝真实播放。
- 项目交付按 CLAUDE.md 四闸门；真实翻译服务/真实账号/真实库播放必须单独授权。不要把匿名请求/参数接受当作真实服务与每个后端的画面验收。
