# 本机整理

设置 → 本机整理。目录列表在最上方，点「添加目录」可以添加多个媒体库；一个目录就是一个本地媒体库，保存每一行时才要求媒体库名称和目录同时有效。保存后该目录即出现在首页媒体库区域，进入后只展示这个库已经入库的内容。源目录可以是本机盘符（`C:\媒体`）或网络共享（`\\服务器\共享\媒体`），网络共享使用当前 Windows 账号访问，Momoka 不保存共享凭据。

识别方式在目录列表下方统一选择：Momoka（直连 TMDB）或 MoviePilot。Momoka 需要 TMDB 帐号的 API Read Access Token，界面中文名为「API 读访问令牌」，保存后由 Windows 加密保管；MoviePilot 使用现有连接，只提交相对路径文本，不上传视频。

本机整理不再提供硬链接、软链接或直接改名：

- 视频文件保持原位，文件名、目录和时间戳都不改，也不创建任何链接。
- 刮削出的 NFO、海报、背景图与单集剧照写入「元数据目录」，默认是 `%LOCALAPPDATA%\Momoka\metadata`，可在页面里自定义或恢复默认。
- 元数据按媒体库名称分开存放：电影在「作品 (年份)」下；剧集在「作品 (年份)」下再分 `Season NN`，`tvshow.nfo` 与海报放在作品目录。
- 同名元数据不覆盖；同一部剧的不同单集共用 `tvshow.nfo`、海报和背景图，写入前核对 TMDB 身份，其他作品不会混用。
- 演职人员头像按 TMDB 人物编号写在作品目录的 `people` 子目录里，同一部剧各集共用；头像下载失败只少一张脸，不算入库未完成。
- 图片按元数据目录里的目标后缀落盘；TMDB 取图只接受 JPEG/PNG，不索取 WebP，避免 `.jpg` 目标拿到 WebP 字节而被拒写。

保存媒体库后可以手动「扫描并识别」并确认入库，也可以打开该行的「自动监控并刮削入库」。自动处理会等待文件大小和修改时间稳定，再识别并写入元数据；识别不明确、缺季集或没有唯一匹配的文件留在列表里等待「校正」。保存预览后再改识别方式、媒体库目录或元数据目录会使旧预览失效，需要重新扫描。

已有条目如果上一轮只写入了视频和 NFO、图片失败，条目会标为「已入库 · 部分附属文件未完成」。本地库页这时出现「重试未完成项」：重新识别并只补缺失的海报、背景图和剧照；已经写好的同作品 NFO 按 `uniqueid` 与季集号核对后复用，不会覆盖，也不会改动源文件。上一版取图格式不一致（WebP 字节写 `.jpg` 目标）留下的条目，启动监控时会自动放开一次补写，不必先点重试；上一版没有人物编号与头像的条目也会自动放开一次，补上头像后不再重复；已看与收藏在补写后保留。

本地库页按 Emby 媒体库的读法排成海报墙：一部作品一张卡（电影一条文件；剧集把同一 TMDB 作品的各集聚成一张），顶部是作品数与工具栏。封面悬停浮出已看、收藏、更多三颗；已看与收藏按整部作品写进本机索引，更多菜单提供播放、打开所在文件夹、重新识别并补全元数据与刷新。点一张卡直接进入现有详情页，版式与其他媒体库完全相同：演职人员头像取自 TMDB 并写进元数据目录，剧集页列出带真实集名的分集；「视频：」那一行读文件大小、分辨率、编码、音频格式与制作组；已看、收藏、更多仍在标题下方那排标准按钮里，本机不再另加一套封面图标。播放仍直接打开原文件，进度只留在本机，不向任何服务器上报。移除媒体库只停止监控、移除首页入口，源文件和已写入的元数据都保留。

## 开发验证

先按开发文档编译当前 Release Tests/Core/Shell，然后执行主测试的 `local-media-fixture`，以及 `local-media-vm-fixture <本树当前 x64 Release Momoka.dll> <本树绝对根>`、`local-library-coordinator-fixture <本树 Shell DLL> <本树根>`。前者包含临时文件的真实原地入库、NFO/图片、身份和匿名 HTTP，并用 `\\localhost\C$` 回环共享验证网络路径扫描；后两者加载实际 VM／协调器，覆盖逐行保存、确认取消、校正失效和相对路径边界。

真实 WinUI 检查入口：`Momoka.exe --probe-shell --probe-section local-media --screen 1`。检查宽窄页面、目录列表置顶、逐行保存、扫描取消与确认、元数据目录写入、两种来源切换和断线恢复。只用独立运行目录和匿名 handler，禁止服务器整理请求；与其他桌面诊断和完整主测试串行。

自动化测试不使用真实 TMDB 令牌。`C:\Users\89400\Desktop\TEST` 这类真实文件验收需要在应用里填入用户自己的 API 读访问令牌后扫描：离线用例覆盖「爱·回家之三代同糖.Like.Mother.Like.Daughter.S01E75」的季集解析、中文段关键词匹配和元数据路径，真实 TMDB 请求与播放由用户在独立运行目录里复核。
