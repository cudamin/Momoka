# 本机整理

设置 → 本机整理。源文件在运行 Momoka 的 Windows 本机磁盘上，支持电影及明确季集的电视剧单集。

识别方式可选 Momoka（直连 TMDB）或 MoviePilot。Momoka 需要 TMDB 帐号的 API Read Access Token，填入页面并保存，令牌由 Windows 加密保管；不依赖 MoviePilot。MoviePilot 使用现有连接，只提交源目录下的相对路径文本，不上传视频，也无需共享目录。实际部署的 MoviePilot 版本仍需对应接口支持。

整理方式独立选择：

| 方式 | 文件结果 |
| --- | --- |
| 直接改源文件名 | 在原目录改视频及同名字幕的名称；NFO、图片按视频名写入原目录 |
| 硬链接 | 在目标目录建立规范命名的链接；源和目标须同卷，共享视频内容 |
| 软链接 | 在目标目录建立指向源的链接；源移动或删除后链接失效，Windows 可能要求开发者模式或链接权限 |

先选择目录、扫描并识别，核对列表。识别不足时点「校正」，搜索正确作品，指定季集（特别篇为第0季），更新预览。勾选条目后确认实际视频、字幕、NFO和图片路径才执行。目标已有同名文件不覆盖；方式、来源或表单修改后旧预览失效。停止只取消后续操作，已执行文件和失败原因保留在逐项回执，不自动回滚或重试。

首版不自动监控、不处理音乐和多集范围、不触发媒体库刷新或播放。链接输出按「作品 (年份)/Season NN」组织剧集；直接改名保持原目录层级。文件系统拒绝检测到的重解析目录及非本机盘，硬链接不降级为复制。

## 开发验证

先按开发文档编译当前 Release Tests/Core/Shell，然后执行主测试的 `local-media-fixture`，以及 `local-media-vm-fixture <本树当前 x64 Release Momoka.dll> <本树绝对根>`。前者包含临时文件的真实链接/改名、XML、图片、身份和匿名 HTTP；后者加载实际 VM，覆盖确认取消、校正失效和相对路径边界。

真实 WinUI 检查入口：`Momoka.exe --probe-shell --probe-section local-media --screen 1`。检查宽窄页面、确认取消、三种方式和两种来源、断线及恢复；只用独立运行目录和匿名 handler，禁止服务器整理请求。与其他桌面诊断和完整主测试串行。源码/匿名测试不等同用户服务版本或真实媒体操作验收。
