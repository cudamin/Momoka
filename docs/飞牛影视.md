# 飞牛影视

在 Momoka 的服务器连接页填写飞牛影视地址，可以使用设备根地址、`/v` 地址或从网页复制的 `/v/login` 地址。应用自动识别服务类型，使用飞牛影视 v2 登录；保存的账号密码和令牌使用现有 DPAPI 凭据保险箱。

连接后复用 Momoka 的主页、媒体库、搜索、电影和剧集详情、收藏与播放界面。搜索按影片、节目和单集分类；列表支持名称、入库时间、上映日期与评分排序。播放器使用服务器原始媒体 Range 入口，支持续播、内嵌音轨和字幕以及进度上报。飞牛没有对应接口的 Emby 专属菜单会隐藏。

设置中的“飞牛影视”分区只对确认拥有管理权限的当前飞牛账号显示，顺序与网页一致：

| 页面 | 功能 |
| --- | --- |
| 媒体库 | 新增、编辑、移除、扫描、保存排序；授权目录选择；电影、电视节目、混合、其他视频和直播源配置；元数据、文件过滤、NFO、字幕选项 |
| 用户 | 用户列表、新增、编辑、删除、解锁；指定可访问媒体库；新用户默认权限 |
| 设置 | 名称、语言、元数据和播放临时文件存储位置、文件监控、重建搜索索引 |
| 任务计划 | 每日执行开关、媒体扫描和字幕提取任务、上次运行时间 |

按用户范围排除全部网盘功能，以及 GPU 转码、首选 GPU、CPU 解码回退。保存服务器设置前重新读取当前配置，只合并本页支持的字段，保留未编辑选项和未知字段。任务开关按官方接口发送字符串 `"1"` / `"2"`，没有额外添加网页不存在的每任务定时规则。

编辑使用草稿，保存后才写服务器；删除和索引重建包含确认。写入前再次核实管理员权限，管理请求持有捕获的身份，离页、退出和切服后不会继续提交旧页面的操作。

本次协议依据为 2026-10-15 读取的官方网页 0.9.8 / 媒体服务 0.8.43。签名、请求字段、权限及任务语义见 [飞牛协议技能](../.claude/skills/momoka-fnnas-media-api/SKILL.md)。这是版本观测，不是所有服务器版本的兼容承诺。

当前原画播放使用服务器媒体 Range 入口，不接入网盘功能。直播频道播放及外置字幕管理未接入，相关入口不显示。媒体库管理仍可维护网页支持的直播源配置。

离线验证由 `FnNasProtocolTests`、`FnNasMediaTests` 与 `--probe-shell` 的飞牛四区检查覆盖。测试使用假传输、临时账号和设置，检查登录恢复、签名、错误、分页、搜索分类、播放参数、权限撤销、保存字段和四页宽窄布局。真实服务器只进行了版本、公开配置和网页界面的只读核对；当时服务器为空库，未执行真实播放、扫描、创建或删除。
