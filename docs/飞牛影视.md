# 飞牛影视

在 Momoka 的服务器连接页填写飞牛影视地址，可以使用设备根地址、`/v` 地址或从网页复制的 `/v/login` 地址。应用自动识别服务类型，使用飞牛影视 v2 登录；保存的账号密码和令牌使用现有 DPAPI 凭据保险箱。

连接后复用 Momoka 的主页、媒体库、搜索、电影和剧集详情、收藏与播放界面。搜索按影片、节目和单集分类；列表支持名称、入库时间、上映日期与评分排序。播放器使用服务器原始媒体 Range 入口，支持续播、内嵌音轨和字幕以及进度上报。飞牛没有对应接口的 Emby 专属菜单会隐藏。

媒体库页按官方网页端补齐了三项（2026-10-19）：

- **筛选**：工具栏下方展开内联面板，分类来自 `/tag/list`，题材与地区经 `/tag/genres`、`/tag/iso3166` 显示中文。选中项按官方请求形状写入 `item/list` 的 `tags`：只有 `type` 是数组，`genres` 是单个整数，`resolution`、`color_range`、`audio_type`、`locate`、`decade`、`recognition_status`、`watched` 是单值字符串；空值不发。飞牛搜索页不显示排序与筛选，因为 `/search/list` 不吃这些参数。选中的值只在面板里高亮，收起后由按钮上的数字提示数量，不再在工具栏下方另铺一条可点的筛选标签。
- **布局**：「布局」菜单只有竖幅海报与横幅海报。横幅是 16:9 卡片：竖版海报居中、同图放大铺底，左上评分、右下清晰度，标题和年份居中；评分来自 `vote_average`，清晰度来自列表的 `media_stream.resolutions`。它只作用于飞牛，Emby／Jellyfin 的缩略图视图保持原样。
- **原生媒体库排序**：「影视服务器 → 媒体库」的「排序」为每行显示上移/下移，按屏幕顺序提交 `mdb/setSort`，写入失败回滚本地次序。
- **卡片「更多」**：照官方网页端加了管理版本、手动匹配影片、解除匹配影片、刷新元数据、编辑元数据、删除六项；原有播放、已看、收藏仍在。管理版本读 `media/itemfile`，手动匹配读写 `scrap/search`／`scrap/rescrap`，解除匹配走 `DELETE scrap/{guid}`，刷新与编辑元数据走 `item/refresh` 与 `item/getEditDetail`＋`saveEditDetail`，删除走 `DELETE item/{guid}` 并带 `delete_file`。这些请求的正文形状来自官方前端 0.9.8，**没有在真实服务器上执行写入**。

飞牛媒体库不再显示「影片 / 收藏」分段条，收藏仍可从顶栏收藏入口进入。本轮在同一台 0.9.8 / 0.8.43 真实服务器上只读核对了筛选（题材「动作」返回 14 项）、横幅/竖幅切换与原生排序界面，未播放、未写入，排序未提交。

**2026-10-19 起，飞牛影视作为唯一在线服务器时使用它自己的设置目录。** 左栏在「Momoka」之后分成两组，名字与次序照官方 0.9.8 设置抽屉：

- **帐号**：修改密码、播放偏好、外观。三项对所有已登录的飞牛账号可见。修改密码走 `/api/v2/user/passwd`，成功后同时换掉 Momoka 保存的密码与令牌；播放偏好读写服务器用户资料里的首选字幕／音频语言；外观复用 Momoka 自己的「界面」卡，不另造一套网页外观设置。
- **影视服务器**：媒体库、用户、设置、任务计划。只对 `is_admin == 1` 的账号显示，和网页端一样。四张页都是 WinUI 原生页，不是内嵌网页；媒体库与用户页的写操作、服务器设置保存与任务开关都只在用户按下保存后发生。网盘直链、GPU 转码等刻意排除的服务器设置没有接回来。

多服务器登录时，飞牛影视在设置左栏是 Momoka 组之后的一个可折叠服务器组，默认收起；展开后仍是同一个「帐号」三项与「影视服务器」四项，页面仍是 Momoka 原生页。组内入口绑定这台飞牛的账号与捕获会话：非管理员只保留修改密码、播放偏好、外观，媒体库/用户/设置/任务计划不列；其他服务器组不受影响。单服务器（独占）时的两组布局不变。飞牛影视本身仍不是一套完整的浏览界面复刻：主页、媒体库、详情与播放继续使用 Momoka 的通用版式，这一点和 Emby／Jellyfin 不同。

本次协议依据为 2026-10-15 读取的官方网页 0.9.8 / 媒体服务 0.8.43。签名与登录语义见 [飞牛协议技能](../.claude/skills/momoka-fnnas-media-api/SKILL.md)。这是版本观测，不是所有服务器版本的兼容承诺。

当前原画播放使用服务器媒体 Range 入口，不接入网盘功能。直播频道播放及外置字幕管理未接入，相关入口不显示。

离线验证由 `FnNasProtocolTests`、`FnNasMediaTests` 与 `--probe-shell` 的设置导航检查覆盖。测试使用假传输、临时账号和设置，检查登录恢复、签名、错误、重定向、分页、搜索分类、播放参数，改密码请求的 v2/SHA-256 形状与新令牌回写，播放偏好的两格语言正文，筛选与「更多」菜单的请求正文（刷新模式、删除、手动匹配的季集形状、编辑元数据的四格回写），以及飞牛左栏「帐号／影视服务器」两组、非管理员收起服务器组、六张原生页落点和「外观」落到「界面」卡。2026-10-19 在用户那台 0.9.8 / 0.8.43 服务器上只读打开并截图核对了七项页面：媒体库、用户、任务计划与播放偏好读到真实数据，设置页读到真实服务器名、语言与存储空间；同一轮还只读核对了媒体库筛选（题材「动作」→14 项）、竖幅/横幅布局与原生排序界面。本轮的验证没有提交修改密码、保存偏好、创建/删除媒体库、修改任务开关或提交媒体库排序，也没有执行「更多」菜单里的写入操作。离线测试 **1976 项全过**；发布件 `--probe-shell --probe-section library --screen 1` **13 项全过、80 项未执行**，`--probe-section moviepilot --screen 1` **22 项全过、71 项未执行**。真实播放和真实写入仍未验证。
