# 弹幕与新增快捷键

## 弹弹play 接入

1. 打开 **设置 → 弹幕**，开启「启用弹弹play」。默认关闭，不配置时不会访问弹幕服务。
2. AppId 已预填 Momoka 的公开 ID `dav282msq5`。这个 ID **不是密钥，也不表示应用已获授权**；填写经弹弹play 开发者中心批准的对应 AppSecret，点击「保存密钥」。也可填写自己的 AppId 与密钥。
3. 密钥使用 Windows DPAPI 加密，只能由本机当前 Windows 用户解密。输入框在保存成功后清空，不回填明文；加密或保存失败会提示并保留输入。配置备份不导出 AppId、密钥或服务启用状态，恢复偏好不覆盖这三项。
4. 使用内置播放器播放时，控制条与右键菜单会出现「弹幕」入口。集成模式使用播放页浮层，独占模式使用主窗口的同款面板；播放设置子菜单也可直接打开弹幕设置。
5. 自动匹配只采用**唯一且精确的作品标题**。标题有多个结果、续季或特别篇时不猜；在播放面板输入作品名称和集数，搜索后选择对应剧集，再按「加载所选剧集的弹幕」。集数留空可搜索作品的全部剧集。

这是按媒体元数据搜索的匹配，不是视频文件哈希识别；不会为计算哈希下载媒体服务器上的视频。显示设置参考 B 站：开关、不透明度、字号、速度、25%／50%／75%／全屏区域、同屏上限、滚动／顶部／底部／彩色弹幕、10 秒重复合并与屏蔽词。拥挤时丢弃放不下的评论，优先避免重叠，不承诺全部弹幕都显示。

弹幕使用独立 mpv OSD 图层，不占用主字幕或第二字幕轨。暂停、拖动进度和倍速都按视频时钟同步；新文件与新加载请求会清理旧图层并拒绝迟到数据。改外观约 100 ms 后合并下发，避免拖滑块时重复传输整库。关闭显示或切换后端不会清空偏好。**外部 mpv.exe 后端不接入弹幕**，对应入口自动隐藏；切回内置后恢复。

## 网络与安全边界

- 使用弹弹play 官方 v2 搜索与弹幕接口。仅服务开启且 AppId／密钥完整后才能请求。
- 查询发送作品名称与集数；弹幕请求发送弹幕库 ID 和是否包含关联弹幕。不发送媒体服务器地址、账号、访问令牌或视频内容。
- 使用官方签名方式，密钥不进入 URL、日志、播放器命令行或弹幕脚本。
- 官方 comment 接口可能 302 跳到弹幕加速服务：仅允许 `dandanplay.net` 官方 HTTPS 子域、标准端口、无 URL 用户信息；跨来源不传任何鉴权头。搜索接口不跟随跳转。
- 每次请求含排队和读取共用 30 秒预算；响应最多 32 MiB。每次最多解析 40,000 条普通弹幕，不支持高级脚本弹幕或发送弹幕。
- 搜索和弹幕结果缓存在本机 `cache/danmaku`，有效期两小时，最多 16 份；按应用凭据隔离。失败不缓存，不回显可能夹有敏感内容的服务端错误正文。
- 官方授权、额度、网络与内容可用性由服务提供方决定。没有正式密钥和授权时，离线测试通过不等于真实弹幕服务可用。

官方接入文档：[开放弹幕网络](https://doc.dandanplay.com/open/)，[接口规格](https://api.dandanplay.net/swagger)。

## 新增快捷键

原有 21 个快捷键默认值不变，新增以下 17 个动作；均可在设置 → 快捷键中改绑或解绑。旧用户已改过的键优先，新增默认键遇到冲突会显示为未设置，不会抢走旧绑定。弹幕服务不可用时隐藏弹幕快捷键行，偏好仍保留。

| 默认键 | 动作 |
| --- | --- |
| S | 当前尺寸截图，含字幕 |
| Shift + S | 原始尺寸截图，不含字幕 |
| V | 字幕显示开关 |
| J / Shift + J | 下一条／上一条字幕轨道 |
| A / Shift + A | 下一条／上一条音轨 |
| E / Shift + E | 前进／后退一帧，进入暂停 |
| Home | 跳到片头 |
| Shift + Backspace | 回到上次跳转前的位置 |
| Ctrl + I | 播放信息 |
| I | 显示一次播放统计 |
| Shift + I | 播放统计／着色器统计／关闭 |
| D | 弹幕显示开关 |
| Ctrl + D | 弹幕提前 0.5 秒 |
| Ctrl + Shift + D | 弹幕延后 0.5 秒 |

截图沿用设置 → 播放行为 → 截图中的保存目录和格式。弹幕时间偏移只影响当前视频，不持久化到下一集。

设置 → 关于新增「如果你喜欢本项目就点个星星吧」与 GitHub 入口，只打开项目仓库，不代替用户执行 Star。

```powershell
# 先编译正式测试，再运行，参数按 CLAUDE.md。

& "$HOME/.dotnet/dotnet.exe" run --project ./tests/Momoka.Tests/Momoka.Tests.csproj -c Release --no-build

# 新输出目录必须不存在；使用随包 libmpv 的 Lua，无媒体、窗口、HTTP 或用户设置。
py tools/test-danmaku.py --output work/danmaku-lua-new
py tools/test-uosc.py --output work/uosc-new

# 正式 Shell 隔离假身份/假网络界面检查，含宽窄设置、密钥控件、显隐与过期面板。

# 实际集成图层与字幕独立性使用本地媒体，遵守现有本地素材边界。

```

运行结果必须以当前报告为准。集成图层本地探针不覆盖独占真实视频窗口、独占同窗换片或外部 mpv；Lua 回归只验证状态与算法，不能冒充对应管线的真实播放。正式服务认证与真实媒体服务器播放需分别授权与验证。
