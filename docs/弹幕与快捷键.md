# 弹幕与新增快捷键

## 弹弹play 接入

1. 打开 **设置 → 弹幕**，开启「启用弹幕」。默认关闭；来源默认是 **两者合并**，未配置 danmu_api 时仍可使用弹弹play。弹弹play使用 **Momoka 内置凭据**，普通用户不需要申请开发者密钥。
2. 内置凭据由 Momoka 的凭据端点（`website/worker` 的 `/api/danmaku/credential`）下发：HTTPS、AES-GCM 加密，客户端解密后用 DPAPI 缓存，到期前自动换新。端点只返回应用凭据，不参与搜索和弹幕请求；作品名称、集数与弹幕仍直接发往 `api.dandanplay.net`。
3. 应用凭据一律由 Momoka 统一提供：设置页没有 AppId／AppSecret 输入框，也没有开发者中心入口，用户不需要申请弹弹play 应用。2026-10-27 起「使用自己的应用凭据」这条能力已整条退役，旧配置里保存过的自定义 AppId 与密钥不再读取，也不会被导出或恢复。服务启用状态仍属于本机连接，配置备份不导出、恢复偏好不覆盖。
4. **内置凭据是共享额度，不是保密方案。** 基础层搜索与获取弹幕各日 100／月 2,400，发送弹幕日 10／月 240（2026-10-25 后台确认，实际以开发者中心为准）；额度用尽时会返回频率限制提示，等额度恢复后再试。密钥随客户端分发，愿意动手的人仍能提取，它只避免把 AppSecret 写进公开仓库，并允许服务端轮换。
5. 使用内置播放器播放时，控制条与右键菜单会出现「弹幕」入口。集成模式使用播放页浮层，独占模式使用主窗口的同款面板；播放设置子菜单也可直接打开弹幕设置。
6. 自动匹配只采用**能确认的作品与集数**：第一季及以上、集号为正的单集会按作品名和集数搜索，续季再用标题里的季标记（第二季／第2季／Season 2／2nd Season／S3 等）核对。标题有多个结果、季标记缺失或对不上、特别篇时不猜；在播放面板输入作品名称和集数，搜索后选择对应剧集，再按「加载所选剧集的弹幕」。集数留空可搜索作品的全部剧集。服务端提示结果未完整返回或本地达到结果上限时，不自动匹配，提示细化片名或集数。

这是按媒体元数据搜索的匹配，不是视频文件哈希识别；不会为计算哈希下载媒体服务器上的视频。设置页把这一套拆成四张卡：「弹幕」管启用与匹配，「来源与聚合」管来源、自部署地址、令牌与合并，「显示与外观」管开关、输入栏和画面上的大小疏密，「类型与屏蔽」管哪几种弹幕与屏蔽词。显示设置参考 B 站：开关、不透明度、字号、速度、25%／50%／75%／全屏区域、同屏上限、滚动／顶部／底部／彩色弹幕、10 秒重复合并与屏蔽词。拥挤时丢弃放不下的评论，优先避免重叠，不承诺全部弹幕都显示。

弹幕使用独立 mpv OSD 图层，不占用主字幕或第二字幕轨。新文件与新加载请求会清理旧图层并拒绝迟到数据。改外观约 100 ms 后合并下发，避免拖滑块时重复传输整库。关闭显示或切换后端不会清空偏好。**外部 mpv.exe 后端不接入弹幕**，对应入口自动隐藏；切回内置后恢复。

### 显示与外观控制（2026-11-04）

设置中启用弹幕后，集成播放页和独占窗口都提供一键开启／关闭弹幕的按钮，原弹幕按钮继续打开选择和外观面板。关闭「显示弹幕」时保留按钮，以便随时恢复；关闭全局「启用弹幕」后，播放按钮、输入栏、右键弹幕功能和播放设置里的弹幕入口一起隐藏。设置中的启用入口始终可达。

设置页与播放面板使用同一份本机偏好，支持随窗口缩放（关闭时固定像素字号）、字幕可见时预留底部20%、本地避免弹幕重叠和追尾、正常／较多／重叠三档密度、倍速跟随开关、本机字体与粗体、描边／重墨／45°投影。密度三档均受同屏上限约束；重叠档隐藏无效的防重叠开关，切回其他档恢复原偏好。速度默认随播放倍数；关闭跟随时补偿播放倍数以保持移动速度。

### 进度条弹幕热力（2026-11-14）

启用弹幕并成功加载后，集成播放页的进度条会按已加载弹幕的时间密度画一条低透明度热力条：越热闹的时段越高，底对齐，不改变拖动、点击跳转和缓存条纹。悬停进度条时，章节预览里会多一行「此处约 N 条弹幕」，按指针前后各 2.5 秒统计；附近没有弹幕时不显示这一行。热力只统计已加载弹幕，不受颜色、类型和屏蔽词影响，也不额外请求弹弹play 或 danmu_api，不消耗额度。关闭「显示弹幕」或设置 → 弹幕 →「在进度条显示弹幕热力」后收起；独占 uosc 时间轴不显示这条热力。

屏蔽词在设置页和播放面板之间同步保存同一份本机列表，未接入平台账号或远端屏蔽列表；「智能防挡」指本地防重叠，不包含人物识别。「恢复弹幕外观默认」只重置外观，保留启用、显示、来源连接、匹配、类型及屏蔽词。当前只接受普通滚动、顶部、底部弹幕，高级模式仍在解析与渲染边界过滤，不显示不会生效的高级开关。

## danmu_api 自部署来源（2026-11-02）

**待对齐的实现边界：** 当前 `DanmuApiEndpoint.TryCreate` 仍会把非空访问令牌拼入 URL 路径，与 [CLAUDE「凭据」](../CLAUDE.md#凭据)的全域规则冲突。下列路径令牌说明记录已有实现，不构成安全例外；该模式须另行修复并验证，不能按这段旧接入说明扩展使用。本次文档整理没有修改产品行为。

1. 来源模式有三档：**弹弹play**、**danmu_api**、**两者合并**。当前默认是两者合并；danmu_api 需要用户自己部署，未配置时合并模式仍可使用弹弹play。Momoka 不提供公共 danmu_api 地址、共享凭据或代理。
2. 在「来源与聚合」里填写服务根地址（例如 `http://192.168.1.10:9321`）和可选访问令牌。地址不带令牌；令牌单独填写，用 Windows DPAPI 加密保存在本机，不进入配置备份，也不回填明文。上游默认 TOKEN 配置允许兼容无令牌请求；服务端自定义 TOKEN 后必须填写。
3. 请求与弹弹play v2 兼容：搜索 `/api/v2/search/episodes`、弹幕 `/api/v2/comment/{episodeId}`。danmu_api 的令牌按协议放在 URL 路径段里，客户端不签名、不跟随跳转；日志、状态和错误不显示令牌，缓存文件名使用摘要。当前客户端需要 JSON，服务端应保持 `DANMU_OUTPUT_FORMAT=json`。
4. 自动匹配使用 `POST /api/v2/match`，片名带 Emby 年份与季集号；返回后核对集标题里明确写出的集号，和当前 `IndexNumber` 不一致就不用，退回手动选择。第 1 季及以后的单集都会自动请求，季号由文件名携带；特别篇仍不自动匹配。
5. 合并模式在客户端合并两源：分别匹配、分别取弹幕，按时间排序后交给现有过滤（相同文本 10 秒内去重），最多 40,000 条。一个来源读取失败时保留另一个并显示警告；手动搜索与加载一次只选择一个来源，会替换当前结果。缓存按来源、地址和令牌摘要隔离，弹弹play 与 danmu_api 的 `episodeId` 不会串数据。
6. 发送弹幕只支持弹弹play：纯 danmu_api 模式隐藏输入栏；合并模式可开启输入栏并标注「发到弹弹play」，但必须成功加载弹弹play库才能发送，danmu_api 侧不会出现这条弹幕。
7. 合并模式会同时请求两个来源，每集消耗弹弹play 一次搜索/匹配与一次取弹幕额度（命中两小时缓存时除外）。不想消耗共享额度时选 danmu_api 单源，或不要打开合并。
8. 限流取决于用户部署配置。已核对的上游版本在弹幕读取缓存未命中时，默认按 IP 每分钟最多 3 次；缓存命中跳过该计数，不能把它当作所有接口统一限额。
9. 实机验收覆盖集成与独占两条内置管线，用用户自己的 danmu_api 和 Emby 条目真实播放；离线探针与单测不能代替真实播放、真实服务器或真实令牌。

## 网络与安全边界

- 使用弹弹play 官方 v2 搜索与弹幕接口。仅服务开启后才能请求；第一次使用时会先向 Momoka 的凭据端点取一次密钥。
- 内置凭据端点主要看到请求时间、IP 与 `Momoka/版本` 的 User-Agent（HTTP 栈可能附带标准 Accept／编码头），不发送作品名称、集数、媒体服务器信息或弹幕内容；真正的搜索与弹幕请求仍由客户端直连 `api.dandanplay.net`。
- 查询发送作品名称与集数；弹幕请求发送弹幕库 ID 和是否包含关联弹幕。不发送媒体服务器地址、账号、访问令牌或视频内容。
- 使用官方签名方式，密钥不进入 URL、日志、播放器命令行或弹幕脚本；内置凭据只在本机内存与 DPAPI 缓存中出现。
- 官方 comment 接口可能 302 跳到弹幕加速服务：仅允许 `dandanplay.net` 官方 HTTPS 子域、标准端口、无 URL 用户信息；跨来源不传任何鉴权头。搜索接口不跟随跳转。
- 每次请求含排队和读取共用 30 秒预算；响应最多 32 MiB。每次最多解析 40,000 条普通弹幕，不支持高级脚本弹幕。
- 搜索和弹幕结果缓存在本机 `cache/danmaku`，有效期两小时，最多 16 份；按应用凭据隔离。内置凭据缓存在同一目录的 `builtin-credential.bin`，DPAPI 加密，到期前自动换新。失败不缓存，不回显可能夹有敏感内容的服务端错误正文。
- 内置凭据端点不可用时，未到期的缓存仍可继续使用；弹弹play 返回 401/403 时客户端会丢掉缓存、换一份凭据重试一次（发送不自动重试，避免重复写入）。
- 官方授权、额度、网络与内容可用性由服务提供方决定。内置凭据是 Momoka 应用在弹弹play 后台的基础层级凭据；服务端轮换、额度变化或审核状态变化都可能影响可用性，离线测试通过不等于真实服务始终可用。
- 基础搜索和读取弹幕使用应用签名，不要求用户 OAuth 登录；开发者中心里的回调地址不参与这两条请求，用户也不需要持有任何应用密钥。
- 2026-10-25 应用后台确认的基础额度：搜索与获取弹幕各日 100／月 2,400，番剧详情与文件识别各日 200／月 4,800，发送弹幕日 10／月 240。内置模式下所有用户共享这一份额度，同一 AppId 的不同用户和设备不要各自当作一份；实际剩余量以开发者中心为准。当前使用搜索、获取弹幕及用户主动发送。
- 相同请求在两小时内使用缓存，并发相同请求也只下载一次；失败不自动重试。不开启额外的启动连接探测或定时额度查询。官方未公开剩余额度查询接口、重置时区及统一瞬时速率，客户端不显示猜测的剩余额度。


### 发送弹幕

播放器顶部影片标题右侧提供输入栏，支持回车或「发送」，普通白色滚动弹幕最多 100 个 UTF-16 字符。先选择并成功加载当前弹幕库才能发送；正在发送时不会接受第二次提交，成功后清空原草稿，失败保留。发送时间取点击时视频时间减去当前弹幕延迟，下限为零。

设置 → 弹幕 →「显示弹幕输入栏」默认关闭，可按需开启。关闭它只隐藏输入栏，不影响观看弹幕；关闭弹幕显示或整个服务也会隐藏。重新开启保留偏好及当前视频草稿，切换视频清空草稿，切换弹幕库保留草稿；两者都会隔离旧回执。集成模式与独占模式均支持；输入时播放快捷键让路。

发送使用官方 POST /api/v2/comment/{episodeId}/app，无需用户登录，只保存到本应用的私有弹幕库；不会发送到其他应用的弹幕库。基础层的发送额度仅供测试使用。请求不跟随重定向、不自动重试；超时等未确认结果可能已经送达，避免立即重复发送。确认成功后把评论加入当前本地列表，并使该库缓存失效，不自动再消耗一次获取额度。

登录可能用于以后同步关注与观看历史，但公开文档尚未明确基础层用户权限及完整第三方 OAuth 流程，当前未增加登录入口；应用签名即可使用上述弹幕功能。

官方接入文档：[开放弹幕网络](https://doc.dandanplay.com/open/)，[接口规格](https://api.dandanplay.net/swagger)。

| Alt + G | pgs 字幕灰度转换 |
| R | 重载当前字幕 |

PGS/VobSub 是位图字幕，mpv 没有像 `sub-ass-force-margins`／`sub-use-margins` 那样的图形字幕黑边开关；「输出到黑边」用的是 `stretch-image-subs-to-screen`（把图形字幕画布铺到整屏，画面比 16:9 更宽时字幕因此落进黑边，代价是字幕会被拉伸）。灰度用 `sub-gray`，只作用于图形字幕，不改文本字幕。两项都只在本次播放内有效，换片按现有逐片状态复位，不写入设置。

设置 → 关于新增「如果你喜欢本项目就点个星星吧」与 GitHub 入口，只打开项目仓库，不代替用户执行 Star。

### 任意按键、冲突替换与音量条反馈（2026-11-21）

录入范围放开到「键盘上能送到应用的键」：字母、数字、F1–F24、方向键与导航键、小键盘（含小键盘回车、方向键和运算符）、标点与 OEM 键、CapsLock／NumLock／ScrollLock、PrintScreen／Pause、媒体键和浏览器键都能作为单键或组合键。没有稳定名字的厂商键、输入法键和部分布局键保存为 `VkXX`，设置页显示「按键 XX」，集成播放页照常派发；内置独占窗口只在 mpv 有对应键名时生效（媒体键、小键盘和常用标点可以，`VkXX`、Win 键等没有 mpv 键名的键不会写进独占窗口）。Win 键、Alt+Tab、Ctrl+Alt+Delete 等组合由系统保留，应用收不到，不能录入。

Esc、回车和 Delete 不再是不可改的固定键。没有用户绑定时它们保留原行为：Esc 在全屏时退出全屏、否则停止；出现跳过提示时回车确认跳过、Delete 关闭提示。把任意动作绑到这些键后，绑定动作优先，原来的固定行为让路。捕获框里的 Esc 会当作要绑定的键，退出捕获请点方框外让焦点离开。

快捷键页在可改动作列表末尾仍列出三条只读说明行：退出全屏 / 退出播放＝Esc、确认跳过片头 / 片尾＝回车、关闭跳过片头 / 片尾提示＝Del。它们不参与改绑，也不计入「可改快捷键」数量；搜索能按名称或这三个键命中。说明行写的是上面那条回退规则，不是第二份可编辑绑定。

改绑撞到已占用的键时弹出「替换快捷键」确认：确认后新动作拿到该键，原占用者改用新动作原来的键；新动作原来没有键时，原占用者变为「未设置」。取消、点外关闭或按窗口关闭都不会改动任何绑定。

音量增大／减小／静音快捷键只亮音量条，不再把整套播放控件叫出来；自定义按键、Ctrl + ↑／↓ 和独占窗口（通过 uosc 的 `flash-elements volume`）一致。音量条不显示或只显示一部分时，先确认焦点不在音量滑条上：未改绑的方向键仍归滑条自己调整。

### 快捷键页分区与步长（2026-11-24）

快捷键页按动作归组拆成十三张卡，次序就是阅读次序：

1. 播放与进度：播放／暂停、四颗方向键的快退快进（含大步与精细）、逐帧、片头与回跳、跳到静音位置。
2. 播放控制：音量、静音、全屏、置顶、窗口不在前台时的画面单击、播放信息与 OSD、统计。
3. 集数与章节：上一集／下一集、章节跳转，以及标记、改名、删除与导出章节。
4. 速度与循环：调速、恢复常速、固定倍速、A-B 片段与单片循环。
5. 字幕：主字幕开关、挑轨、延迟、按字幕跳转、缩放、位置、渲染样式、时序修复、重载与字体。
6. 次字幕与兼容性：第二字幕轨，ASS／SRT／PGS 黑边、PGS 灰度、混合、颜色兼容、视频数据、双向文本与描边缩放。
7. 音轨与音频：挑轨、音频延迟、声道、响度均衡、滤镜、直通输出与精确跳转丢帧。
8. 画面与缩放：宽高比、缩放、平移、旋转、裁切、归零与去黑边检测。
9. 画质与色彩：对比度／亮度／伽马／饱和度／色相、去色带、HDR、ICC 与非线性缩放。
10. 视频与滤镜：视频轨、插值同步、反交错、翻转、同步模式与各项视频滤镜。
11. 截图：当前／原始／窗口／字幕截图与逐帧截图。
12. 弹幕：弹幕开关与时间偏移；服务关着或后端画不出弹幕时整张收起，绑定保留。
13. 回退键与恢复默认：三条只读回退键说明行与「恢复默认快捷键」。

`ShortcutCatalog` 以后新加的动作如果没有归组，会落在末尾自动出现的「其他」卡里，不会从页面上消失。分区只改展示，不改绑定、搜索与恢复默认的语义：搜索仍按动作名称或当前按键过滤，命中的卡留下、其余收起；搜索步长名称（如「快进跨度」）会带出它上面那颗快捷键。

四行步长（快退／快进／大步快退／大步快进）是缩进一档的从属行，紧跟在各自的方向键快捷键行下面，说明写「← 键跳这么多秒」这类。数值仍住在 `PlaybackSettings` 的 `SeekBackwardSeconds`／`SeekForwardSeconds`／`SeekBackwardLongSeconds`／`SeekForwardLongSeconds`，集成模式与内置独占窗口共用；改完下一次按键就生效，与快捷键改绑一样立即保存。它们不是快捷键，不参与改绑，也不计入「可改快捷键」数量。

「快退」「快进」下面各还有一行倍率附注：**快退跨度（倍）** 与 **快进跨度（倍）**（各是 2～10，装机默认 2）。说明分别是「长按箭头以这个倍速快退」和「长按箭头以这个倍速播放」。单击 ← / → 仍只跳上面那行秒数；按住超过约半秒后，→ 改为按快进倍率播放，松手回到按下之前的速度（不是回到 1×）；← 不改播放速度，按快退倍率把进度连续往回推（每 200ms 走「倍率 × 0.2 秒」）。两格分开保存，可以把回退和正放调成不同的倍率。判定按住与否问的是键盘本身（`GetAsyncKeyState`），所以松开、焦点跑掉、停止播放都不会卡在倍速上。两条管线同一套判据：集成模式听 KeyDown／KeyUp，内置独占窗口听 mpv 转发的 `momoka-shortcut`。大步、精细与逐帧不吃长按。数值住在 `PlaybackSettings.SeekBackwardHoldMultiplier` 与 `SeekForwardHoldMultiplier`。
