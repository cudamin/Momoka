# 弹幕与新增快捷键

## 弹弹play 接入

1. 打开 **设置 → 弹幕**，开启「启用弹弹play」。默认关闭；开启后默认使用 **Momoka 内置凭据**，普通用户不需要申请开发者密钥。
2. 内置凭据由 Momoka 的凭据端点（`website/worker` 的 `/api/danmaku/credential`）下发：HTTPS、AES-GCM 加密，客户端解密后用 DPAPI 缓存，到期前自动换新。端点只返回应用凭据，不参与搜索和弹幕请求；作品名称、集数与弹幕仍直接发往 `api.dandanplay.net`。
3. 应用凭据一律由 Momoka 统一提供：设置页没有 AppId／AppSecret 输入框，也没有开发者中心入口，用户不需要申请弹弹play 应用。2026-10-27 起「使用自己的应用凭据」这条能力已整条退役，旧配置里保存过的自定义 AppId 与密钥不再读取，也不会被导出或恢复。服务启用状态仍属于本机连接，配置备份不导出、恢复偏好不覆盖。
4. **内置凭据是共享额度，不是保密方案。** 基础层搜索与获取弹幕各日 100／月 2,400，发送弹幕日 10／月 240（2026-10-25 后台确认，实际以开发者中心为准）；额度用尽时会返回频率限制提示，等额度恢复后再试。密钥随客户端分发，愿意动手的人仍能提取，它只避免把 AppSecret 写进公开仓库，并允许服务端轮换。
5. 使用内置播放器播放时，控制条与右键菜单会出现「弹幕」入口。集成模式使用播放页浮层，独占模式使用主窗口的同款面板；播放设置子菜单也可直接打开弹幕设置。
6. 自动匹配只采用**唯一且精确的作品标题**。标题有多个结果、续季或特别篇时不猜；在播放面板输入作品名称和集数，搜索后选择对应剧集，再按「加载所选剧集的弹幕」。集数留空可搜索作品的全部剧集。服务端提示结果未完整返回或本地达到结果上限时，不自动匹配，提示细化片名或集数。

这是按媒体元数据搜索的匹配，不是视频文件哈希识别；不会为计算哈希下载媒体服务器上的视频。设置页把这一套拆成三张卡：「弹幕」管启用与匹配，「显示与外观」管开关、输入栏和画面上的大小疏密，「类型与屏蔽」管哪几种弹幕与屏蔽词。显示设置参考 B 站：开关、不透明度、字号、速度、25%／50%／75%／全屏区域、同屏上限、滚动／顶部／底部／彩色弹幕、10 秒重复合并与屏蔽词。拥挤时丢弃放不下的评论，优先避免重叠，不承诺全部弹幕都显示。

弹幕使用独立 mpv OSD 图层，不占用主字幕或第二字幕轨。暂停、拖动进度和倍速都按视频时钟同步；新文件与新加载请求会清理旧图层并拒绝迟到数据。改外观约 100 ms 后合并下发，避免拖滑块时重复传输整库。关闭显示或切换后端不会清空偏好。**外部 mpv.exe 后端不接入弹幕**，对应入口自动隐藏；切回内置后恢复。

## 网络与安全边界

- 使用弹弹play 官方 v2 搜索与弹幕接口。仅服务开启后才能请求；第一次使用时会先向 Momoka 的凭据端点取一次密钥。
- 内置凭据端点主要看到请求时间、IP 与 `Momoka/版本` 的 User-Agent（HTTP 栈可能附带标准 Accept／编码头），不发送作品名称、集数、媒体服务器信息或弹幕内容；真正的搜索与弹幕请求仍由客户端直连 `api.dandanplay.net`。
- 查询发送作品名称与集数；弹幕请求发送弹幕库 ID 和是否包含关联弹幕。不发送媒体服务器地址、账号、访问令牌或视频内容。
- 使用官方签名方式，密钥不进入 URL、日志、播放器命令行或弹幕脚本；内置凭据只在本机内存与 DPAPI 缓存中出现。
- 官方 comment 接口可能 302 跳到弹幕加速服务：仅允许 `dandanplay.net` 官方 HTTPS 子域、标准端口、无 URL 用户信息；跨来源不传任何鉴权头。搜索接口不跟随跳转。
- 每次请求含排队和读取共用 30 秒预算；响应最多 32 MiB。每次最多解析 40,000 条普通弹幕，不支持高级脚本弹幕。
- 搜索和弹幕结果缓存在本机 `cache/danmaku`，有效期两小时，最多 16 份；按应用凭据隔离。内置凭据缓存在同一目录的 `builtin-credential.bin`，DPAPI 加密，到期前自动换新。失败不缓存，不回显可能夹有敏感内容的服务端错误正文。
- 内置凭据端点不可用时，未到期的缓存仍可继续使用；弹弹play 返回 401/403 时客户端会丢掉缓存、换一份凭据重试一次（发送不自动重试，避免重复写入）。
- 官方授权、额度、网络与内容可用性由服务提供方决定。内置凭据是 Momoka 应用在弹弹play 后台的基础层级凭据；服务端轮换、额度变化或审核状态变化都可能影响可用性，离线测试通过不等于真实服务始终可用。
- 基础搜索和读取弹幕使用应用签名，不要求用户 OAuth 登录；开发者中心里的回调地址不参与这两条请求，用户也不需要持有任何应用密钥。
- 2026-10-25 应用后台确认的基础额度：搜索与获取弹幕各日 100／月 2,400，番剧详情与文件识别各日 200／月 4,800，发送弹幕日 10／月 240。内置模式下所有用户共享这一份额度，同一 AppId 的不同用户和设备不要各自当作一份；实际剩余量以开发者中心为准。当前使用搜索、获取弹幕及用户主动发送。
- 相同请求在两小时内使用缓存，并发相同请求也只下载一次；失败不自动重试。不开启额外的启动连接探测或定时额度查询。官方未公开剩余额度查询接口、重置时区及统一瞬时速率，客户端不显示猜测的剩余额度。


### 发送弹幕

播放器顶部影片标题右侧提供输入栏，支持回车或「发送」，普通白色滚动弹幕最多 100 个 UTF-16 字符。先选择并成功加载当前弹幕库才能发送；正在发送时不会接受第二次提交，成功后清空原草稿，失败保留。发送时间取点击时视频时间减去当前弹幕延迟，下限为零。

设置 → 弹幕 →「显示弹幕输入栏」默认开启。关闭它只隐藏输入栏，不影响观看弹幕；关闭弹幕显示或整个服务也会隐藏。重新开启保留偏好及当前视频草稿，切换视频或弹幕库清空草稿并隔离旧回执。集成模式与独占模式均支持；输入时播放快捷键让路。

发送使用官方 POST /api/v2/comment/{episodeId}/app，无需用户登录，只保存到本应用的私有弹幕库；不会发送到其他应用的弹幕库。基础层的发送额度仅供测试使用。请求不跟随重定向、不自动重试；超时等未确认结果可能已经送达，避免立即重复发送。确认成功后把评论加入当前本地列表，并使该库缓存失效，不自动再消耗一次获取额度。

登录可能用于以后同步关注与观看历史，但公开文档尚未明确基础层用户权限及完整第三方 OAuth 流程，当前未增加登录入口；应用签名即可使用上述弹幕功能。

官方接入文档：[开放弹幕网络](https://doc.dandanplay.com/open/)，[接口规格](https://api.dandanplay.net/swagger)。

## 新增快捷键

原有 21 个快捷键默认值不变，新增以下 17 个动作；均可在设置 → 快捷键中改绑或解绑。旧用户已改过的键优先，新增默认键遇到冲突会显示为未设置，不会抢走旧绑定。弹幕服务不可用时隐藏弹幕快捷键行，偏好仍保留。

| 默认键 | 动作 |
| --- | --- |
| S | 当前尺寸截图，含字幕 |
| Shift + S | 原始尺寸截图，不含字幕 |
| V | 字幕显示开关 |
| J / Shift + J | 下一条／上一条字幕轨道 |
| A / Shift + A | 下一条／上一条音轨 |
| E / Shift + E | 前进／后退一帧，进入暂停 |
| Home | 跳到片头 |
| Shift + Backspace | 回到上次跳转前的位置 |
| Ctrl + I | 播放信息 |
| I | 显示一次播放统计 |
| Shift + I | 播放统计／着色器统计／关闭 |
| D | 弹幕显示开关 |
| Ctrl + D | 弹幕提前 0.5 秒 |
| Ctrl + Shift + D | 弹幕延后 0.5 秒 |

截图沿用设置 → 播放行为 → 截图中的保存目录和格式。弹幕时间偏移只影响当前视频，不持久化到下一集。

### 更多快捷键与搜索（2026-10-26）

再增加 25 个动作，总计 63 个可改绑快捷键。原有 38 个动作的默认键不变；升级新增键仍优先保留已有自定义绑定，冲突的新动作显示为「未设置」。弹幕服务未配置或不可用时隐藏四个弹幕动作，但保留绑定。

| 默认键 | 动作 |
| --- | --- |
| Shift + ← / → | 精细快退／快进 1 秒 |
| Ctrl + ← / → | 跳到上一句／下一句字幕 |
| Ctrl + [ / ] | 画面缩小／放大 |
| Ctrl + 0 | 画面缩放归零 |
| Alt + ← / → / ↑ / ↓ | 画面左移／右移／上移／下移 |
| Ctrl + Home | 画面位置归零 |
| Alt + [ / ] | 字幕缩小／放大 |
| Shift + ↑ / ↓ | 字幕上移／下移 |
| Ctrl + Z / X | 字幕／音频延迟归零 |
| L | 设置 A 点、设置 B 点、清除片段循环（依次循环） |
| Shift + L | 直接清除片段循环 |
| Ctrl + L | 单片循环播放开关 |
| Ctrl + 1 / 2 / 3 | 切换到 0.5／1.5／2 倍速 |
| Shift + D | 弹幕延迟归零 |

快捷键页面顶部新增即时搜索，支持操作名称、当前生效的按键和按键别名；英文大小写、加号周围空格不影响匹配，例如「字幕」「Ctrl + ↑」「ctrl+up」「未设置」。多个关键词以空格分隔，全部匹配才显示；Esc 和回车的固定动作也能搜索。改绑后立即使用新键参与搜索，不再按旧默认键匹配。清空搜索恢复完整列表，切换分类保留搜索词。

搜索仅过滤显示，不修改偏好。「恢复默认快捷键」始终保留，恢复所有快捷键，包括搜索隐藏的项目，不影响其他设置。没有匹配项时显示空结果说明。调整画面、字幕、循环与延迟沿用播放器本次运行的行为，不新增持久化选项；跳字幕需当前字幕轨可提供相应时间点。

新增动作由集成页与内置独占窗口共用处理器。复位多条命令顺序执行、拒绝时显示失败回执，排队期间切换播放身份会丢弃旧动作。独占 uosc 的连续调整支持长按，复位、循环与固定倍速不长按重复；菜单或弹幕输入框占用键盘时仍让路。


设置 → 关于新增「如果你喜欢本项目就点个星星吧」与 GitHub 入口，只打开项目仓库，不代替用户执行 Star。
