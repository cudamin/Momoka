# 打格子

「设置 → 打格子」包含 Bangumi 和豆瓣两张卡，默认关闭。启用并配置后，所有媒体服务器账号播放影视单集时都会自动识别作品并尝试同步；不需要填写媒体服务器用户名或手动添加作品关联。音乐不参与同步。

## 配置

Bangumi 填写官方 [Access Token](https://next.bgm.tv/demo/access-token)。令牌需要收藏写入权限，经 ISecretProtector 加密保存在本机，保存后不回填明文。

豆瓣使用 Momoka 内的登录窗口。登录与自动标记共用 WebView2 豆瓣独立配置；Cookie 由 WebView2 自管，不复制到设置、HTTP 客户端或日志。系统浏览器的登录不会同步进来。切换登录、退出或修改配置会撤销旧播放场次的待办同步。

进入设置、保存密钥、完成豆瓣登录或退出后，会自动只读验证已启用站点。Bangumi 卡显示密钥是否有效，豆瓣卡显示已登录或未登录；检查中、未配置和网络／页面识别失败分别显示，也可点击「重新验证」。关闭登录窗口本身不代表登录成功。验证不修改收藏，Bangumi 身份验证成功也不代表已实测写入权限。旧配置、旧页面或较早的检查结果不能覆盖新状态。

## 自动匹配

播放时先读取当前媒体库剧集的 Bangumi／豆瓣编号；有对应编号时优先核对并使用。没有编号时，只有候选标题经规范化后精确一致、年份一致，且最终只剩一个候选，才会自动采用；随后还会读取站点条目详情，确认站点总集数与媒体库一致后才同步。标题候选不唯一、年份缺失／不一致、站点总集数缺失／不一致或查询失败时跳过该站点同步，不会凭相似标题猜作品。每张站点卡的「查看记录」按站点分别显示当前应用运行期间的自动匹配、跳过、失败和标记结果，每站最多保留 100 条；离开设置页会关闭记录弹窗，关闭 Momoka 后记录清空。

自动换算集号目前只接受完整的单季度剧集：该剧只有一个非特别篇季度，媒体库集号从 1 开始连续递增、没有重复／缺失／合并集，并且当前播放集确实属于该季。多季度、特别篇、拆季、集号不连续或元数据不完整时，无法安全对应站点集号，会跳过同步。媒体库已有的站点编号不会改变这项集号核验要求。

## 播放与同步

- 豆瓣在实际起播后标记「在看」；已有「看过」不会降回「在看」。
- 达到「播放行为 → 标记已看进度」即算完成，国漫使用国漫专属百分比；不要求自然播到片尾。完成判断独立于媒体服务器进度上报开关。
- Bangumi 达到完成进度后，按自动换算出的对应集号标记单集「看过」。已有作品收藏状态、评分、评论及已看单集保持原样；未收藏作品先建立在看收藏。
- 豆瓣只有在公开条目信息确认对应单集为最后一集、且实际进度达到完成门槛时才标记「看过」。总集数未知或无法确认时不标记完成；媒体库当前最大集号不参与完结判断。
- 同一场起播与完成串行、各一次；停止时只补真实位置，EOF 不给第三方补满进度。账号退出、配置更改和旧回调受原始作用域及配置代次限制。第三方失败不改变播放结果，可在设置卡状态行查看结果。

豆瓣提交先读取站点返回的收藏表单，保留评分、短评、标签及隐私，去掉分享控制；所有请求留在豆瓣同源页面内。表单地址、页面来源或字段不能确认时停止同步。网页流程可能变化，失败时需要重新登录或等待适配。

## 实现与依据

Core ScrobblingService 在播放场次内读取媒体库剧集及季度集号，并按严格唯一规则寻找站点条目；PlaybackScrobblingAttempt 接受实际起播和进度。BangumiClient 负责固定 API 来源的认证请求及动画条目搜索，连接验证只读 v0/me。Shell DoubanSession 在 UI 线程按任务创建 WebView、完成后关闭，共享独立登录配置；豆瓣剧集候选只从其搜索页面提取公开作品信息，登录验证只从可信首页读取导航身份标志，Cookie 留在 WebView 内。设置页提供启用、Bangumi 令牌、豆瓣登录及独立的连接／同步状态。

豆瓣登录判定核对 2026-11-26 匿名首页及[导航脚本 2.0.1](https://asset.doubanio.com/cuphead/nav/2.0.1/shire/bundle.js) 的 _GLOBAL_NAV.USER_ID、.nav-user-account .bn-more 和 nav-login：有效身份与账号入口共同存在才视为已登录，明确的官方登录入口才视为未登录；缺失或冲突视为验证失败。

Bangumi 接口核对至 [server ae5861f1](https://github.com/bangumi/server/tree/ae5861f1b7a91363d0e34b419a28913b7e654fbd) 的 web/routes.go、web/handler/user/update_episode_collection.go、ctrl/update_episode_progress.go 及 OpenAPI：未收藏时创建在看，单集通过 PATCH 修改。豆瓣流程依据本站 Douban.init_collect_btn / remote_submit_json，来源为[站点脚本](https://asset.doubanio.com/cuphead/vendors/js/douban.751471eacdfd.js)；网页接口不是公开稳定 API。

## 验证

先编译当前 Release Shell 与测试工程，再运行测试程序的 scrobbling-fixture；其中协议和播放用例同时纳入默认 Momoka.Tests 主套件。豆瓣脚本独立入口为 tools/test-scrobbling-dom.ps1，执行当前生产代码生成的脚本；不需要额外浏览器或 npm 依赖。命令见[开发与验证](开发与验证.md#打格子离线验证)。

设置卡和设置搜索由 settings-page-state-fixture、settings-search-fixture 及当前 Shell DLL 路径覆盖。离线用例执行生产状态机、服务、假播放句柄、假 HTTP 和实际生成的 JavaScript；DOM 为模拟，不能替代真实 WebView2、登录或写后读回。本次临时分支本地体验发布已刷新对应桌面快捷方式；真实 Bangumi／豆瓣登录、第三方写入、真实服务器播放和设置页实屏验收仍待统一验证。
