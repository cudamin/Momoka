# 打格子

在「设置 → MoviePilot」中可以分别启用 Bangumi 和豆瓣，两站默认关闭。播放影视剧时，Momoka 用本次播放所属的媒体账号读取信息，并通过 MoviePilot 识别作品。豆瓣按作品标记，Bangumi 按常规单集同步。MoviePilot 断开或关闭时，仍可在这里恢复连接、配置站点或查看已有记录。

## 配置

Bangumi 填写官方 [Access Token](https://next.bgm.tv/demo/access-token)。令牌需要收藏写入权限，经 ISecretProtector 加密保存在本机，保存后不回填明文。

豆瓣使用 Momoka 内的登录窗口。登录与自动标记共用 WebView2 豆瓣独立配置；Cookie 由 WebView2 自管，不复制到设置、HTTP 客户端或日志。系统浏览器的登录不会同步进来。切换登录、退出或修改站点配置会撤销旧播放场次的待办同步。

进入设置、保存密钥、完成豆瓣登录或退出后，会自动只读验证已启用的站点。Bangumi 卡显示密钥是否有效，豆瓣卡显示已登录或未登录；检查中、未配置和网络／页面识别失败分别显示，也可点击「重新验证」。关闭登录窗口本身不代表登录成功。验证不修改收藏，Bangumi 身份验证成功也不代表已实测写入权限。旧配置、旧页面或较早的检查结果不能覆盖新状态。

## 自动匹配

Momoka 把父剧标题、年份、可用的提供方编号和季集信息交给已连接的 MoviePilot 核对。MoviePilot 用已有编号和来源关系核对作品，必要时查标题与年份一致的唯一候选。特别篇、合并集或缺少集号时，能确认对应豆瓣作品仍可标记「在看」。Bangumi 同步和豆瓣完结都需要常规单集。条目信息冲突或识别结果无法确认时，相关站点记录为「已跳过」。识别请求出错时，记录为「失败」。

Bangumi 优先用经 MoviePilot 核验的 TMDB 剧集编号、季号和集号查内置逐集对照表，再向 Bangumi 核实动画类型和常规单集归属。同一个 TMDB 季可以对应多个 Bangumi 条目，媒体库缺少其他集也可以命中。表内已收录的剧若缺少当前单集对应关系，就跳过。表外只有在 MoviePilot 确认 Bangumi 作品、当前为常规第一季且集数可核对时，才尝试按原集号找单集。

## 播放与同步

- Bangumi 在实际进度达到「播放行为 → 标记已看进度」后标记单集「看过」，国漫使用国漫专属百分比。已有收藏状态、评分、评论及已看单集继续保留。未收藏作品先建立「在看」收藏。
- 豆瓣按作品记录。实际起播只识别作品并标记「在看」，已经「看过」的作品重播时保留原状态。达到标记已看进度后，MoviePilot 再核对当前集是否为季末集，并与豆瓣同一条目的公开总集数核对。两边相符才标记「看过」。使用媒体库直接给出的豆瓣条目编号时，也可按条目的公开总集数核对末集；后续季还须回读确认条目季号与播放季号一致。媒体库暂时只收录到哪一集，不影响判断。
- 同一场起播与完成串行处理，各一次。停止时只用实际进度。媒体账号退出、站点设置变化或 MoviePilot 切换连接后，旧任务失去写入资格。打格子独立于媒体服务器进度上报。

豆瓣提交先读取站点返回的收藏表单，保留评分、短评、标签及隐私，去掉分享控制；所有请求留在豆瓣同源页面内。表单地址、页面来源或字段不能确认时停止同步。网页流程可能变化，失败时需要重新登录或等待适配。

## 结果与通知

每张站点卡显示本站最新同步结果。「查看记录」按时间从新到旧列出作品和详情，Bangumi 还显示集号。记录可筛选在看、已看、已跳过和失败。弹窗实时刷新并保留当前筛选。关闭站点后仍可查看本次运行的已有记录。每站最多保留 100 条，退出 Momoka 后清空。

启用任一站点后，设置里会显示「打格子失败或跳过时发送系统通知」。两站共用一个开关，默认关闭，修改后即时保存，也可随无凭据的偏好备份导出和恢复。开启后，遇到失败或跳过时，Momoka 会请求 Windows 显示站点和固定原因。两站遇到同一个识别问题时各记一条结果，合发一条通知。主动取消、只读连接验证和未达到同步条件的播放保持静默。

写入结果未确认时，请到对应站点查看实际收藏或单集状态。Momoka 不会自动重发这笔写入。

## 实现与依据

`PlaybackScrobblingAttempt` 接收实际起播和进度，`ScrobblingService` 委托 `MoviePilotService` 读取作品、单集及已有来源对应关系。读取路径依据 MoviePilot v3.2.9 的 `app/api/endpoints/media.py`、`app/api/endpoints/tmdb.py` 和 `app/schemas/mapping.py`。`BangumiClient` 核验动画作品和单集并写入。`DoubanSession` 在独立 WebView2 会话中核对登录、读取条目并提交作品状态。[MoviePilot v3.2.9 源码](https://github.com/jxxghp/MoviePilot/tree/b186df432f2f1657f2e2e70e1fdedf78b4f3bde8)

TMDB 与 Bangumi 逐集对应取自 [open-ani/bangumi-tmdb 固定发行](https://github.com/open-ani/bangumi-tmdb/releases/tag/data-e6d78b44cfc999eacabc28fa0661f9dee743de79)，索引只保留数字编号和唯一的一对一坐标，在应用内查询。覆盖范围随应用打包的数据版本变化。无需 TMDB 密钥，也无需为对照表发送网络请求。归属、许可和转换说明见[第三方组件归属](../THIRD-PARTY-NOTICES.md)，复现入口为 [build-bangumi-tmdb-map.py](../tools/build-bangumi-tmdb-map.py)。Bangumi 单集归属核对使用 [OpenAPI 65d29cf](https://github.com/bangumi/api/blob/65d29cf/open-api/v0.yaml) 的 `GET /v0/episodes/{episode_id}`。

豆瓣登录判定核对 2026-11-26 匿名首页及[导航脚本 2.0.1](https://asset.doubanio.com/cuphead/nav/2.0.1/shire/bundle.js) 的 _GLOBAL_NAV.USER_ID、.nav-user-account .bn-more 和 nav-login：有效身份与账号入口共同存在才视为已登录，明确的官方登录入口才视为未登录；缺失或冲突视为验证失败。

Bangumi 接口核对至 [server ae5861f1](https://github.com/bangumi/server/tree/ae5861f1b7a91363d0e34b419a28913b7e654fbd) 的 web/routes.go、web/handler/user/update_episode_collection.go、ctrl/update_episode_progress.go 及 OpenAPI：未收藏时创建在看，单集通过 PATCH 修改。豆瓣流程依据本站 Douban.init_collect_btn / remote_submit_json，来源为[站点脚本](https://asset.doubanio.com/cuphead/vendors/js/douban.751471eacdfd.js)；网页接口不是公开稳定 API。
