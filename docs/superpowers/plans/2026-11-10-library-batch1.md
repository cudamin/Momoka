# 媒体库第一批实施与验收

用户已将补齐范围与顺序交给助手，并于 2026-11-10 要求开始第一批。沿用当前 C#/WinUI 架构和后端独立协议，直接实现。

1. 飞牛续播卡增加可选「从继续观看移除」。仅官方 `play/list` 返回的记录提供操作，普通媒体页和合成下一集不提供。确认说明删除该条播放记录、可能影响断点；不承诺保留进度、不改已看状态。独立命令及客户端入口使用 `DELETE api/v1/play/record {item_guid}`，成功刷新续播，失败保留卡片。不得走媒体删除回调或记录为已删媒体。
2. Jellyfin 合集管理读取 `EnableCollectionManagement`，管理员或明确授权用户可用；身份和当前权限贯穿服务、命令、菜单。Emby 使用自身权限条件，保留已有创建与添加。
3. 当前 Emby/Jellyfin 合集页可移除成员，捕获合集/成员/来源上下文。Emby `POST Collections/{id}/Items/Delete`，Jellyfin `DELETE Collections/{id}/Items`，均传成员 Ids；仅解除关系。权限撤销、换账号及错误响应不得更新页面或误删媒体。
4. 飞牛现有可达 Other 库和目录提供列表视图，复用既有列表组件。按官方 Hq 适用条件隐藏/恢复，保留横竖海报与列表偏好。IPTV 已有媒体类型隐藏规则继续适用，本批不增加直播浏览。

## 复核重点

删除续播不能调用 Home 的 Remember/RemovedMedia；映射标记必须参与卡片指纹，防止下一集与服务器记录复用错误；确认等待期间换身份不写入；合集权限不能只在菜单判断；列表不可用不能覆盖已存偏好。源码参考与具体运行证据在本批进度/报告中记录，旧审查不当作已测试结果。
