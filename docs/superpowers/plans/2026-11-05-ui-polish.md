# Momoka UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 落实已确认的截图美化建议，改善首页响应式、库页密度和卡片可读性。

**Architecture:** 复用现有 HomeCarousel/HomeFold、LibraryPage、CardItem/PosterCard 和样式角色；纯计算留 Core，局部展示留 Shell。保留后端差异，不改变传输及持久化协议。

**Tech Stack:** WinUI 3 / .NET 10 / C# / 现有控制台测试和离线 Shell 探针。

**Spec:** `docs/superpowers/specs/2026-11-05-ui-polish.md`

## Global Constraints

- 保留深色底、薄荷绿、海报墙和三种服务器各自的功能。
- 无服务器写入、真实播放、用户设置改后恢复或 GitHub 上传。
- 使用现有角色颜色与字号；不新增依赖，不改设置页。
- 编译和测试使用当前树、用户级 .NET 10、Release、单节点；UI 验证串行。
- 每项提交包含相关回归；仅主代理整合、运行最终 UI 验证和发布。

## Review Focus

- 窄窗与断点来回缩放不能让标题、按钮或媒体库和顶栏重叠。
- 首页位置偏好保留，宽窗恢复后仍按用户设置摆放，轮播关闭无遗留间距。
- 标题清理不损伤合法年份片名、括号及身份；回收卡缺图和图片成功切换不残留占位。
- 卡片两行文字不超出货架的测量高度，第三行来源仍完整。
- 搜索、收藏、文件夹等共用 LibraryPage 的入口不能被库页对齐改动破坏。

**Interfaces:** 保留现有 Height/NaturalHeight 和位置偏好接口；如加窄窗判断，命名并由生产与测试共用。

- [ ] 横幅最高 640 DIP；小于 760 DIP 宽时紧凑标题、避让 40 DIP 顶栏，媒体库置于下方；常规布局继续复用现有构件。
- [ ] 分隔线使用现有刷子降低透明度，不改变标题按钮点击区域。
- [ ] 编译与运行相关测试；更新真正受影响的旧几何断言及说明，不能抹掉无关失败。
- [ ] 提交任务，记录验证和需要最终实际窗口验证的范围。

### Task 2: 卡片可读性和缺图展示

**Files:** `src/Momoka.Shell/Views/CardItem.cs`, `PosterCard.xaml(.cs)`, 相应标题纯规则及 `tests/Momoka.Tests` 回归、卡片相关 Shell 探针；必要时修改 `CardSize.cs`。

**Interfaces:** 保留 CardItem 的身份、图片请求和动作；展示标题不得写回 EmbyItem 或后端。

- [ ] 为 Jellyfin 已知尾部编号、重复年份、合法括号数字及空标题；飞牛继续观看剧名/集名组合补失败回归。
- [ ] 清理 Jellyfin 卡片展示标题；飞牛继续观看主行剧名、次行集数和集名，卡片文字左对齐。
- [ ] 片名最多两行且标题区高度一致，保留年份与第三行来源；图片占位增加片名并正确随图片成功/失败/回收切换。
- [ ] 已观看勾选徽标使用较弱现有表面角色，数量徽标保留强调；中央播放按钮提高对比，保留动作路由。
- [ ] 编译、运行相关测试，提交任务并记录视觉验证范围。

### Task 3: 媒体库页头和继续观看留白

**Interfaces:** 消费 Task 2 的卡片尺寸；所有服务器保留各自分类与按钮，搜索页继续保持现有居中布局。

- [ ] 核对继续观看过大间距的真实来源，补对应失败回归。
- [ ] 非搜索库页使用一致现有标题刻度；按用户后续纠正保留分类/工具栏/浏览组的原居中方案，飞牛库根和继续观看仍用原左对齐分支；隐藏行不保留空隙，工具区至卡片 28 DIP。
- [ ] Jellyfin 字母索引在可见时留独立边距，隐藏后收回；不盖最后一列。
- [ ] 编译、运行相关测试，提交任务并记录视觉验证范围。
