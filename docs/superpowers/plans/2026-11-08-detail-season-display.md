# 媒体页默认文字与集页分季

用户指定三项行为：沉浸媒体页恢复默认字色；集页只列当前季，S00 特别篇按各季第一集首播日归季并按播出日期插入，首季前归首季、无日期留 S00；集页移除全部剧季卡片。

实现采用现有 Core 纯计算与详情页货架。归季不改服务器 DTO，播放全剧队列保留。集页的季菜单切换显示列表，剧页继续现有全剧列表；日期边界无法可靠确定时留 S00。
