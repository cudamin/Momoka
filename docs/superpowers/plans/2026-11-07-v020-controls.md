# 0.2.0 详情控件默认效果实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已批准 Demo 的按钮、闭合选择框半透明三态和展开亚克力实装为默认。

**Architecture:** 复用现有逐态局部画刷，不复制 WinUI 模板；恢复展开列表框架资源。新建、缺键、恢复默认的常态浓度采用 15/255×100；已有有效偏好原样保留。

**Tech Stack:** C# / .NET 10 / WinUI 2.3.9，保持已有依赖。

**Spec:** ../specs/2026-11-07-v020-controls-design.md；用户 2026-11-07 明确“复刻、设为默认效果”，视为修订后 Demo 批准及实施授权。

## Global Constraints

- 详情按钮与六颗闭合选择器共用正常/悬停/按下背景；默认 alpha 15/21/8，除以255。
- 展开列表亚克力仍为主题 SurfaceElevated，Tint/Luminosity 0.55；行状态恢复平台资源。
- 0常态透明、100各态实底；亚克力仍可切换，画刷对象和控件整体Opacity稳定。
- 不修改真实设置、播放或服务器共享数据；不上传。主树交付串行验证和发布。

## Review Focus

- 有效旧数值25、0、100及小数必须保留，缺键/恢复默认使用新值。
- 默认按下比常态淡，不能误走深色主题实底；小于默认时保留悬停/按下反馈。
- 高对比度必须回退系统实底；主题切换保留旧强调色图标。
- 展开列表不能被局部灰色键截断，长轨道宽度与点外关闭保持。
- 打开设置不能将精确默认5.882%无意保存成6%，滑块仅在用户修改时写偏好。
