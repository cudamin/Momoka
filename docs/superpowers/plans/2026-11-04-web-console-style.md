# 服务端设置网页修复与样式对齐

目标：修复内嵌 Emby 服务端设置缺少页面功能的问题，按当前 WinUI 设置页统一 Emby／Jellyfin 的网页皮肤。

设计依据：Emby 4.10.1.0 发布前端的 `modules/layout/layout.css` 给顶栏设置 `contain: strict`，与本地自动高度冲突；`modules/headroom/headroom.css` 还使用独立 `translate`。`server/sync/sync.js` 的“下载／设置”属于服务器自己的页签。保留原始节点、事件、权限隐藏和滚动；只移除重复的全局导航，保留页面标题、返回与帮助。沿用主题角色，正文和标题字体、标签15／说明13／标题18、输入圆角10、卡片间距16对齐当前设置页；不改服务器配置和认证。

- [x] 修复 `EmbyWebConsole.cs` 的顶栏尺寸与页面功能保留；修改两份 Skin 的有限样式和分组标题自然布局，避免隐藏原有功能。
