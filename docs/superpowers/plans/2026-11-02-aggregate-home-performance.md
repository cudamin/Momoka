# 聚合主页性能实施计划

**目标：** 加快聚合模式首页加载和刷新，保留媒体内容、货架顺序与账号隔离。

**依据：** 用户指定首页加载或刷新。`HomeViewModel.LoadAsync` 已并发读取，但所有内容仍等待库总数及入库指纹；`Shelves.Clear` 会让 `HomePage.RefreshHomeRows` 反复移除、重建整页行。

**实现选择：** 在现有 WinUI / MVVM 路径内修正等待与集合更新，不增加依赖。主树干净，本会话独占写入，子代理只读调查和复核。

- [x] 用当前 Release Shell DLL、真实 HomeViewModel 和假 HTTP 写回归：辅助请求挂起时内容可用、刷新货架不 Reset、迟到辅助响应不能覆盖新加载或离页状态。
- [x] 内容完成后结束前台加载；库总数与指纹保留在同一加载生命周期，完成后逐项回填，取消/换代拒绝旧回填。
- [x] 更新 Shelves 时只删除、插入或移动变化的货架；保留轮播上媒体库的所属与排列。
- [x] Recent + All 轮播直接捕获各来源原始前 24 项指纹，省掉同路由检查；随机/类型筛选/关闭轮播仍单独检查。
- [x] 请求次数、24 项基线、辅助失败、身份隔离与取消测试先红后绿。
- [x] 独立复核，当前 Core/Tests 全套、实际 VM 专项、accounts/library 离线探针，主树发布并检查快捷方式。

**验收限制：** 假 HTTP 的受控挂起证明等待关系与请求次数，不代替真实服务器耗时、WinUI 帧率或真实播放验证。版本号不变，不上传 origin。
