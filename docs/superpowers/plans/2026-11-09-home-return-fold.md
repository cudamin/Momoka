# 返回主页媒体库误翻档修复

目标：返回主页时，默认应在轮播下方的媒体库直接保持在下方，不因货架入场位移先压上轮播再落下。

原因：普通货架的界线通过 TransformToVisual 测量，模板根的入场 TranslateTransform.Y 会进入屏幕坐标和标题高度；混排只在屏幕坐标处单独扣除。稳定布局没有改变，却可能越过 Auto 阈值。

实现：主页增加只用于布局判定的坐标读取，扣除路径上的 TranslateTransform.Y。屏幕界线、标题高度和标题到卡片的间隔共用它；动画起落点仍使用现有现场坐标。混排删除重复扣除。保持原阈值、设置、动画曲线和时长。
