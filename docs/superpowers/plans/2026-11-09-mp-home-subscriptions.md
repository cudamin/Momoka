# MP 主页订阅交互与布局

**目标：** 封面直接编辑，更多菜单按网页端的动作及顺序排列，详情下方组件紧凑两列，背景图采用详情页亚克力。

**实现：** 复用现有编辑器与服务身份/写入防重；增加分享与活动的原生弹窗和安全字段投影。文件统计独立打开，电影也有有效落点。背景沿用设置里的染色、浓度与系统回退。

**布局：** 海报/标题/操作在上；简介和季在左、资料卡在右；窄窗叠放，不让资料卡撑高头部。不改变侧栏订阅分类或新增外观开关。

**追加要求：** 按钮也跟随现有外观设置；沉浸模式上下不要分层，正文完全透明，共用背景亚克力。

**依据：** 用户四项要求与三张附件；背景图遮罩已另行明确。官方前端 v3 ae956ef259fc3ff17a34c2e5247536829f5eefa1，后端 v3 4620ceacda78b1e0d0f903aebb320fdb6d613420。当前部署版本尚未核对。
