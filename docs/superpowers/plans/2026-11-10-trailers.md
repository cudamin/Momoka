# 预告片 Implementation Plan

**Goal:** 在详情页选择并观看服务器提供的预告片。

**Architecture:** Core 提供 DTO、预告列表接口及安全候选规则；详情 VM 管理访问生命周期、加载和启动，页面仅构建选择菜单。复用现有播放器和浏览器启动器。

**Tech Stack:** .NET 10、WinUI 3、现有匿名测试与 Shell 探针。

**Spec:** ../specs/2026-11-10-trailers-design.md

## Global Constraints

只支持 Emby/Jellyfin；远程链接在浏览器打开。真实服务器播放不在验证范围。不得将正片 ID 用于预告播放。并行开发使用独立树。

## Review Focus

无资源及错误后的隐藏恢复；重载/离页/切换来源后的旧菜单失效；URL 凭据和协议过滤；本地预告自身身份和起点；宽窄窗口按钮可达。

## Task 1: Core 数据与选择规则

- [ ] 先写 DTO、Emby/Jellyfin 路由、空值、URL 过滤和去重的失败测试。
- [ ] 增加 `MediaTrailerUrl` DTO、EmbyItem.LocalTrailerCount/RemoteTrailers。
- [ ] 新增 `EmbyClient.GetLocalTrailersAsync(string itemId, CancellationToken cancellationToken)`，返回 `Task<List<EmbyItem>>`；非支持来源拒绝。
- [ ] 新增 `ItemTrailers.Supports(MediaServerKind)`、`HasAny(EmbyItem, MediaServerKind)`、`Remote(EmbyItem)`（返回 `IReadOnlyList<MediaTrailerUrl>`），只返回有效、安全、去重的 URL。
- [ ] 测试通过后提交，整合到本树。

## Task 2: 详情交互

- [ ] 在现有实际 Shell VM 夹具中先补预告缺失的失败用例。
- [ ] 新增 DetailViewModel.Trailers.cs；绑定入口显隐，在页面访问范围内读取列表，提供包含本地条目或远程 URL 的候选快照与选择入口。
- [ ] DetailPage 两套操作区增加预告按钮及点外关闭菜单，展示加载/错误/重试，选择时调用 VM。
- [ ] 测试确认单独 ID、从零、无正片队列；旧访问/重载拒绝；错误可重试和无资源隐藏。

## Task 3: 验证与交付

- [ ] 增加匿名原生预告检查，验证宽窄入口、选择菜单、隐藏恢复并截图。
- [ ] 当前 Release Shell/Tests 编译，核心全量及相关 VM 回归、自动化句柄、编码/差异检查。
- [ ] 独立审查，修复必要缺陷并验证；提交产品及证据记录。
- [ ] 按主树状态安全整合，重验最终代码，发布实际交付目录并核对快捷方式；未获上传授权不推送。
