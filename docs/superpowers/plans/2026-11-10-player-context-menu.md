# 播放右键菜单与工具实现计划

目标：按用户截图及 dyphire/mpv-config 源码补齐播放菜单、快捷键和可选外部工具。用户已明确要求直接实装，并确认外部工具一起接入、配置后显示。

架构：原生动作使用同一 Core 目录供 WinUI/uosc 与快捷键调用；动态轨道、宿主操作和工具菜单在视图模型生成。命令执行固定播放身份。外部程序只接收本地文件和固定参数，认证下载由宿主进程完成。

源码依据：本地 2026.08.12 portable_config/input.conf，SHA256 1480084C45CD6ED1D32617DF7C1FF92DE78928F05E581093475442C461AD68DC；2026-11-10 远端 HEAD e235480f28674ee507ac87d2d0c8e79ac1fa0682。menu.conf 刻意为空，菜单实际来自 input.conf 注释及 dyn_menu/uosc。新增行为按实际内核支持取舍，不把脚本入口当原生命令。

- [x] 原生目录、主次字幕、音视频/HDR/滤镜/截图动作、无冲突快捷键、同窗复位及测试（player-native-menu 独立树）。
- [x] 外部工具固定参数、路径边界、取消与输出核验、SRT 翻译及测试（player-tools-core 独立树）。
- [x] 工具设置、exe/目录选择、符号按键的 WinUI/Lua 对齐及测试（player-tools-settings 独立树）。
- [x] 动态菜单能力过滤、轨道/设备/章节、旧菜单失效、认证媒体本地准备、工具任务进度与取消、原片字幕回载。
- [x] 整合后当前 Release 编译与测试；本地隔离探针和真实界面截图；主树整合、重验、发布与提交。

验证重点：关闭字幕仍可重新选轨；无依赖时完整收起且保留配置入口；自定义按键优先；异步工作不能借用下一集身份；子进程参数和日志不含凭据；失败不报告成功；不覆盖用户输出。

真实媒体库不作为测试夹具。外部处理远程媒体需要先下载本地副本，界面明确提示时间/磁盘成本，并提供取消。测试采用匿名 HTTP、合成媒体与临时目录。
