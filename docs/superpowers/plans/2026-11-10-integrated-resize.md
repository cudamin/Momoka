目标：快速拖大、拖小和反向拖边时，视频跟随客户区，右侧及底部不出现旧尺寸露底；松手正确恢复播放。

范围：沿用 WinUI、libmpv 集成管线和现有拖动暂停语义，不改变视频宽高比、独占后端或用户设置。使用当前隔离工作树直接修复。

- [x] 给现有本地 motion 探针增加仅缩放入口；后台连续捕获实际屏幕，不在每次拖边后等待提交。单帧像素规则用完整彩条、右边/底边露底和裁切反例验证。
- [x] 用未修改产品路径运行，保留中间失败帧，确认旧缓冲与 HWND/合成提交的时间差。
- [x] 修复实际提交边界；优先复用已有帧承接层和拖边生命周期，避免阻塞 XAML 提交、重复抓帧或固定放大掩盖。
- [x] 验证连续双向、左上/右下边、快速二次拖动、用户暂停和恢复；保留真实连续画面证据。用户原暂停及快速收尾交接由源链接回归覆盖。
