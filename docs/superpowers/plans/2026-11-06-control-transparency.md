# 详情控件灰色透明背景实施计划

**目标：** 落实用户批准的 Demo：现有底色与亚克力均可连续调节，中性灰底、白字白图标、无文字阴影；默认不透明度 25%。

**设计批准：** 本聊天中用户逐次指定白字、去掉阴影、底色偏灰，随后回复「可以」，并追加「默认25%」。常态 RGB 为 B0/B0/B0，悬停 C3/C3/C3，按下 9B/9B/9B。常态 0 完全透明，100 实底；悬停/按下额外反馈分别为 6/12 个百分点，封顶 100%。

**实现：** 沿用现有每态固定 AcrylicBrush 与资源键，仅详情控件走精确百分比分支；不改首页的既有反馈。保留高对比度系统颜色，已有显式透明度偏好不迁移。默认值与缺键/恢复默认统一 25。

**技术：** C#、.NET 10、WinUI 3，不增加依赖。

**追加批准：** 用户随后确认文字方案并纠正为遮罩/高斯都统一：分类、评分来源、年份等头图信息与简介使用视频/音频的 `EgOnScrimBrush`。主题色链接、星标和卡片文字保持原样，高斯已有文字阴影保留；控件文字不新增阴影。
