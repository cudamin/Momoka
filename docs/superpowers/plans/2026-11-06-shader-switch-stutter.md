# 着色器切换卡顿修复计划

**目标：** 减少集成 D3D11 模式切换到 Anime4K 时，逐项改变前置参数造成的中间渲染更新。

**依据：** mpv 270367e8af 的 UPDATE_VIDEO 单项 set 立即通知 VO；配置文件应用会合并同类通知。随包内核的隔离本地对照得到每次三轮更新减少为一轮。首次目标帧等待约 2.30 秒降到 1.97 秒，热切换尚无稳定耗时改善证据。现有 shader cache 已启用，同值 set 本身不会重新编译。

**实现：** 仅集成内置句柄增加可选切链批量能力，现有 service 预检、默认值和无损旧值快照不变。用独立临时 UTF-8 配置只写八个受控选项，由真实 native 文件代次闸门执行一次 mpv_load_config_file；随后在同一闸门完整读回。配置解析可能部分失败却返回成功，必须读回匹配才确认；失败尝试整批恢复，换片后拒绝写入/回滚。普通独占与外部控制保留逐项命令。

**取舍：** 不加载两套渲染器，不预热所有着色器，不更换 Anime4K 算法或画质。批量应用减少中间配置，不能消除首次 GLSL 编译和目标链运行成本。
