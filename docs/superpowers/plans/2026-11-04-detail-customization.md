# 详情页自定义设置实施计划

目标：移除关于中的弹弹play来源行；在界面设置中为剧、单集、电影提供正文卡片排序与隐藏，提供控件底色与背景图不透明度，并可固定使用现有沉浸布局。

用户已确认：集页面只指单集详情；透明度仅影响按钮/选择框底色，文字图标保持清晰。两条滑块默认 0 保留原外观，只能增加不透明度，100 完全不透明。

设计：沿用当前 WinUI 设置卡片、勾选拖拽表和 SettingsPriorityMotion 弹簧。三种页面独立保存正文顺序与显隐，季页面继续默认顺序；无数据卡片仍自动收起。影片信息头、简介和尾图不属于正文卡片。默认保留现有外观；固定沉浸仅覆盖原布局的窗口大小触发条件，保留无图、单集与窄窗的适用条件。设置即时生效，纳入备份/导入/恢复默认。

选型：复用现有设置表及页面卡片实例，避免增加另一套拖拽算法或重建整个详情页。纯外观通过专用通知更新，不触发首页重新请求。

- [x] Core：卡片目录与归一化、三套设置、外观数值范围及导入/恢复测试。
- [x] 设置：移除来源行，界面增加透明度/沉浸/三套排序表，接弹簧与完整拖拽提交。
- [x] 页面：按实际正文次序重排既有面板，显隐叠加数据条件，动画遵循重排后的次序。
- [x] 外观：控件背景画刷、首页详情按钮、背景图与沉浸开关即时联动。
- [ ] 验证：当前 Release 测试、实际设置与详情隔离探针、宽窄与主题截图、自动化定位、diff检查。
- [x] 收尾：复核并在当前工作树提交；用户明确先不合并，主树整合及桌面发布留待恢复指示。

重点回归：未知/重复/缺失键和空列表；隐藏后恢复顺序不丢；拖拽期间不保存缺项快照；禁动画/离页清理；透明度调整不重读首页；导入与重置即时生效；关闭固定沉浸恢复自动判定。

验证记录：新增功能运行Case 2/2、主测试3677/3677、外观31/31；扩展材质探针窗口缩放超时仍未通过，见 PROGRESS。
