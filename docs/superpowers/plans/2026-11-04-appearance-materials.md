# 外观材质与背景效果实现计划

**目标：** 在已有详情自定义分支中增加按钮「现有底色／亚克力」与背景「暗色遮罩／高斯模糊」，保留零档不透明度语义，缩短与主题同色的背景收边渐变。用户要求先不合并。

**设计：** 两个独立布尔偏好默认关闭，选择行沿用现有 SettingChoiceRow；滑块继续显示。每态固定一支 AcrylicBrush，只改变材质属性，不重写共享资源键；现有底色使用精确 fallback，100 档完全实底。背景复用有界像素缓存、WIC/BMP 管线和取消/换代守卫，分离式高斯仅改变图片。高斯替换图上的文字暗化层；下沿短渐变仍接到主题底色，用于隐藏图片底边。

**技术：** C#/.NET 10、WinUI 3，不增加 NuGet 依赖。

## 工作与验证

- [x] 设置与按钮：新增配置/两组选择；覆盖零档、100档、三态、checked/focused、切换与主题、导入恢复和资源键别名风险。
- [x] 背景：新增真正分离式高斯，模式进入缓存键；详情与首页即时切换不请求媒体，取消或离页不回写旧图；保留图片身份、轮播与实体卡片。
- [x] 收边：缩短下沿渐变，停点颜色取主题页面底色；主题切换重画，透明起点到不透明底端自然相接。
