# 固定亚克力与主图底色

最终用户范围：取消剧页与集页合并，保留现有独立布局和各自卡片设置。移除高斯与纯色遮罩选择，背景、按钮与闭合选择框固定原生亚克力。文字使用固定项目白色角色，高对比使用系统前景。背景亚克力染色取当前主图整图8×5均色，默认不透明度20%，既有有效浓度保留；旧增量迁移仍使用历史40。

沿用DetailPage，不改变单集身份、标题、播放/删除目标或原宽窄版式。移除材质、背景效果、手动背景色选择，保留控件底色、两条浓度滑块与显示模式。原主图不再按裁切或设置做CPU重糊；无图底色回主题Window，颜色随原像素身份更新，滚动和窗口尺寸不改色。普通版式仍保留图片底部收边。原生高对比/系统关闭透明效果按平台回退。

实现选择：直接简化原有材质分支，不引入新模板或依赖；公共高斯算法仍供首页扩边使用。本任务按用户直接实施偏好执行，不制作Demo。

追加要求：集页列表只显示当前/选定季度；按正片季首播日期把S00特别篇归入正季并依AirOrder插入，早于首季归首季、日期缺失留S00。季DTO日期缺失时取该季最早普通集日期；不改服务器条目季号/身份。集页改为现有纵列表形状，隐藏全部剧集卡片与设置项，剧页保持全剧横带。全剧DTO仍用于播放上下文，选季只投影不HTTP不改本集目标。

亚克力透明度修复：按钮/闭合选择框及背景均固定材质Tint/Luminosity0.55，滑块直接驱动整支Brush.Opacity。0全透明，100Fallback实底；按钮三态保留既有反馈曲线，主页按钮保留反馈alpha下限。

最终追加：按钮与选择框背景为全局设置，普通按钮/闭合选择框、卡片浮出播放/操作及货架和主页翻页箭头接同一材质；仅命中层、颜色样本与媒体承载板继续保留功能背景。深色媒体页面文字固定纯白，浅色固定深色，只随主题而非主图/滚动改变。亚克力TintColor/TintOpacity/TintLuminosityOpacity均提供中文设置；背景默认自动主图色，可切自定义。省电由WinUI内建EnergySaver策略自动回退FallbackColor，未切换系统省电测试，禁止声称实际电池验证。
