# 本机目录识别与链接整理

用户最终选择：源文件位于 Momoka 所在 Windows 电脑，MoviePilot 在另一台 NAS；不共享目录、不上传视频。识别可选 Momoka 直接联网查询 TMDB，或使用 MoviePilot；整理独立选择直接更改源文件名、在另一目录创建软链接或硬链接。链接方式保留源文件名和位置；直接改名则在原目录规范命名。NFO、海报和背景图写入对应输出目录。

## 方案

已讨论直接共享给 MP、上传到 MP、本机处理三条路径，用户选择本机处理，随后明确要求双识别和三种整理方式。沿用现有 MP 连接及图片读取，新增独立 TMDB 客户端、本机文件规划和执行能力。入口是设置中的「本机整理」，无需开启 MP。提供源目录、链接目标目录、递归扫描和三种方式。Momoka 识别使用用户的 TMDB API Read Access Token，由现有 Windows protector 加密保管。扫描后展示逐文件识别、季集、目标及错误；自动唯一匹配不足时手动搜索选片、指定季集，重新预览后才可确认。保存上次目录和方式便于再次使用。

## 行为与边界

- 首版处理电影及电视剧单集；多集文件、身份缺失、季集不明确时列出错误，不猜编号。
- 输出采用作品目录；剧集增加 Season NN。字幕旁车文件通过同一方式链接并保留语言后缀。
- 链接方式不重命名、不移动、不写源内容；直接改名只改变原目录里的视频和匹配字幕名称。目标已有同名文件不覆盖，链接目标不得位于源目录内。软链接不会改用硬链接，硬链接不会降级为复制。
- 硬链接仅同卷成功；软链接权限失败给出明确操作提示。硬链接与源共享文件内容，界面提示不能编辑链接中的视频内容。
- 预览后修改目录/方式、文件变化、连接变化使计划失效。取消只停止后续项目，保留并如实报告已经创建的结果。
- 数据通过所选来源的识别、详情、单集和图片接口读取；MP 可能更新内部识别缓存、Cookie 与日志，本功能不调用 transfer/manual 或 scrape，不触发媒体库扫描或播放。
