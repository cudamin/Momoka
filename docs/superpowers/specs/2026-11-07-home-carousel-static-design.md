# 主页轮播固定画面与完整扩边高斯（待 Demo 确认）

用户要求主页轮播图不再自动缓慢缩放，并让高斯模糊完整覆盖左侧延长区域。按用户此前明确指定的流程，先制作真实服务器数据 Demo，明确同意后才正式实装。本次只完成独立预览，没有产品改动或发布。

## 方案

继续使用已有的扩边与原图合成位图，保留自动换图、切换按钮和交叉淡入；移除每张图片从 104.5% 在七秒内缩到 100% 的背景动画。扩边每一列写入现有 sigma 12 高斯结果，取消扩边末 20% 淡回清晰的混合。

用户看首版 Demo 后指出过渡太生硬，截图片段显示模糊与清晰区之间的竖向接缝，首版尚未批准。第二版将衰减过渡移入原图左侧 8% 宽度：扩边与原图起始列使用同一高斯卷积结果，随后通过两端导数为零的平滑曲线恢复清晰。代价是原图最左侧一小段也会柔化；过渡之后的原图及全部 alpha 保持原样。第二版复用既有真实素材，重新渲染不再读取服务器。

独立模糊覆盖层需要额外同步 UniformToFill 的裁切和尺寸，当前位图路线已经保证同图同裁切，因此不另加覆盖层。增大高斯半径无法修复末列强度为零的问题。以上实现选择由助手提出，尚未获得用户的 Demo 批准。

## 约束与后续

高斯在扩边完整覆盖，宽高比变化仍按原有居中裁切计算；超宽图片的扩边可能被画框裁掉。第二版将模糊到清晰的过渡移入原图，真实 Demo 供用户评估柔化范围。当前为浏览器预览，不代表实际 WinUI 验证或快捷方式交付。
