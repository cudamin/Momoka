# 主页轮播固定画面与完整扩边高斯（待 Demo 确认）

用户要求主页轮播图不再自动缓慢缩放，并让高斯模糊完整覆盖左侧延长区域。按用户此前明确指定的流程，先制作真实服务器数据 Demo，明确同意后才正式实装。本次只完成独立预览，没有产品改动或发布。

## 方案

继续使用已有的扩边与原图合成位图，保留自动换图、切换按钮和交叉淡入；移除每张图片从 104.5% 在七秒内缩到 100% 的背景动画。扩边每一列写入现有 sigma 12 高斯结果，取消扩边末 20% 淡回清晰的混合，原图与 alpha 保持原样。

独立模糊覆盖层需要额外同步 UniformToFill 的裁切和尺寸，当前位图路线已经保证同图同裁切，因此不另加覆盖层。增大高斯半径无法修复末列强度为零的问题。以上实现选择由助手提出，尚未获得用户的 Demo 批准。

## 预览与证据

- 本树 `work/carousel-static-demo-20261107/index.html`，本机预览 `http://127.0.0.1:8767/`；可切调整后/当前效果、1280/760/600 窗口宽度，以及隐藏文字和遮罩检查延长区。实际显示宽度受浏览器可用空间限制。
- 当前所选服务器的最近添加列表经过只读身份与账号核对取得，导出六张真实背景及六个徽标。图片从生产缓存只读命中十二次；未登录回退、写真实配置或播放。
- 独立提取工具构建 0 警告、0 错误；三项像素断言及 PNG 五十四项检查通过。118055 个变化像素全部在扩边内，原图与 alpha 相同；真实设置与备份前后哈希一致。详情见忽略目录内 `receipt.json`、`extractor/verify_assets.py`。
- 浏览器检查六张图片和徽标、宽/窄/小窗、扩边边界、当前七秒缩放对照；调整后背景没有缩放动画且矩阵为单位值。自动换图等待首轮定位器超时，随后真实状态确认第六张自动回到第一张，背景仍静止；不把超时称通过。截图在 `screenshots/`。

## 约束与后续

高斯在扩边完整覆盖，宽高比变化仍按原有居中裁切计算；超宽图片的扩边可能被画框裁掉。完整模糊与清晰原图交界在高对比边缘可能更明显，真实 Demo 供用户评估。当前为浏览器预览，不代表实际 WinUI 验证或快捷方式交付。

批准后定点修改 `HomeBanner` 的两处 Nudge 调用与 camera 动画、`CarouselBackdrop` 的混回循环，并更新图片处理缓存版本和相关测试/探针。测试、实际 WinUI 宽窄截图、主树整合及本地发布属于后续正式实装批次。
