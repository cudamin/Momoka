# 后端审查两项修复

用户授权自行决定是否修复。两项均已有匿名复现与可达调用链，决定修复；不扩大到已排除的审查疑点。

## 目标

- 原生播放的每次 HTTP 请求只能向所属来源发送服务器认证；跨来源跳转与回跳不能携带原认证，HTTPS 不得降级。字幕、重连、拖动与同窗换片遵守同一边界。
- Plex 一个 Media 保留为一个版本，其 Part 按顺序组成一部影片；续播、拖动、上报与完成判定使用整片时间轴。
- 不把凭据放进 URL、日志或子进程启动参数。不连接真实服务器，不改变用户观看记录。

## 方案与取舍

播放认证不能仅靠一次预先探测：后续请求仍可能返回不同重定向。选择每个播放句柄持有的本机流转发：令牌只在受管 HTTP 内逐跳使用，播放器只获得不可猜测的本机资源地址，原生全局认证头始终为空。拒绝响应 Cookie 与 Location 透传，支持 Range 并随句柄取消释放。原生禁止重定向加受管解析未采用：随包 mpv 的 curl 与 FFmpeg 路径并不共享该限制。保留现有后端与管线选择，不在本轮扩展 HLS 清单重写。

Plex 用 mpv EDL 组成单一时间轴，减少服务层多次启动及中途 EOF 的生命周期分支；保留结构化分段清单供安全传输逐段映射。替代方案是服务层分段接续，需额外换算所有 seek、字幕、进度与完成信号。缺失/非法分段时长或内置轨道布局不兼容的 Media 排除，保留其他版本；多段影片只隐藏无法表达整片时间轴的服务器外挂字幕轨，内置轨与无字幕播放可用，单段外挂字幕不受影响。不伪造总时长或把其他版本串入影片。

## 验收

匿名两来源 HTTP 跳转复现从“目标收到占位令牌”变为“目标未收到”；同源仍能认证，回跳不恢复认证，Range 与取消不破坏边界。两段各 3600 秒的 Plex 影片从 4500 秒续播落在第二段 900 秒；中间段结束不产生整片完成，单段与独立版本保持语义。
