# 弹幕显示控制

用户要求补充两张截图中的弹幕控制，并追加：全局开启后播放页提供一键显示开关；全局关闭时隐藏右键相关入口。用户已选择智能防挡和屏蔽列表按 Momoka 本地防重叠、共用屏蔽词处理。

沿用现有 WinUI 设置卡片与弹幕浮层，同一设置对象保存偏好，播放页与独占窗口保留面板入口并增加直接开关。没有服务或渲染能力时完整隐藏从属入口；临时关闭显示仍保留恢复按钮和偏好。

补充随窗口缩放、字幕底部预留、防重叠、正常/较多/重叠密度、倍速跟随、字体/粗体、描边/重墨/45度投影和仅恢复外观默认。屏蔽词在两处实时保存和刷新；不引入无来源的联网同步按钮。普通类型、区域、透明度、字号、速度、上限、屏蔽词继续复用现有行为。高级模式当前被来源解析和渲染器过滤，继续隐藏无效开关。

实现选择：复用当前独立 ASS 叠加层，保留默认播放效果；缩放关闭时按物理像素固定字号，字幕避让仅在可见字幕存在时预留底部20%。用户没有要求人物识别、B站账号接入或界面像素复刻，不引入这些依赖。

验证覆盖归一化、偏好保存与恢复、脚本消息字段、实际Lua布局/倍速/暂停/seek、UI宽窄开关与全局显隐恢复；离线匿名探针不播放真实媒体。最终整合主树后重验并发布，不上传远端。
