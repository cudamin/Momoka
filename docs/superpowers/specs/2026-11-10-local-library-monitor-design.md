# 多本地媒体库与自动监控

用户追加并更正验收：设置支持多个目录，一个目录对应一个独立媒体库；首页在媒体库区域显示每个库。每库可分别命名、选择 Momoka/TMDB 或 MoviePilot 识别、直接改名/软链接/硬链接、递归及监控。开启监控处理已有和新增文件。此要求覆盖上一批的“不自动监控”。

监控归应用服务生命周期，关闭设置页继续，关闭应用停止；不安装后台服务。源文件经过稳定时间与独占写入检查后只对唯一识别结果自动生成和执行计划；歧义等待校正，失败和部分完成保留记录。持久化处理账本避免重复事件与重启再执行。自动整理只在用户保存并明确开启的库范围内。

文件和元数据实际成功后才登记本地库；视频与NFO是入库条件，图片失败单独说明。首页一库一卡，进入展示该库的海报、片名、季集和本机路径；新入库和库配置变化更新当前首页。移除库配置不删除媒体或输出文件。手动整理也记入该库索引。索引与本机设置不进入可分享配置。

实现由独立的 Core 监控/索引、Shell 协调器、设置多库编辑和首页列表页组成。复用上一批识别与文件操作，避免两套命名和安全规则。真实已有与新增测试在独立临时目录配匿名识别服务，必须观察真正FileSystemWatcher触发、稳定等待、NFO/图片/索引以及多库隔离。真实服务器副作用/真实媒体范围仍遵循 CLAUDE.md。
