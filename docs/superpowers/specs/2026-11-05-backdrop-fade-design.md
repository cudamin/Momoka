# 详情背景主题收边与主页底部渐变移除

用户要求：剧、季、电影页普通模式复刻 Emby Theater 背景底部渐变；沉浸模式不加；渐变终点与当前主题底色一致；主页轮播移除底部渐变。

参考安装包 `Emby Theater/electronapp/package.json` 版本 3.0.20-3.0。`www/item/item.css:298-317` 的图片蒙版为 `linear-gradient(to top, transparent 0%, black 30%)`，30% 相对背景元素；不是原图或截图百分比。CSS SHA256：6CEF345654844E0D270694688CA02E080AB21BD01F58FEADFAEB99E4556BAD62。静态证据未证明截图的运行尺寸。

## 实现选择

复用 WinUI 图片层、画刷与现有主题事件。普通有图三页把均匀阅读遮罩移入固定背景，上方绘制从元素顶端70%到100%的主题色过渡；滚动头尾和未覆盖标题栏透明，避免末端再被压暗。仅在图片上加渐变会被现有头尾黑罩再次压暗，因此不采用。无需重解码图片或新增依赖。

沉浸模式保持原阅读遮罩，收起新渐变；单集、无图与其它页面维持原逻辑。主页只删除独立底部渐变，保留标题和侧边阅读遮罩。主题、普通/高斯和沉浸切换即时重算，图片透明度不影响渐变末端不透明性。
