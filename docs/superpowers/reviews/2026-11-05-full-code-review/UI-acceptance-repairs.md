# 主树验收时新增的界面与探针修正

原审查选定15项之外，主树运行验收另确认账号聚合开关的视觉问题；本页独立记录，不改写原133项历史计数。

## 账号开关快关后位置残留

用户可达路径：打开账号菜单，开启聚合，关闭聚合后立即关闭浮层，缩窗或重新打开；开关文字为“关”，滑块仍为右侧开启位置。原位置断言不变。无视觉状态对象查询的运行 `shell-probe-20261106-185505727-34264/logs` 在两秒等待后仍为 IsOn=False、X=20、动画基础值0，真实屏幕也不一致。

当前 WinUI 2.3.9 模板的 Off 没有位置时间线，On 用零时长动画设 X=20。仅账号聚合开关的实际模板补 Off 的 X=0 时间线，保留原 On、过渡与普通交互。通过对象绑定当前模板变换，不强写基础值。首次按名称绑定产生 `Cannot resolve TargetName KnobTranslateTransform`，原失败保留，改为真实对象绑定。两个局部引用确保同一模板反复加载只安装一次，已有时间线不清空。

固定来源：实际载入和包内 Microsoft.UI.Xaml.dll 的 FileVersion均指向上游提交 `693f472aeaf89c6dff66256ee6fcd453e5d553b8`。核读 ToggleSwitch_Partial.cpp、VisualStateManagerActuator.cpp、CVisualStateManager2.cpp 及实际包 generic.xaml；来源副本在本树忽略的 `work/scroll-pin-693f472`，不是干净检出的运行依赖。

直接对象绑定后的运行 `shell-probe-20261106-190047378-8500/logs` 账号分区5项全过，四档宽度重复快关后 Off=0、On=20。最终版补重复安装不触发 Toggled、不增加时间线、不改偏好或发请求的实际控件断言；最终四分区运行结果见 REPAIRS。

## 探针窗口与异步控件就绪

原探针在空 Grid 上初始化 XAML 岛；Loaded、尺寸和 Rendering 回调均成立，早期真实屏幕却纯底色，ScrollCompleted关联号结束也未产生偏移。主应用启动在初始化前已有 ShellPage 内容。最小对照：普通背景无效；首个 RenderTargetBitmap仅提交旧快照，不恢复后续更新；在 Show 前放入未 Attach 的真实登录页则恢复实际滚动和显示，关闭 HomeMotion 后仍恢复。所有原红保留，没有将位图渲染或动画留作催帧修复。

正式探针先挂匿名登录页，等待 Loaded 与实际 Rendered 后移除、Detach并Dispose，再执行原用例；全程不接真实账号或设置。初始化失败仍记宿主失败，成功不增加用例计数。滚动必须加载内部 Presenter、等待对应关联号后再核实际目标偏移。Sidebar在模板就绪后读取滚动器；对话框等待真实按钮 Loaded、有尺寸及可访问，再调用原 UIA 路径。

账号拍照以实际位置连续稳定为前件，最多两秒，保留0/20位置阈值与快关路径；截图后重新取值。诊断枚举视觉状态组会展开 WinUI 优化状态对象并改变处理路径，已从正式检查移除。公开 CurrentState在快速关闭后可能滞后，不作为视觉通过条件。错误路径保留最终偏移、基础值和有限样本，不放宽基线。

所有 build、测试和桌面运行串行。仅匿名夹具、内存HTTP和本地证据；未运行真实服务写入、播放或外部发布。
