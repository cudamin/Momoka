- Jellyfin 文件源 `Id` 是版本条目GUID。`ServerSubtitles` 捕获它作为搜索、下载、删除和复读目标；无有效版本GUID拒绝打开，不回退主条目。复读仍检查返回条目身份、源ID唯一、原路径与完整字幕快照，变化时不删除。
