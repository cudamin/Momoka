### R02-001 · P2 · 旧版本的空播放设置让整份配置回退

- 位置：`src/Momoka.Core/Configuration/SettingsMigration.cs:248–251,955–957`。
- 触发：schema 13–17 的文档含 `Playback: null`，其他身份与偏好有效。第38行Repair已补默认对象，但v18迁移仍对原JSON空节点调用ReadBool，没有先检查Object。
- 后果：FromJson抛InvalidOperationException；普通Load将主文件隔离，采用备份或默认，用户原有其他有效设置不再生效。原文件保留为corrupt文件，不能称永久删除。
- 证据：当前Core逐一执行schema12–18；13–17全部抛异常，12/18以及17的空对象对照保留PageSize=77。Store.Load对schema17回退PageSize=100、更换设备标识并隔离原文件；保护器调用0次。
- 最小修正：在读取priorPlayback前要求Object，空节继续采用Repair默认。回归覆盖缺节/null/对象及13、17边界，并断言其他有效字段不变、Store不隔离可修复文档。现有null节用例固定schema10，未覆盖该分支。

### R02-002 · P2 · 旧目录主文件复制失败仍被判为迁移成功

- 位置：`src/Momoka.Core/Infrastructure/AppPaths.cs:134–135,156–157,289–294`。
- 触发：当前目录无主备，第一旧目录的settings.json被独占读锁或权限阻止复制，第二旧目录有可读配置。CopyTree吞掉主文件复制异常，MigrateFrom仍返回第一来源，MigrateFromAny提前停止。
- 后果：启动未尝试可恢复的后续候选；若本次也未复制出可用备份，Load采用默认（本轮反例属于此情形）。退出保存后可能使下一次也不再迁移，用户需手动找回仍保留的旧配置。
- 证据：匿名第一文件持有FileShare.None，第二文件完整可读；PrepareStartupData返回第一目录，但目标settings.json不存在，Load读出默认PageSize=100，第二来源完整保留。没有锁定真实文件。
- 最小修正：主配置完整复制成功才算迁移成功，再尽力复制缓存等附属文件；主文件失败应允许继续候选。仅以File.Exists确认目标不足以防部分复制。增加首项被锁/权限失败、第二项成功与附属文件失败不撤销有效主配置的用例。

### R02-003 · P2 · MoviePilot空密文字段通过加载却使设置卡构建异常

- 位置：`src/Momoka.Core/Configuration/SettingsMigration.cs:354`、`AppSettings.cs:1347`；调用者 `src/Momoka.Shell/ViewModels/SettingsViewModel.cs:1164,2383`。
- 触发：当前schema文档中 `MoviePilot.ProtectedPassword` 为JSON null。Repair只修整个MoviePilot节，字段null保留下来；HasSavedPassword直接访问Length。设置页首次创建无条件构建MoviePilot卡，即使它处于关闭状态。
- 后果：读取设置看似成功，随后打开设置时同步抛NullReferenceException，无法正常进入设置页。页面没有局部恢复；实际WinUI终止行为没有在本轮制造。
- 证据：匿名文档经实际Store.Load保留设备与PageSize、未隔离；调用当前Shell实际MoviePilotCard（_settings只注入匿名SettingsService）在Enabled=false时抛NullReferenceException。没有执行整页Reload、账号解密或网络。
- 最小修正：在加载的Repair处按现有账户凭据规则验证该必需字段，拒绝损坏文档以走备份/隔离恢复；或明确制定一致的可恢复null规则。不要只在HasSavedPassword吞null而让损坏密文继续传播。覆盖缺键、空串、null、关闭MoviePilot及有效备份恢复。

### R02-004 · P2 · 字幕密钥加密失败越过输入行的错误处理

## 覆盖边界与排除项

- 保存快照不写回活对象、旧代快照不得覆盖新同步保存、新编辑不被旧失败取消、隐藏后的排空与重开状态已沿生产链及专项检查；未发现需要另修的确证缺陷。HasUnsavedChanges表示保存失败欠项，待调度编辑由版本另跟踪，不将其改作“滑块每次都报未保存”。
- 偏好备份保留同步即用的列表引用，生产调用立即序列化，不据引用共享本身要求抽象或深拷贝。导入/默认保留服务器、账号、连接密文和子对象引用，具体显隐/播放生效交后续分区。
- 直通保护器仅在测试/匿名探针使用，生产注册DPAPI。CredentialVault加密失败清空为现有显式测试契约，不能仅因与字幕策略不同另报缺陷。danmu_api的8192密文裁剪未证实破坏合法输入，实际端点限制明文不超过512字符，不计缺陷。
- SchemaVersion精确键与当前反序列化忽略大小写有差异，但尚无手改键大小写的承诺支持证据，记录输入兼容边界，不列缺陷。无schema的 `{"Ui":{}}` 用例走v1，不能证明v2+缺键；快照测试给当前模型设旧标签是防止保存重跑迁移的有效测试，不是历史schema输入。
- 非当前用户DPAPI、断电持久性、UNC/网络盘、真实权限变化和跨进程写入不在本次执行覆盖中。Atomic通过不代表这些场景全覆盖。
