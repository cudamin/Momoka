# 音乐媒体库

音乐库统一使用 `MusicLibraryPage` 和同一底部播放栏，Emby、Jellyfin、Plex、飞牛音乐共用布局与交互，不按服务器另建音乐界面。服务器差异仅在协议适配与适用功能显隐中处理。

在服务器连接页输入 Emby、Jellyfin、Plex 或飞牛音乐地址。飞牛音乐使用音乐网页入口（路径包含 `/music/`），随后输入用户名和密码；它与飞牛影视分别保存账号身份。已有音乐库会出现在主页媒体库和侧栏，点击进入歌曲页。

音乐页按分区画成两种形状，不是五个长得一样的列表：歌曲与收藏是一张**曲目表**（44 的方封面、等宽时长、发丝线只从标题那一列起画、正在放的那一行左缘一条强调色），专辑、艺术家与歌单是一面 170 的**方形封面墙**；点一格进入那一层的曲目列表。形状与格子尺寸由 `MusicCatalog.UsesCoverWall` / `WallTileWidth` 决定，有 Core 测试钉着。页头是眉字＋库名＋等宽条目读数（歌曲按「首」、专辑「张」、艺术家「位」、歌单「个」），分区是一排药丸而不是单选圆点；搜索框按剩余宽度收放，窄窗自己换到下一行。

点击歌曲时收齐所选列表的分页后建立播放队列，大库首次准备可能需要等待，停止可取消。底部播放栏换曲时，曲目表里那一行的标题换强调色（播放栏的 `CurrentKey` → 页面 → `MarkPlaying`），停止后清空。切换页面不停止音乐。艺术家详情显示当前服务器该艺术家的曲目。Plex 歌单是当前账号的服务器级音乐歌单；Plex 容器/歌单搜索、收藏，以及飞牛音乐容器/收藏内搜索不提供入口。

底部播放栏是一条**悬浮单行胶囊**（2026-11-11 改版）：材质沿用项目亚克力画刷，封面墙与曲目表从它底下透上来；圆角由代码取实测高度的一半，正常窗宽两端永远是半圆。提供上一曲、播放/暂停、方块停止、下一曲、封面与曲名、细进度条（框架 Slider 覆写尺寸资源键改细，拖动／键盘／焦点保留平台行为）、时间读数（收在艺术家行右侧）、随机、循环、收藏、队列和音量。音乐页不再为它整行让位：滚动区自己留避让（`MusicLibraryPage.SetPlayerClearance`），末行能滚到栏上方，停播后归还；其余页面仍由外壳预留底部空间。方块停止会结束播放、清空队列并隐藏整条控件；暂停继续显示。紧凑档（<760）收起随机／循环与时间读数，窄窗（<480）再收起封面、退成两行圆角矩形，随机和循环仍在队列浮层可达。系统关闭透明效果时使用主题实色回退。

音乐使用内置 libmpv，无视频窗口，不载入视频着色器、SVP、自定义视频配置、uosc 或弹幕脚本；与视频共用单一播放服务和账号生命周期。音量确认后保存到已有音频偏好，下一首沿用。媒体流使用现有带身份隔离的传输，凭据不放进资源 URL 或子进程参数。

飞牛音乐协议依据本次官方 1.1.19 前端，详见[协议证据](飞牛音乐协议.md)。目前普通原文件音频可播放；CUE 分轨、ISO/SACD、转码/HLS、歌词、漫游、OAuth 与服务端音乐管理不在本批范围。

## 本批验证

- `music-fixture`：曲目查询、艺术家关联、歌单路由与队列规则。
- `fnmusic-fixture`、`plex-protocol-fixture`：各服务协议与媒体映射、分页、登录/恢复边界。
- `music-playback-fixture`：AudioOnly 规划、内置内核选择、无窗契约、上报及视频服务隔离。
- `Momoka.MusicViewModelTests`：真实 VM/PlaybackService/EmbySession 的停止、迟到结果、分页队列、收藏与音量；另含分区形状（44 曲目行／170 封面墙、读数与第二行）、专辑容器里不重复专辑名、正在播放标记与 `CurrentKey` 的换曲/停止。
- `--probe-shell --probe-section music --screen 1`：真实 WinUI 五主题、1280/760/360窗口、自动化定位和停止按钮，曲目表与封面墙两种形状各出截图（`music-*-screen.png` / `music-wall-*-screen.png`），并核正在播放那一行的标记与列头显隐；使用匿名假服务，拒绝真实播放与写入。`shell` 分区检查音乐库侧栏导航。胶囊改版后同探针加核：亚克力画刷、单行高度与半圆端、栏压在页面内容上（而非整行让位）、曲目表／封面墙滚动区避让与停播归还；探针整棵外壳上屏、播放栏用外壳自己那份。
- `artifacts/verification/music-native/REPRODUCE.md`：本地静音 WAV 的真实 libmpv 初始化、播放/暂停/跳转/音量、Stop/EOF和无顶层窗口证据；不验证物理扬声器或真实服务器。

主测试、专项测试与运行探针的数量有重叠，不合计。所有服务器真实播放、收藏与历史写入须按 CLAUDE.md 授权边界另验。
