# 播放菜单与工具

播放页面和内置独占窗口的右键菜单共用目录；快捷键在「设置 → 快捷键」搜索和修改。新增动作不会抢占已有的自定义绑定；原有70个默认键保持不变。

## 播放操作

- 轨道与章节：视频、音频、主字幕、次字幕、章节列表；字幕重新选轨会恢复对应可见性。
- 画面：宽高比、旋转、缩放、平移、裁切填充、ICC、调色、去色带及HDR控制。
- 视频和音频：解码、帧同步、插值、反交错、声道、均衡、设备、独占、延迟。
- 字幕：主次显隐、位置与延迟、字号、跳句、重载、ASS/SRT/位图格式兼容。
- 截图：当前尺寸、原始尺寸、窗口及逐帧截图。逐帧截图仅在内置且无自定义配置时提供，换片或停止自动结束。
- 静音跳转：临时分析解码后的音频，完成或取消后恢复倍速、静音和暂停状态。再次执行可取消；分析进行中换片可能重建独占窗口。
- 章节制作：本次播放标记、编辑和删除章节，并导出CHP或OGM格式。不修改原媒体或服务器章节。

菜单按轨道、字幕格式、内核属性及滤镜支持收起无效项。当前随包内核没有`cropdetect`，自动去黑边隐藏；具有该滤镜的外部mpv可提供此操作。旧H.264兼容参数只在解码器初始化时生效，因此没有作为即时开关加入。

## 外部工具

在「设置 → 播放工具」选择自己安装的程序。找到exe只确认路径存在，程序版本是否兼容仍由执行结果确认。

| 功能 | 条件 |
| --- | --- |
| 无损MKV片段、GIF、文字字幕导出 | FFmpeg |
| 带字幕GIF | FFmpeg、已选文字字幕 |
| 截图裁切、字幕区域拼图 | FFmpeg；先保存至少两张同宽区域再拼接 |
| 字幕同步 | FFmpeg、FFprobe及ffsubsync或alass；使用当前选中音轨 |
| AI字幕 | FFmpeg及兼容faster-whisper-xxl参数的程序；当前音轨可读取 |
| 整份字幕翻译 | FFmpeg、已选文字字幕，并在字幕设置启用和配置翻译服务 |

视频片段先标记开始、结束时间。AI识别有标记时处理该区间，未标记时处理整片；生成字幕加回原片时间偏移。无损剪切受关键帧约束，不保证逐帧精确切点。

Plex多段文件目前隐藏外部媒体工具，避免把整片时间轴误用于首段；截图仍使用播放器当前画面。远程媒体先由Momoka下载完整本地副本，再交给程序；需要下载时间和磁盘空间。准备和处理期间右键菜单保留取消。字幕翻译会按配置发送整份文字字幕，可能产生服务费用。程序路径与服务器认证信息不会进入可分享的偏好备份，认证信息不会进入工具命令行。

输出默认使用截图保存目录，也可在工具设置指定目录。任务先写临时文件，成功后以唯一名称保存，不覆盖已有输出。同步、AI及翻译字幕仅在原影片仍在播放时自动加载；换片、停止或取消会阻止旧任务回载。

## 主要新增默认键

| 操作 | 默认键 |
| --- | --- |
| 标记片段开始／结束 | W／Shift+W |
| 导出GIF／带字幕GIF | Ctrl+W／Ctrl+Shift+W |
| 导出无损片段 | Ctrl+Shift+C |
| 导出当前字幕／自动同步 | Alt+M／Ctrl+Alt+M |
| 生成AI字幕／翻译整份字幕 | Alt+F／Ctrl+Alt+Shift+T |
| 裁切截图／字幕区域／拼图 | Ctrl+Alt+C／Ctrl+Alt+R／Ctrl+Alt+Shift+R |
| 章节标记／标题编辑／删除 | Alt+C／Alt+E／Alt+R |

全部键位以右键菜单右列及快捷键设置的当前绑定为准。

## 来源与验证

上游以本地`mpv_config-2026.08.12/portable_config/input.conf`及对应脚本为参考，另核对GitHub提交`e235480f28674ee507ac87d2d0c8e79ac1fa0682`。菜单来自`input.conf`的`#menu`注释，`menu.conf`本身为空。

开发回归：当前Release Tests编译后运行`native-menu-fixture`、`player-tools-fixture`、`player-tool-download-fixture`；Shell编译后运行`settings-page-state-fixture <Shell DLL> <仓库根>`及`--probe-shell --probe-section shortcuts`。Lua执行测试为`tools/test-uosc.py`与`tools/test-mpv-analysis.py`。这些不播放真实服务器媒体。

真实程序验证使用匿名合成媒体覆盖FFmpeg片段、GIF、字幕、音轨提取、图片裁切与拼接，以及alass的SRT同步；faster-whisper、ffsubsync和真实云翻译未做联网运行验收。
