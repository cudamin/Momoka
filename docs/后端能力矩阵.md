两种内置播放管线共用「导航 → 本次播放队列」。有可操作的当前片时可搜索并安排后续视频，有待播项时提供上移、下移、移除和清空。聚合模式有多个可用影视账号时可切换选片来源。待播项保留原服务器和账号，账号退出后移除对应条目。四后端共用客户端安排方式，搜索沿用各自的只读媒体接口。四后端真实搜索和跨服务器接续待验。[本次播放队列的验证入口](开发与验证.md#2026-11-21-本次播放队列)

主页媒体库封面可在「设置 → 主页 → 媒体库封面」开启，四后端共用叠卡、九宫格海报墙、纯文字渐变三套单选预设，默认关闭。已保存的旧「斜切大图」值按未知值回到叠卡。只替换主页媒体库入口横排，关闭恢复原图，不生成服务器封面、不写回或改变媒体 DTO。选图复用该库已读到的近期条目和已有库封面，按来源账号与登录代次隔离；不为被隐藏的近期排追加目录查询。缺图显示库名渐变，九宫格少图循环补足；MP 与本地入口复用其已有封面读取路径。叠卡保留左侧库名，右侧用最多三张不同近期海报组成静态悬浮扇形：最新海报在前卡，较早两张分列后侧并降低不透明度，配圆角柔影和三停点主题渐变；不足三张时由库已有封面补位，仍不足复用已选图。纯文字不发图片请求，叠卡最多读取三张、九宫格最多读取九张缓存缩略图。三种预设均为静态构图，不启动封面循环动画或解码 APNG；高对比主题使用系统前景背景的文字封面；关闭覆盖后的 APNG 原路径继续保留。当前只有离线 Core、正式 VM 与构建证据，四后端真实窗口画面、主题和输入仍待统一验收。

侧栏「日历」仅依赖独立的 MoviePilot 连接，与四后端的媒体库编号、播放能力和账号权限无关；未启用或连接不可用时隐藏，设置可单独关闭，关闭后退回主页并清理日历历史，保留订阅入口和日历偏好。六周月视图七列适应窗口宽度、不横向滚动；日格海报等比缩放、窄卡文字重排，显示集数和真实入库进度，五卡以上原地展开。读取日期窗口、分页及当前 MoviePilot 账号的数据，不把下载进度当已入库。当前仅离线协议、实际视图模型与源码显隐契约验证，四后端实屏及真实 MoviePilot 未验证。

主页轮播版式与媒体库位置属于上述四后端共用的客户端展示：商店版式固定媒体库在整组轮播下方，并隐藏不生效的位置设置，整宽版式恢复保存偏好；商店支持三档响应式推荐与主卡饼形倒计时，鼠标悬停主卡暂停、移开保留余量。当前以 Core、真实主页/设置 VM 与源链接计时测试验证，不表示四后端实屏或真实鼠标均已验收；服务端请求与权限能力不变。

主页「媒体库」横排中的服务器库入口可独立显示和排序，涵盖上述后端与飞牛音乐。默认沿用当前目录次序，已有偏好时新增库默认显示在末尾。聚合时以来源和库编号区分同名库，切换或暂时离线不会覆盖原偏好。设置作用于主页的库入口；侧栏导航与各库最近添加货架仍按各自的现有规则显示。离线测试覆盖四后端及飞牛音乐的目录载入顺序和设置隔离，实际窗口中的拖拽及实服数据仍待验证。

四后端共用的影视媒体库卡片墙按图像大小的目标宽度就近选列，允许窄窗封面略小于目标；卡片宽高与网格在同一轮更新，停止缩放 120ms 后再补齐图片清晰度。刷新期间保留旧图，新图成功后替换，失败仍显示旧图；同一卡片的清晰度替换不重新淡入，首次到图与换卡仍淡入。客户端沿用各后端原有取图、身份和取消边界，不改变服务端能力或入口显隐。四后端真实窗口缩放、主题、DPI 与交互仍待统一验收，不能以离线布局和图片生命周期用例代替实屏流畅度证据。

四后端共用的影视媒体库封面可以播放图片响应中保留的 APNG 动画，GIF 使用 WinUI 原生解码。动图使用响应图片的原生分辨率，不再按卡片宽度或整部动画帧数缩小；APNG 在后台逐帧解码并复用画布，解码位图缓存及 APNG 活动画面有字节预算，GIF 内部帧缓存仍由 WinUI 管理。封面是动图时，悬浮预览保留这张封面，避免被静态宽图替换；预览徽标自身是动图时也播放，预览拥有独立播放容量。关闭预览、真正离树或最小化停止 APNG 帧更新，系统或应用关闭动画时 APNG 退回静图。客户端保留各后端原有的取图方式；响应若只有静态缩略图，封面就显示静图，动图 WebP 仍按原路径显示。原生像素、帧合成、预算、取消、预览保留动图与卡片回收有离线测试，各后端真实响应与窗口画面待验。

「通知」位于 Momoka 设置组的「诊断」正上方，只对在线且可管理的 Emby 来源显示；多个 Emby 来源保留独立来源键，并在侧栏、下拉和搜索中附服务器名，不切换默认来源。其他后端（含飞牛音乐）未适配本页使用的 Emby 用户通知接口，连接后隐藏入口；不据此推断服务端没有通知能力。断线或明确降权后撤回入口并拒绝旧页面／编辑器请求，隐藏保留本地通知接管偏好。Emby 权限未知时沿用现有回退。当前验证为匿名离线的正式设置 VM、源链接通知 VM 和命令测试，未访问真实通知服务或实际发送通知；实际窗口、主题、DPI 和实服兼容待统一验证。

## 使用规则

四后端共用的影视封面关联转场按条目所属登录身份仍在线判断，不要求它是默认账号；
退出／重登、不同账号同 ID、图版本改变仍拒绝旧票据。2026-11-21 修正聚合主页误判，
封面票据离线边界覆盖非默认来源与默认切换；原生检查使用匿名 Emby 夹具，其他后端真实转场尚未验收，
不改变协议、权限或入口显隐。按用户排障要求，飞行使用 Image 直角快照，静态圆角保留。

- **共享领域模型或通用 UI 能力有改动时，同一批次更新本表。** 至少核对四个后端的“已接入／只读／隐藏／未验证”状态，以及受影响分支的显隐测试；只改一个后端而让其他后端静默降级，不算完成。
- **“未接入”必须继续隐藏入口并在服务层拒绝请求**，不能只靠置灰、空页或提示代替；服务端后续支持也不自动等于客户端已接入。
- **真实验证按后端分开记账。** 离线假传输、协议夹具、单后端实服只读或播放，只证明各自覆盖；不能用 Emby 的结果代替 Jellyfin、飞牛或 Plex。
- **能力差异先查当前源码和协议技能。** 本表与实现冲突时以当前源码、测试和当轮证据为准，并回写本表；不要从其他后端的相似功能推断协议。

## 搜索页的独立来源

Emby、Jellyfin、飞牛影视和 Plex 共用搜索页来源栏。媒体库搜索使用当前媒体服务器账号。MoviePilot 订阅、资源和字幕依赖独立的 MoviePilot 连接，AniBT 使用独立公开查询，入口同时要求 MoviePilot 可用和 Momoka 的 AniBT 功能已开启。连接或功能不可用时保留来源入口和恢复说明，禁止查询。资源站点和字幕站点沿用同一份本机站点偏好。各来源的真实服务回包和窗口交互按待交付批次验收。
