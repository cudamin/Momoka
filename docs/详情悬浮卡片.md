# 详情滚动悬浮卡片

2026-11-13：详情页主播放键在滚动视口顶部被裁切一半时，显示顶部应用内亚克力卡片，缩略保留封面、片名、副标题和原播放操作。回滚超过半切线4 DIP时收回；小按钮的余量最多为自身高度的十分之一。宽窄主按钮按正式 `IsCompact` 选择，判断使用实际布局坐标；不从头图高度猜滚动阈值。

浮层与正文 ScrollView 同级，不改变正文高度或滚动落点。520 DIP以下收起海报和播放文字，按钮保留实时可访问名称和提示。资料复用详情绑定，播放复用原 `PlayCommand`；后台附属读取不会剥夺已确认的播放入口。无目标、命令不可用、断树和离页立即收起，旧队列不得重开旧卡片。

## 先查桌面 Gallery 的证据

按用户指定先静态检查 `C:\Users\89400\Desktop\WinUIGallery.exe`，没有启动它。实际版本2.10.0.0，产品提交 `7b4314a25904c784e5a1b4bb0627f535550d88bd`，exe SHA256为 `9e2b08e9a4937e9c8c0be0ed577d153f596353a01db0329993fc3dc439b4ec7d`。单文件bundle内解出的实际 `Controls/ControlExample.xaml` 定义：显示位移24→0 DIP/400ms、透明0→1/200ms；隐藏位移0→24 DIP/200ms、透明1→0/100ms，均为EaseOut。实际CIL的 `HandlePresenterVisibility` 由选择项切换 Visible/Collapsed，附加的 `Implicit.ShowAnimations/HideAnimations` 接到平台Composition。未找到完整的滚动半切缩略头样例，滚动检测与资料卡是本次本地组合。

Gallery提交没有从公开Git远端取到，结论采用exe实际XAML与CIL，不以另一缓存提交冒充此版本。REA整exe检查受128MB快照上限拒绝，按真实bundle成员表提取较小DLL后完成检查。Gallery DLL成员证据 `ev_c257c5c9870917f17e345602dbf70f4ee2dee264a62dd1e92a28352a0b3a95d3`；Toolkit证据 `ev_380229a5b84d5855de54933bba21278a2f1557f3c8e37086a1f0f994e0731fb1`。

Gallery与Momoka引用的 `CommunityToolkit.WinUI.Animations` 8.2.251219 DLL哈希完全相同：`336b63fb560642b644c8325e2370d3ff3c501fc2b8b91ac4d7dac7053bcfb25f`。包nuspec和PDB SourceLink指向 [Toolkit固定源码](https://github.com/CommunityToolkit/Windows/tree/a6b4dc451c0e54dd29f58743894a956100e7f713)。核对 `components/Animations/src/Implicit.cs`、`Xaml/ImplicitAnimationSet.cs`、`Xaml/Default/{Offset,Translation,Opacity}Animation.cs`、`Xaml/Abstract/ImplicitAnimation{TValue,TKeyFrame}.cs` 和 `Extensions/AnimationExtensions.cs` 后复用：不新增或升级依赖。

必要适配：顶部方向改为-24 DIP，使用Translation替代布局拥有的Offset；去掉会把反转强行拉回起点的From，仅首次显示初始化起点，保留样例进退时长和EaseOut。平台负责Collapsed后的视觉退场；页面立即移交焦点并关闭命中。应用或系统关闭动画时撤hook，停止Opacity/Translation并落定；离页取消所有订阅和旧队列。此适配为当前XAML布局与生命周期所需，并非逐字复制整个Gallery控件。

实际Gallery `Samples/Acrylic/AcrylicPage.xaml` 使用 `AcrylicInAppFillColorDefaultBrush`，此卡片沿用该系统资源及系统描边/文字角色，保留系统固色回退。[微软Acrylic设计指南](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic) 推荐滚动或交互时覆盖内容的辅助界面使用应用内Acrylic；[Motion指南](https://learn.microsoft.com/en-us/windows/apps/design/motion/) 推荐原生动效与一致进退，未发现本方案的硬限制或不推荐冲突。

## 验证入口与边界

`Momoka.DetailStickyHeaderTests` 将完整正式partial编入可观察的平台边界，覆盖阈值、反向、可用性、队列、焦点、宽窄、系统/应用动画和断树；不模拟GPU动画或证明像素。运行方法见 [专项README](../tests/Momoka.DetailStickyHeaderTests/README.md)。原生入口是检查台 `InspectDetailStickyHeader` 或 `library` 分区，使用匿名假HTTP和不能起播的外壳，检查1000/760/360 DIP、真实ScrollView、绑定、亚克力资源、关动画、离页与实屏，写 `detail-sticky.json` 和 `detail-sticky-*-screen.png`。单项通过不代表全量检查或真实服务器/播放验证。高对比、系统透明关闭、节电、跨DPI和Narrator仍按交付环境实际覆盖记录，不能由单元测试推断。
