# MoviePilot 订阅

订阅详情切换剧集组时，文件统计仅挂在原订阅组的对应季；其他组显示自己的剧集列表。取消成功后立即同步按钮、季标记和管理区域，再次订阅会采用服务器分配的新编号。操作结果不明时，可在详情的“更多 → 核对后继续”中核对并解除限制，期间编辑和写操作不可用。

订阅封面读取失败后可通过刷新重试，服务器更换海报后原卡片会加载新图。电视剧文件统计在最窄窗口下改为剧照在上、文字与操作在下；未找到当前 Emby 播放目标时隐藏播放入口，匹配完成后原地显示，操作忙碌时只暂时禁用。

设置 → 主页中的“媒体库顺序”同时列出“MP 电影订阅”和“MP 电视剧订阅”（2026-10-13 晚从“MoviePilot 电影订阅／电视剧订阅”缩短，名字只有 `HomeLayout.FixedTitle` 一处：侧栏那两条、主页那两排、订阅列表页的标题都读它）。可分别拖动、上移／下移及勾选，与 Emby 各排混合排序；首次加入时两排默认放在末尾。MoviePilot 未启用或当前连接不可用时，设置列表和主页同步隐藏订阅排，保留原顺序与勾选，恢复连接后按原偏好显示。

侧边栏模式（设置 → 界面）下，侧栏里另有这两条订阅入口，文案与主页那两排同名，归在“订阅”那条分区标题底下（分区排在“媒体库”那一段之后；没有可用入口时标题跟着收起，不留一条空带子）：点开是一页只列该类的订阅列表（点卡片进订阅详情，与主页那一排同一个控件、同一套刷新与管理菜单）。两条入口的图标照 MoviePilot 网页端复刻（场记板与带底座的电视）。两条入口跟的是同一个判据 —— MoviePilot 开关已开且当前连接可用；没开启或连不上时整条收起，那时若正停在订阅列表页上会退回主页，返回／前进历史里的这一页一并清掉。

搜索页新增 **AniBT** 栏：输入番剧名后按回车，选择番剧查看公开 RSS 资源，下载时选择 MoviePilot 下载器与保存目录。采用 AniBT 官方匿名接口，番剧搜索最多返回 25 条、资源最多返回最新 100 条；没有结果时可以更换译名或原名。MP 启用 Bangumi 来源时使用对应的 Bangumi 媒体详情下载；没有该来源时交由 MP 按公开种子下载，不冒用 TMDB 编号。

**查看遗漏集** 每行提供 MP 搜索入口，关键词按剧名、季号、集号生成；类型包含“动画”或“动漫”时，入口提供 MoviePilot 与 AniBT 两个来源。相同动画类型的“搜索不同版本”折叠为“使用 MoviePilot”和“使用 AniBT API 搜索”。季与单集继承父剧的类型判断，虚拟遗漏集无需读取自身详情。

AniBT 按[官方 Bangumi 搜索](https://wiki.anibt.net/docs/open-api/bgm-search)用纯番剧名查找作品，选择对应季度后用 [RSS](https://wiki.anibt.net/docs/open-api/rss-anime) 的独立 `episode` 参数精确查询分集，不发送 MoviePilot 的 `Sxx Exx` 格式或 TMDB 季号。合集不保证出现在单集结果中，可点“查看全部集数”移除条件。RSS 不支持分页；默认 `limit=100` 按官方要求省略，编号合并的同站跳转保留分集条件，下载使用跳转后的 Bangumi 身份。两个来源均经 MoviePilot 下载确认，可选下载器、已有保存路径或自定义路径。

类型（Genres）包含“动画”或“动漫”的电影、剧集、季、单集，在封面、单集行和详情的更多菜单中新增 **AniBT 识别并重新刮削**。季与单集可读取所属剧集的类型。点击后逐文件优先查 MP 原整理记录的源文件名；没有记录时读取当前视频文件名，多条记录冲突时停止并提示核对。沿用批量文件收集上限 30，超过时提示按季或单集操作，不悄悄只处理前一部分。

识别表列出每个文件的候选，明确的自动识别默认选中，模糊匹配须选择候选。确认后用 Bangumi 编号调用 MP 的文件刮削接口，更新 NFO 和图片，不移动或重命名视频。需要 MP 开启 Bangumi 媒体来源，且当前视频路径可被 MP 直接访问。该接口的电视剧单文件操作更新本集 NFO／缩略图，季集号由 MP 从当前文件名解析，不能用 AniBT 的标题结构强行改写编号；不会额外触发 Emby 扫库。MP 成功回执仅表示已处理请求，未逐个验证图片和 NFO 的落盘状态。

AniBT 两类入口均跟随 MP 的当前连接状态显示；关闭 MP、连接失败、切换地址或账号时撤销查询与旧结果。提交采用逐文件状态和进程内防重，网络结果不明时要求先在 MP 核对，避免重复发送。公开查询规格见 [AniBT 开放 API](https://wiki.anibt.net/docs/open-api)。

MoviePilot 功能仅在设置中开启且当前连接可用时显示，包括搜索来源、主页订阅、搜索其他版本和手动整理。启动后验证当前配置，连接失效时收起入口、已展开的 MP 菜单与下拉层、操作弹窗和独立搜索窗口；搜索页回到媒体库，订阅详情回到主页，返回或前进不会重新打开失效页面。已启用时每 30 秒检查连接，恢复后重新显示；修改地址或账号密码立即撤销旧连接，等待新配置验证。设置卡始终保留，“测试连接”不会自动打开开关，历史测试成功也不代表当前连接可用；测试过程中断线或认证失败也不会显示为连接成功。

搜索页的“MoviePilot 订阅”按关键词查找可订阅媒体，并支持按来源筛选；“MoviePilot 资源”直接到站点搜索资源，输入后按回车或点击搜索图标提交。订阅媒体搜索随输入更新，选中作品后的“搜索资源”仍按媒体身份精确检索。切换两种入口会取消旧查询；返回订阅搜索保留已选来源。

两种资源搜索均提供“搜索站点”：默认沿用 MoviePilot 自身的搜索站点设置，取消“使用 MoviePilot 默认站点”后可多选，也可全选或清空。从订阅搜索结果点击“搜索资源”后，先选择站点，再点击“搜索资源”发起首次精确查询。全选会明确发送当前目录内全部已启用站点的编号；清空后须重新选择，不会自动改成默认搜索。更改站点会取消旧结果，按回车或点击“搜索资源”应用；已有结果中的“站点”筛选仍只筛当前列表。站点目录在打开选择器时读取，精确媒体搜索按电影或电视剧能力筛选，读取失败可刷新重试。

相同完整发布名、体积及媒体身份的跨站点资源默认折叠；展开后各站点的优惠、做种数、种子页面与下载按钮仍各自保留。体积缺失或媒体身份不同的结果不合并。筛选与排序新增“季”和“集”，按 MoviePilot 返回的编号、范围或离散集列表匹配，包含第 0 季特别篇；切换季会刷新集选项。未标集号的合集可在“全部集”查看，筛选不会推测其包含哪些集，也不会改变原始下载范围。

下载确认框可选择 MoviePilot 的已启用下载器及已有保存路径，也可输入自定义服务器路径；默认下载器和空路径继续沿用 MoviePilot 配置。远程存储路径保留其前缀。下载器和路径目录仅提取名称与保存路径，不显示连接凭据；读取失败可刷新或明确使用默认值。取消、离开页面或切换查询不会提交下载；改变下载器或路径不能绕过已提交、处理中或结果待核对资源的防重状态。

在设置中启用并连接 MoviePilot 后，主页按“媒体库顺序”显示已勾选且有内容的订阅排。两排共用一次列表读取，在进入主页时读取，并每分钟刷新；每排右上方可手动刷新。关闭集成后停止读取，离开主页后停止轮询。

“季”展示 MoviePilot 返回的全部有效季号。TMDB 媒体可在“默认”和服务器提供的剧集组间切换，随后展开该组的季，读取剧照、集名、日期、简介与入库状态。切换剧集组只是浏览，不会修改原订阅。组内季号取服务器返回值，特别篇 0 季合法；不同组的集号、缓存和状态分开处理。入库状态无法读取时显示未知。

“已订阅 N 季”或季旁的心形按钮打开季选择弹窗。选择剧集组、季和普通订阅／分集洗版／全集洗版后，底部显示待提交变更；提交只新增选中且不存在的季、取消本组中被取消勾选的季、修改实际改变的模式。未显示季、其他组和其他来源的订阅保持不动。全集洗版指当前季目标范围的整包。新增后读取服务器返回的订阅编号核实模式；中途失败保留已提交项并停止，结果不明须显式核对，不自动重发。关闭弹窗不提交草稿。

“搜索资源”菜单支持标题／IMDb 搜索，先选站点，再显示可筛选和下载的资源列表；它不会执行可能自动下载的订阅搜索。媒体精确搜索接口只支持季，不支持剧集组和单集参数；集入口在返回资源包含集号时追加筛选。订阅季折叠栏里每一集的搜索仍按“剧名 S0x E0x”查询。“搜索字幕”显示独立字幕列表，选择服务器目录并确认后由 MoviePilot 保存字幕，签名下载对象在内存中原样回传。

右上角那张资料卡不带小标题，最上面是评分星（取订阅快照），下面是一列字段：来源 ID、原名、状态、上映日期、语言、国家、制作公司，再接订阅编号、订阅状态、年份、总集数、订阅进度、搜索间隔、时间、站点、下载器、保存路径与用户，都取真实媒体详情与订阅快照。订阅那一行的状态写“订阅状态”而不是“状态”，因为媒体信息里已经有一行“状态”说的是 TMDB 的状态。媒体评分不在这张卡里，它跟着片名（见上一段）。这些字段只显示服务器确实给出的那些；没有订阅（从搜索或推荐打开的纯媒体详情）时评分星与订阅那几行一起收起，卡上只剩媒体信息。演职员可打开资料站，相关推荐和相似作品可继续在项目内浏览详情和订阅。正文最下面这三段（演职员、相关推荐、相似作品）照电影详情页的版式：每段一块板（与上面季那块同一种材料），板里是货架牌子接一条横向翻页货架带，指针进到带上时两端浮出翻页箭头。**这三条带子用的是详情页那同一个货架控件，不是嵌在页面里的横向滚动条**——后者会把手底的竖向滚轮吃掉，指针停在带上时整页就滚不动了（2026-10-12 用户报的「往下翻页之后不能往上翻」）。“更多”菜单中的“搜索”是立即执行订阅搜索，可能自动下载，仍有明确确认；暂停、恢复、重置、编辑与取消同样接真实接口。取消订阅保留已入库文件。

主页封面不再显示“订阅中”标签；更多按钮固定在封面右下角。鼠标悬停或键盘聚焦时，框内图片轻微推近；系统关闭动画时保持静态。电视剧的“订阅进度”显示在封面内部左下角，与更多按钮并排，无进度数据时不显示占位说明。

已入库的电影和每集电视剧提供播放按钮。客户端在当前 Emby 账号下按媒体来源编号、媒体类型及季集查找实际条目，再交给现有播放流程，保留续播和剧集列表。重复条目优先按入库文件路径匹配；MoviePilot 其他媒体服务器的 `itemid` 不会直接当作当前 Emby 的编号。当前账号找不到或无权读取的条目不启用播放，待入库和缺集不显示播放按钮。页面仅执行读取，点击播放才会真实起播。

订阅集列表参照季页面：左侧为 MoviePilot 文件统计中 `backdrop` 对应的横版剧照，中间显示集名、播出日期、入库状态和剧情，右侧为播放图标，剧情下方不显示路径。播出日期只对来源为 TMDB 的订阅显示，来自 TMDB 季集接口而不是文件统计（见下方接口表）：已播出的写“播出 年-月-日”，还没播的写“待播出 年-月-日”，取不到日期时这一行不出现。剧照按可见行读取，缺图保留占位，刷新和离页撤销旧图片。季页面的集列表也提供右侧播放图标，沿用原有播放动作与选集列表。

已播出的集在播放按钮下方另有一颗“搜索资源”按钮：按“剧名 S0x E0x”在 MoviePilot 各站点搜这一集的可下载资源，打开的是和“搜索其他版本”同一个独立窗口，结果里的下载、详情与站点选择与那边一致。还没播出、以及取不到播出日期的集不给这颗按钮——没播出的集搜也搜不到。搜索本身只读取，点“加入下载”才提交。

编辑支持搜索关键词、包含／排除、质量、分辨率、特效和电视剧起始集／总集数，只发送实际修改的字段。站点、下载器、保存位置等其他设置保留服务器当前值。

## 入库与缺集

- 电视剧的文件统计与逐集列表住在订阅那一季的折叠栏里：打开订阅详情即自动展开；切换剧集组后若该组不含订阅季，或季信息读取失败，折叠栏暂不可达，刷新可恢复。电影没有季折叠栏，原先给电影留的那块独立「入库与缺集」面板已按用户令删除（2026-10-12）：电影页上的入库情况由头部的入库徽标交代，文件统计照旧读取。“更多”菜单的「文件统计」只在电视剧上出现，展开订阅季并滚到折叠栏；电影上这一项跟着收起。
- 首页“订阅进度”来自订阅的 `total_episode` / `lack_episode`，不能视为入库进度。
- 详情逐集读取 `subscribe/files/{id}` 的 `library` 与 `download`。媒体库文件路径或媒体服务器条目构成入库证据；只有下载文件时显示“已下载 · 待入库”。
- 缺集筛选包含订阅目标范围内所有未入库集，包括已下载待整理以及尚未播出的集。依据起始集和总集数过滤，不混入其他目标范围。
- 空响应、接口错误及缺少统计不会显示为“已全部入库”。电影使用接口中的零号条目。

## 接口与版本

2026-10-11 只读核对当前服务器为 `v3.1.3`，媒体身份、元数据和剧集组响应与[后端同版本源码](https://github.com/jxxghp/MoviePilot/tree/v3.1.3)及[前端同版本源码](https://github.com/jxxghp/MoviePilot-Frontend/tree/v3.1.3)对照。此前 v3.1.2-1 部署的 OpenAPI URL 返回 404 是历史观测，当前契约以对应源码与只读响应为准。

| 能力 | 接口（相对于 `/api/v1/`） |
| --- | --- |
| 媒体详情 | `GET media/{id}?media_source=&type_name=` |
| 全部季 | `GET media/seasons?media_source=&media_id=`，不猜季号 |
| 剧集组／组内季 | `GET media/groups/{tmdbid}` / `GET media/group/seasons/{groupId}` |
| 媒体入库状态 | `POST mediaserver/exists_remote`，媒体快照加所选 `episode_group`，只读 |
| 新增订阅 | `POST subscribe/`，含季、组、`best_version` 和 `best_version_full` |
| 资源搜索 | `GET search/media/{id}`，`area=title/imdbid`，支持季和站点 |
| 字幕搜索／下载 | `GET search/subtitle/media/{id}` / `POST download/subtitle` |
| 全量订阅 | `GET subscribe/`，省略 page / count 保留全量语义 |
| 单条详情 | `GET subscribe/{id}` |
| 文件统计 | `GET subscribe/files/{id}` |
| 集播出日期 | `GET tmdb/{tmdbid}/{season}`，可带 `episode_group`；回话是裸的集对象数组 |
| 编辑 | `PUT subscribe/`，id 加实际改动字段 |
| 暂停／恢复 | `PUT subscribe/status/{id}?state=S/R` |
| 执行订阅搜索／重置 | `POST subscribe/search/{id}` / `POST subscribe/reset/{id}` |
| 取消订阅 | `DELETE subscribe/{id}` |

文件统计的每集字段只有 `title` / `description` / `backdrop` / `download` / `library`，**没有播出日期**，所以播出日期另走 TMDB 季集接口。只有来源为 `themoviedb`、媒体编号是数字、季号明确的电视剧才发这一趟；其他来源（豆瓣／IMDb 等）不发请求，屏上就不显示播出日期，也不判“已播出”。这是一趟附加读取，失败按“没有日期”处理，不影响入库统计与播放匹配。

官方公开文档的旧版搜索／重置使用 GET。客户端优先 POST，只有明确的 HTTP 405 才改用旧方法；超时、断线、服务端错误不会触发自动重放。所有这些动作都按有副作用操作处理，与 HTTP 方法无关。回执只说明请求提交成功，不代表下载或整理完成。

连接及账号归属绑定到每批结果。切换连接、离页或取消后，旧列表、旧确认和迟到图片均不应重新生效。结果不明的订阅写操作会锁定；菜单“核对后继续”要求用户先核对服务器状态，再显式解除限制，不自动重发请求。

## 验证

Core 的 `MoviePilotSubscriptionTests` 覆盖分区和身份、入库统计、字段差量、请求方法、405 兼容、结果不明及旧连接，以及播出日期的解析、已播出判定、TMDB 季集请求参数与非 TMDB 来源不发请求；`MoviePilotVersionQueryTests` 覆盖按订阅快照拼的“剧名 S0x E0x”关键词。`--probe-shell` 的订阅界面检查，操作的是假服务器，涵盖宽窄布局、封面导航、菜单、编辑、筛选、确认取消、离页和切换账号，并断言集列表的播出日期行、已播出集的搜索按钮位置与关键词、操作排的形状（五颗带字的键加右端“更多”，以及“更多”菜单摊平的那几项、没有第二层折叠、没有重复的项）、简介那一块不画底色，以及电影页上没有“订阅规则”板块、没有可播放片源时“播放已入库”收起；截图在该次 `shell-probe` 日志目录（`mp-subscription-episodes-<宽>.png` 是集列表那一段）。

新增 `MoviePilotMediaDetailTests` 覆盖媒体身份、组和季差量、三种模式、回执核对、非 TMDB 季查询及字幕下载。Shell 探针另覆盖背景那一套（图按页宽等比铺在页面顶部、罩子正好盖住图那一屏、图下沿那道渐变钉在画面下沿上、下方组件站在不透明的纸面上，并核对图高与 `DetailHero.PictureHeight` 逐像素一致）、五套主题、宽窄季列表和订阅弹窗、切组零写入、模式真实请求体、取消草稿、部分失败和迟到响应。所有写入验证使用假服务器；真实服务核对只读，不等于真实下载或播放验证。
