# 第一轮：减少重复布局和无关初始化（实施计划）

状态：范围已确认（只做第一轮，并在修后用真实账号做只读导航计时对比）；尚未实施。
依据：[调查结果.md](调查结果.md)。

## 范围与非目标

本轮只做调查里的第一轮四项：主页矮窗档合并调度、媒体库 Attach 合并、最近搜索按需加载、搜索/筛选/设置面板懒创建。

不做：主页与媒体库内容快照缓存（第二轮）、轮播背景解码缓存、聚合模式逐排回填、Frame 导航缓存、动画曲线或时长调整。

## 工作包 1：主页矮窗档合并调度与布局去重

文件：`src/Momoka.Shell/Views/HomePage.xaml.cs`、`tests/Momoka.HomeFoldCompletionTests/`。

1. 页面尺寸、轮播尺寸、幻灯片变化、加载完成、货架变化、订阅变化和播放层交回统一走一个 `ScheduleOverlay()`；一次调度只跑一趟。
2. `UpdateLibraryOverlay` 拆成薄包装和核心方法；包装加运行中守卫，重入只记待办，本轮结束后补排一趟。
3. `ApplyLibraryChrome` 记录上一次宿主显隐、宿主内容引用、`OnScrim` 和轮播让位高度。四样都没变且没有动画在飞时，清掉旧落点账目后直接返回：不写控件、不跑强制布局。只有真的换了才写，写完再布局；轮播让位状态或高度真的变了才调 `Banner.SetLibraryOverlay`。
4. 统计公开给探针和夹具：`OverlayPasses`、`ForcedLayouts`、`SkippedChromeWrites`、`OverlayPassMilliseconds`。页面里的强制布局统一经 `ForceLayout()`，计数和计时只在这里加。
5. 保留翻档旧落点量测、`_before` 消费、动画起点和终点、媒体库升降几何不变。

验证：

- 扩展 `Momoka.HomeFoldCompletionTests`：连续尺寸/幻灯片事件只排一拍；重入只补一趟；宿主无变化时 0 次写入、0 次强制布局；有变化时仍写一次并保留原动画。
- 匿名性能探针导航主页后读计数，缩放和换幻灯片只增加合并后的趟数。

## 工作包 2：媒体库 Attach 合并

文件：`src/Momoka.Shell/Views/LibraryPage.xaml.cs`。

1. 新增 `_attaching`、`_viewPending`、`_sectionsPending`、`_headerPending`。
2. `OnNavigatedTo` 的 Attach 段（`ViewModel.Attach` 与面板接线）内，属性通知只记待办；不立即执行 `ApplyView`、`BuildBrowseSections`、`ApplyHeaderLayout`。
3. `ApplyHeaderLayout` 在 Attach 期间也只记待办，避免宽度还是 0 时反复算。
4. Attach 段结束统一执行一次 `ApplyView()`、`BuildBrowseSections()`、`ApplyHeaderLayout()`；`BuildBrowseSections` 内部已有一次头部布局，最终只保留一次。
5. 计数 `ViewApplies`、`SectionBuilds`、`HeaderApplies`，只在真正执行时增加。`OnLoaded` 的头部布局保留，因为那是第一次拿到真实宽度。

验证：

- 匿名性能探针导航普通库页并完成布局后，`ViewApplies`、`SectionBuilds` 各为 1，`HeaderApplies` 为 1（Attach 时宽度 0 的那次不计）。
- 现有搜索生命周期与页面契约夹具全过。

## 工作包 3：最近搜索按需加载

文件：`src/Momoka.Shell/ViewModels/LibraryViewModel.cs`、`src/Momoka.Shell/ViewModels/LibraryViewModel.Search.cs`、`tests/Momoka.Tests/LibraryResumePagingTests.cs`。

1. 删除 `Attach` 末尾无条件 `LoadRecentSearches()`。
2. 新增 `_recentLoaded` 和 `EnsureRecentSearches()`：仅当请求是搜索页、搜索框为空、设置与图片存储已就绪时加载；`Attach` 重置标记；条件不满足直接返回。
3. `OnSearchTextChanged` 在值为空时调用 `EnsureRecentSearches()`；非空不清掉已加载清单，也不发新请求。
4. `SearchAsync` 的空查询分支改用 `EnsureRecentSearches()`；`ClearRecentSearches` 仍重建空清单。
5. `ReleaseSearchPosters` 与 `Dispose` 的释放不变；条目内容、排序和上限不变。

验证：

- 扩展 `library-resume-paging-fixture`：普通库 Attach 不产生最近搜索行、不请求图片；空搜索页 Attach 产生行并请求图片；有词搜索页不产生；清空或空查询后恢复；重复按需加载不重复请求。

## 工作包 4：搜索、筛选、设置面板懒创建

文件：`src/Momoka.Shell/Views/LibraryPage.xaml`、`src/Momoka.Shell/Views/LibraryPage.xaml.cs`、`src/Momoka.Shell/ShellNavigationProbe.*`、`tests/Momoka.SearchLifetimeTests/`。

1. XAML：三个搜索面板从页面根移到 `SearchSourceHost`（`Grid.Row=2`，初始无子元素）；筛选和设置浮层保留遮罩容器，移除内部的 `FilterPanel`、`LibrarySettingsPanel` 元素。
2. 代码：用私有字段保存五个面板；提供 `Ensure...` 创建入口，负责创建、接线、加入宿主、设置边距和尺寸。创建入口返回实例；探针通过成员访问读取，不使用反射找字段。
3. `OnNavigatedTo` 不再无条件附加三个搜索面板；MoviePilot 搜索快照和滚动位置先挂在待恢复状态，面板首次创建时 `Restore` 并刷新订阅状态。
4. `ApplySource`：只对已创建的 MoviePilot 面板取消搜索；只显示或隐藏已创建的面板；当前选中来源可用时才创建对应面板。
5. `SearchTypingAsync` / `RunSearchAsync` 只在对应来源分支访问对应面板。
6. `ApplyHeaderLayout` 只给已创建面板设边距；`SearchSitePicker` 在资源面板创建时再附加站点列表。
7. `Release` 使用空条件调用；MoviePilot 快照只在面板存在时捕获。`ApplyPanelSize`、`OpenFilter`、`OnSettingsClicked`、`CloseFilter`、`PrepareFilterPanel`、`BuildFilterPanel`、`FilterTemplatesResolve` 全部兼容尚未创建的面板。
8. 探针同步修改：读取 MoviePilot/AniBT 面板的地方先选来源或直接成员访问；“其他面板收起”改为“未创建或收起”；`LibraryBrowse` 的筛选/设置在打开动作之后读取。

验证：

- 匿名性能探针：普通库页导航后面板创建数为 0；打开筛选、设置后各为 1；切到 MoviePilot、MoviePilot 资源、AniBT 时只创建对应面板；重复开关不重复创建。
- `Momoka.SearchLifetimeTests` 与 `MoviePilotLifetimeTests` 的边界和文本断言更新后全过。
- `performance`、`library`、`search`、`anibt`、`moviepilot` 受影响探针区域全过。

## 批次验证与真实计时

- 批次内小修：编译受影响项目，运行覆盖改动的定向夹具。
- 批次收尾：全方案 0 警告 0 错误；主测试通过；受影响探针与关键页面宽窄截图；主题与布局没有可见改动，仍按 UI 检查要求拍关键页面。

- 合并 master 后以主树最终代码重跑适用验证，再更新实际交付目录与桌面快捷方式。

## 风险与回退

- 主页排队一拍可能改变首次加载的动画时序：以现有折叠夹具和实机返回主页、缩放检查兜底；若行不通，回退为同步重入守卫（不排队）作为最小修复。
- 面板懒创建牵动探针和释放路径：以搜索/订阅生命周期夹具和五个相关探针区域兜底；未创建的访问一律显式空判，不用 `!` 掩盖。
- 最近搜索按需加载：清空输入框的恢复路径用真实 VM 夹具覆盖；如发现来源可用性变化需要刷新，只加来源变化失效，不扩大为缓存。
