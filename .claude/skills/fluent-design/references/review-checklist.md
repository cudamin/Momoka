# Fluent 验收清单

用途：把「看起来对不对」变成可逐项判定的检查。每项都要有实际观察到的证据；只读代码只能证明用了哪个令牌，不能证明渲染结果。

## 1. 验收前置

先写清楚这次验收的范围，避免用一整屏的结论覆盖全部界面：

| 项 | 取值 |
| --- | --- |
| 界面 | 页面 / 对话框 / 浮层 / 设置页 / 列表 / 空状态 |
| 主题 | 产品提供的全部主题 + 跟随系统；至少覆盖浅色与深色，记录实际深浅 |
| 宽度 | Small（不超过 640）/ Medium（641–1007）/ Large（不小于 1008） |
| DPI | 100% / 150%（至少两档） |
| 输入 | 鼠标 / 键盘 / 触控（如支持） |
| 特殊状态 | 高对比、关闭动画、远程桌面、透明效果关闭 |
| 数据 | 匿名夹具或已授权账号；记录数据规模 |

## 2. 检查表

### A. 层级与表面

- [ ] A1 每个区域能明确归入 base / content / overlay，且只使用该层的材质与圆角。
- [ ] A2 页面根没有额外铺不透明底色，Mica 能透出（除非内容需要独立底色）。
- [ ] A3 卡片外没有多余的 Border 或「卡片套卡片」。
- [ ] A4 浮层有 1px 描边与阴影；卡片默认只有 1px 描边。
- [ ] A5 同一屏没有同时出现两套表面语言（例如 Mica 卡片 + 实心卡片）。

### B. 排版

- [ ] B1 所有字号来自阶梯：12 / 14 / 18 / 20 / 28 / 40 / 68。
- [ ] B2 字重只有 Regular 与 Semibold；没有 Bold、Italic 强调。
- [ ] B3 页面标题 28、区块标题 20、正文 14；层级不超过三级。
- [ ] B4 正文行宽 50–60 字符；宽屏没有铺满整窗。
- [ ] B5 溢出用省略号；没有硬裁或文字压住相邻元素。
- [ ] B6 文案句首大写；专有名词与用户输入保持原样。
- [ ] B7 中英文、数字、单位混排没有错位或基线跳动。

### C. 颜色

- [ ] C1 没有硬编码颜色（`#RRGGBB`、`White`、`Black`、命名颜色）。
- [ ] C2 文本使用 Primary / Secondary / Tertiary / Disabled 四档，语义正确。
- [ ] C3 正文对比度不低于 4.5:1；大字与图形不低于 3:1。
- [ ] C4 强调色只用于主操作、选中态、进度、链接；没有大面积铺色。
- [ ] C5 强调色底上的文字使用 `TextOnAccentFillColorPrimaryBrush`。
- [ ] C6 语义色配了图标或文案；没有只靠红绿区分状态。
- [ ] C7 深色与浅色都实际切换检查过；没有「深色下看不见」的元素。

### D. 间距与几何

- [ ] D1 尺寸、边距、位置都是 4 的倍数（1px 描边、2px 焦点环除外）。
- [ ] D2 同层级间距一致；没有 10、14、18 这类值。
- [ ] D3 控件圆角 4，浮层与对话框 8；相接元素不圆角。
- [ ] D4 标准控件高度 32；紧凑密度只出现在数据密集区。
- [ ] D5 可点击目标不小于 40 × 40，相邻目标间距不小于 8。
- [ ] D6 没有用 `Height` 写死控件；本地化长文本能撑开。
- [ ] D7 图标与文字间距 8；图标尺寸在同一界面内统一。

### E. 材质

- [ ] E1 窗口使用 Mica；旧系统或透明关闭时回退为实心且可读。
- [ ] E2 Acrylic 只出现在浮层或临时表面；没有全屏亚克力。
- [ ] E3 没有材质套材质（Mica 上叠 Acrylic、Acrylic 上叠 Card）。
- [ ] E4 浮层背景与背后内容有足够分离；长文没有放在 Acrylic 上。
- [ ] E5 高对比模式下层级仍能靠描边与表面色分辨。

### F. 状态与动效

- [ ] F1 每个可交互元素都有 Rest / PointerOver / Pressed / Disabled 四态。
- [ ] F2 按下有下沉（高程 2 降到 1），不是只换颜色。
- [ ] F3 选中态与悬停态可区分；选中不只靠颜色。
- [ ] F4 键盘焦点可见，双色环没有被裁掉或压住内容。
- [ ] F5 动效只动 `Opacity` 与 `RenderTransform`；没有动布局属性。
- [ ] F6 退出动效配了淡出；同一状态变化只有一个动画。
- [ ] F7 关闭系统动画后，所有操作仍可完成，没有等动画的遮罩。

### G. 无障碍

- [ ] G1 所有交互元素可 Tab 到达，顺序与视觉顺序一致。
- [ ] G2 图标按钮有 `AutomationProperties.Name` 与 ToolTip。
- [ ] G3 读屏能读出控件角色、名称、状态；列表项能读出选中态。
- [ ] G4 高对比主题下文字、图标、焦点都可见。
- [ ] G5 没有仅靠颜色传达的信息。
- [ ] G6 200% 缩放下内容不被裁切，滚动可达。
- [ ] G7 错误提示可被读屏播报，且给出恢复动作。

### H. 响应式

- [ ] H1 在 640 / 641 / 1008 三个临界宽度实际拉伸检查。
- [ ] H2 按内容区宽度判断布局，不是按窗口宽度。
- [ ] H3 Small 下导航收起、次要命令隐藏、内容单列。
- [ ] H4 宽窄切换后选中项、滚动位置、焦点不丢。
- [ ] H5 没有出现横向滚动条（除非是明确的数据表）。

### I. 文案与本地化

- [ ] I1 中英文资源键齐全，没有硬编码界面文案。
- [ ] I2 占位符、复数、日期、数字格式正确。
- [ ] I3 按钮文案用具体动词（如「删除」「保存」），破坏性操作写清对象；不用含糊的「是 / 否」。
- [ ] I4 错误文案说明发生了什么、下一步做什么，不暴露凭据与内部路径。
- [ ] I5 空状态有说明与主操作，不是只有一句「暂无数据」。

## 3. 证据记录模板

| 编号 | 界面 | 状态 | 判据 | 方法 | 结果 | 证据 |
| --- | --- | --- | --- | --- | --- | --- |
| B1 | 媒体详情页 | 深色 | 字号属于阶梯 | 截图 + XAML 检查 | 通过 | `artifacts/.../detail-dark.png` |
| F4 | 设置页 | 键盘 Tab | 焦点环可见 | 截图 + UIA | 通过 | `.../focus-settings.png` |
| H3 | 主页 | 640 宽 | 导航收起、单列 | 截图 | 通过 | `.../home-640.png` |
| E5 | 播放页 | 高对比 | 层级可辨 | 截图 | 未验证 | 缺高对比环境 |

判定规则：

- 「通过」必须有本次实际观察到的截图、UIA 输出或运行结果。
- 「未验证」不能计入通过；写清缺什么条件、补验入口。
- 「不适用」要写理由，例如纯文档改动没有界面。
- 旧截图、旧报告、别人的结论不能当本次证据。
- 只读代码可以证明「用了哪个令牌」，不能证明「渲染正确」；涉及视觉结果必须看画面。

## 4. 按改动类型抽样

| 改动 | 至少检查 |
| --- | --- |
| 新页面 | A + B + C + D + F + H |
| 单卡片样式 | B + C + D + F |
| 对话框 / 浮层 | A + E + F + G |
| 主题或材质 | A + C + E + G4 |
| 动效 | F + G6 |
| 设置页 | B + D + F + I |
| 列表 / 集合 | B + C + D + F3 + H5 |
| 纯文案 | I |

## 5. 测量方法

- **截图**：同一窗口尺寸、同一数据、同一主题下对比；深色与浅色各一张；150% DPI 再一张。
- **UIA**：用 Inspect.exe 或自动化树核对名称、角色、状态、焦点顺序；截图不能替代。
- **宽度**：拖到 640、641、1008 三个临界值，各截一张；不要只改设计稿。
- **主题**：逐套切换产品提供的主题与跟随系统，记录实际深浅；不要只测默认深色。
- **动画**：在系统设置里关闭动画后重跑关键路径；确认没有功能依赖动画完成。
- **高对比**：切换到高对比主题，检查文字、图标、焦点、选中态。
- **DPI**：100% 与 150% 各看一次；检查 1px 描边是否消失、图标是否模糊。

## 6. 常见违规与修法

| 违规 | 判定 | 修法 |
| --- | --- | --- |
| 硬编码 `#1F1F1F` | C1 | 换 `SolidBackgroundFillColorBaseBrush` 或 `LayerFillColorDefaultBrush` |
| 正文 13px | B1 | 回到 12 或 14 |
| 标题 `Bold` | B2 | `SemiBold` |
| 卡片外再套 Border | A3 | 删除外层，用间距与标题分组 |
| 页面铺 Acrylic | E2 | 页面透明，窗口 Mica |
| 悬停只改边框 | F1 | 改 `ControlFillColorSecondaryBrush` |
| 按下无下沉 | F2 | 高程 2 → 1 |
| 焦点环被裁 | F4 | 调 `FocusVisualMargin`，检查 `Clip` |
| 动画改 `Width` | F5 | 改 `Scale` / `Opacity` |
| 640 宽出现横向滚动 | H3/H5 | 单列、减列、收导航 |
| 图标按钮无名称 | G2 | 补 `AutomationProperties.Name` 与 ToolTip |
| 成功/失败只用红绿 | C6/G5 | 加图标与文案 |
| 空状态只有「暂无数据」 | I5 | 加说明与主操作 |
| 深色下白字写死 | C7 | `TextFillColorPrimaryBrush` |
| 关闭动画后按钮无响应 | F7 | 状态先落，再播动效 |

## 7. 判定结论写法

一段合格的结论至少包含：

1. 验收的界面与状态范围。
2. 实际通过的检查编号与证据位置。
3. 失败项、未验证项及原因。
4. 是否阻断交付，以及补验入口。

示例：

> 媒体详情页（深色 / 浅色，Large / Small，100% DPI）：A1–A5、B1–B7、C1–C7、D1–D7、F1–F7 通过，截图在 `artifacts/fluent/detail-*`。E5 高对比未验证（本机未安装高对比主题），不阻断本次样式改动，登记待验。H5 在 640 宽出现横向滚动，已修为单列后复测通过。
