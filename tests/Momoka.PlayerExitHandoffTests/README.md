# 退出播放的交接范围与退场淡出

构建时逐字提取当前 `PlayerPage.ReturnToBrowseBeforeStopAsync` 与它调用的 `FadeExitAsync`（同一个区段，一起抽），只替换窗口、抓帧、覆盖层、时钟与 DWM 边界。

普通窗口、全屏、负坐标副屏三例要求覆盖层**先用移动宿主前的客户区、再改铺到还原后的新客户区**、alpha 由 255 单调走到 0（≥8 拍、中间档 ≥3 拍、最后一拍为 0），并且只释放一次、等两帧、真的离开播放页。另外四例：浏览页迟迟不就绪时先按住再淡、一直不就绪时宽限到点照常淡完、淡到一半换片就撤层且不再画、全屏退出与「系统关了动画」保持当拍收摊。

窗口还原、就绪判据、淡出曲线与总时长都用 Core 里那一份（`PlayerMotion`），不是另写一套数。

先还原并编译本项目 Release，再**无参数**运行。此专项不启动真实窗口、原生播放器或服务器；屏上像素另由隔离本地播放探针（`--probe-player-motion`）核验。
