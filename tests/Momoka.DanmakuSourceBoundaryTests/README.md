# 弹幕来源与实例边界

Release 构建时从当前生产文件逐字提取 `DanmakuPanel` 搜索/切源/加载、`PlayerViewModel` 设置重载及设置行构造，链接实际 Core。抽取边界不唯一时构建失败；证据写在 obj 的 source-evidence.json。

无参数运行。覆盖切源迟到结果、结果产生时来源、已显示与在途实例失效、地址/令牌变化废弃自部署选择、读取参数保留选择、弹弹play独立保留，以及三来源×两管线的输入栏偏好显隐与恢复。WinUI 控件与播放/加载端点为替身，不证明真实窗口、播放或远程弹幕读取。

另逐字提取发送探针的换片反射调用、清理块与假 HTTP 传输，配合实际 `ResetDanmakuInput` 和 `DandanPlayClient`，核对正确参数、错误参数与普通断言失败。失败必须保留原始原因并排空故意忽略取消的待发送请求，不能由清理超时洗掉；这三项异步执行，界面清理仍为边界替身，实际 WinUI 发送流程由 playback 分区运行验证。
