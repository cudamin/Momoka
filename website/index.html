Momoka — 原生 WinUI 3 媒体库客户端

Windows · WinUI 3 · libmpv

Momoka 是为 Windows 打造的原生媒体库客户端。原生 WinUI 3 界面、libmpv 播放内核，把 Emby、Jellyfin、飞牛影视与 Plex 的片库收进同一块屏幕——画质、字幕和版本，都按你的优先级来。

01 / 播放

Momoka 用 libmpv 播放，WinUI 3 负责外壳。把真正影响观看的三件事——画质、字幕和版本——在按下播放之前就处理好。

  1. 01

    着色器链，按片源和显卡自动选

    随包内置 ArtCNN、ravu、CfL、SSimDownscaler 等着色器，按放大倍数、真人／动画与显卡档自动挑一条链，四个倍数档都做色度重建。也能手动锁定档位、自动识别动画，并修复老片源。

  2. 02

    字幕按你的优先级来

    为字幕设置自定义优先级，默认排除繁体中文，优先双语字幕与特效字幕。不用每次开播后再翻菜单。

  3. 03

    版本按入库顺序和组名来

    视频版本支持自定义优先级，默认优先播放最后入库的版本，也可以按发布组筛选。聚合模式下，同一部片还能在不同服务器的版本之间切换。

SHADER PIPELINE 自动匹配
放大倍数 四档自适应
片源类型 真人 / 动画
显卡档位 自动匹配，可手动指定
输出 一条匹配的着色链 · 全档色度重建

画质预设与着色器互不影响：关掉着色器，画质完全交给 mpv 自己的预设；开着时，预设也照样生效。

03 / 服务端

支持情况

Momoka 支持多个媒体服务器，但成熟度并不一样。这里如实标出验证边界，避免把「已适配」说成「已验证」。

Emby

主要支持

4.10.x

媒体库浏览、播放与播放记录上报走 Emby 协议，是当前的主力使用场景。

系统要求：Emby 4.10.x

Jellyfin

部分验证

协议 / 离线界面

协议与离线界面已完成适配；真实服务器上的播放、写入和网页控制台登录尚未验证。

实服播放与写入：未验证

飞牛影视

部分验证

网页 0.9.8 · 服务 0.8.43

按官方前端核对；当前原画适配的实际播放尚未验证。版本号是核对记录，不是全版本兼容保证。

原画实播：未验证

Plex

实验性

协议 / 离线测试

只做了协议与离线测试适配，没有对任何真实 Plex 服务器核对。连接、浏览与播放行为未经证实。

真实服务器：未核对

聚合模式

默认只让一台服务器、一个账号在线；打开聚合模式后，多台服务器与多个账号可以同时在线，主页和账号菜单会跟着改变。

聚合模式默认关闭，可在「设置 → 服务器」中打开。

  • 主页

    媒体库列表与各库「最近添加」覆盖全部在线账号；两个及以上账号时，继续观看与库名旁会标出服务器名。

  • 账号

    账号菜单改为「添加服务器／添加账号」，登录另一台服务器不再顶掉当前来源，已保存的凭据保留。

  • 版本

    同一部影视的版本选择里，可以挑选不同服务器的版本，不用先切换服务器。

MoviePilot · 3.x.x

播放和订阅，在一个窗口里。

通过 MoviePilot API 内置手动整理、搜索不同版本等快捷键；主页最下方接入网页端订阅列表，播放与订阅不用来回切页面。

服务端界面

各家的控制台，各归各家。

只有一台服务器在线时，使用它自己的界面；多台在线时，设置左栏按服务器折叠分组。没有库管理权限的服务器或账号，不显示管理入口。
